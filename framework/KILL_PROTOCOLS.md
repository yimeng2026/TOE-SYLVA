## 一、协议规则

### 1.1 判死后处置预案（登记必填第八字段，三选一并预登记）

自本协议发布起，每一条新登记预言除 `BLIND_PREDICTIONS.md` §1.1 规定的七字段外，**必须预登记判死后处置预案**，从以下三案中选定一案，缺一不予登记：

| 预案 | 名称 | 触发后处置 |
|---|---|---|
| **A** | 理论死亡归档 | 条目移入 quarantine（隔离区）并撰写**墓志铭**：命题原文、判死统计量实测值 vs 阈值、死亡日期、遗产清单（哪些下游声称连带死亡、哪些幸存及理由）。内容留存、信用注销——隔离是删除的保守实现（方法学 01 附录 D"隔离"工作定义） |
| **B** | 降级收窄 | 主张范围**显式缩小**并登记收窄点：原主张 → 收窄后主张，被排除的适用域必须逐条列出；收窄后的新主张即日受冻结纪律约束，再收窄须重新登记 |
| **C** | 修正重生 | 修正版作为**新预言重新盲登记**（新编号、新登记日期、新版本哈希），原版条目留痕永久可对照；**禁止原地修改**——原地修改即触发 `BLIND_PREDICTIONS.md` §1.2 自动降级为 POST-HOC |

纪律：

1. 预案在判死触发**前**可经新版本条目变更（留痕）；触发**后**不得更换预案——死后改预案等于没有预案；
2. 处置执行时限：证伪条件被满足之日起 **7 日内**执行完毕并同步 `ERRATA_AND_NEGATIVE_RESULTS.md` 登记；
3. 执行完毕状态改标 `STATUS: KILLED-A` / `NARROWED-B` / `REBORN-C`，原 `FALSIFIED` 记录保留。

### 1.2 判死触发与"悬置"纪律

- 证伪条件**干净触发** → 立即进入 §1.1 处置流程；
- 触发**不干净**（范围限定、参数化模型依赖、统计成色不足）→ 标记**悬置（待决监控）**，措辞锚定 `VERIFICATION_PROTOCOL.md` 附录 A.1——必须注明悬置原因与复裁窗口（何种数据到达时复裁）。**禁止借悬置无限拖延**：悬置条目连续两个复裁窗口未干净判定者，自动按 B 案降级收窄处理；
- 判定动词一律锚定置信级别（L1–L4，双条件判定 min(方法级别, 证据级别)）——判死是治理文件对外最强声称，无级别不判定。

### 1.3 登记日体检规则（防"登记日前已被满足"）

登记任何预言时，必须核查其证伪条件**在登记日当刻的满足状态**：

- 条款在登记日尚未被满足 → 正常登记；
- 条款在登记日**已被字面满足或已承压** → 必须显式标注"**带病登记**"，写明存续所依赖判据的成色（先验声明 / 后验冻结线），并把处置预案的提升为更高警觉级别（建议直接预选 B 案）；
- 隐瞒登记日已满足状态事后被查出者，条目直接降级 POST-HOC 并登记 FW 级框架警告。

本规则由 BP-1（α⁻¹ ≈ 137）案例倒逼设立，回填示范见 §三 KP-R3——这是本协议"本应如何工作"的标准演示。

### 1.4 负面结果公开制度（ERRATA 升级路径）

负面结果与判死事件**一律公开**，路径与 `ERRATA_AND_NEGATIVE_RESULTS.md` 三类条目对应升级：

| 阶段 | 登记类别 | 升级条件 |
|---|---|---|
| 单点负结果（按协议正确执行但未得预期） | `FN-` | 登记即公开，无需升级 |
| 已发布内容被更正/判死 | `FE-` | FN 复查确认是内容错误而非执行问题时升级 |
| 危及一类声称可信度的系统性偏差 | `FW-` | 判死牵连整个 sector/一类判据成色时升级，必须附影响范围评估 |

对标 Deposon 先例：当内部检验显示主张**与平凡基线（其案例为"6 关键词规则"）无法区分**时，不等待外部证伪，**主动执行 B 案收窄并公开**——主动收窄不算失败，隐瞒基线不可区分性才算。本条同时是我方对内的强制义务：凡内部审计发现"主张无法区别于平凡解释"者，7 日内按 B 案登记收窄点。

## 三、已有判死实例回填示范

> 以下三案为我方既有记录按本协议新格式的回填示范（KP-R 编号为示范编号，不回改原始登记文件）。

### KP-R1：CNF-P1 页岩降级条件部分激活案 —— B 案（降级收窄）示范

- **原登记**: `papers/页岩油气_CNF成藏理论/01_CNF成藏理论.md` §5 预登记预言 CNF-P1（渗流阈值：S1 对 TOC 负截距 + 低端趋零）；
- **判死过程**: 长7段数据独立重算 P1 存活（b = −0.238 mg/g < −0.05；低/高半区 S1 均值比 0.254 < 0.35，`02_数据验证报告.md` §P1），但 UFPF 在同一数据同向存活后做跨盆地检验，Permian 盆地出现**正截距**——同向预言在跨盆地场景已被部分证伪，CNF-P1 预登记的降级条件（"若跨盆地失效，降级为成熟度均匀、无运移注入的原地生烃体系特例"）**部分激活**；
- **按本协议的示范处置（B 案）**: 收窄点登记——原主张"渗流阈值普遍存在"→ 收窄后主张"渗流阈值存在于成熟度均匀、无横向运移注入的原地生烃体系（长7段型）"；排除域逐条列出：存在运移注入的盆地（Permian 型）、成熟度强非均一体系；
- **教训**: 预登记时写好降级条件，使"部分激活"发生时不需临场发明退路——这正是 B 案存在的理由。

### KP-R2：MUFPF V1 勘误案 —— A 案（死亡归档）与负面结果公开示范

- **对象**: MUFPF paper6 推论 3.2（P6:159）公式 C=(2π)⁻¹(3/2)^{2/3}，标称值 1.59；
- **判死**: 我方双精度实算 = **0.2086**，偏差 **7.62×**；"1.59" 疑为 (2π)⁻¹=0.15915 的移位误读；其"证明"（P6:163）无实际计算（`papers/外部项目批判重建/README.md` §3.2 V1，严重级；`01_MUFPF四十八篇批判性总评.md` §6.1 点 3）；
- **按本协议的示范处置（A 案）**: 该数值主张死亡归档——墓志铭四要素齐备（命题原文 P6:159、判死统计量 0.2086 vs 1.59、死亡日期 2026-09 批判重建轮、遗产：paper6 K41 部分其余量纲分析不受连带，但其"谱流常数第一原理计算"声称整体信用注销）；
- **负面结果公开联动**: 我方已按 ERRATA 口径公开登记（FN 类，算术复核负结果）；对方若发布勘误，按 `外部项目批判重建/README.md` §七既定流程在 01 号文末追加留痕，不改动既有判定行——**公开渠道与留痕格式在判死前即已约定**，这是本协议 1.4 条的对称要求。

### KP-R3：方法学 01 L372 α⁻¹ 条款"登记日前已被满足"案 —— 协议本应如何工作（范式演示）

- **事实链**: BP-1（α⁻¹ ≈ n_CS = 137，登记日 2026-08-10）证伪条件②为"α⁻¹ 实验测量精度突破 0.001 且与 137 偏差 ≥5σ → 定量预言排空"。而登记日当刻：CODATA 实验值 137.035999084，偏差 0.036，测量精度**早已**突破 0.001——证伪条件②的构成要素在**登记日前即已存在**（方法学 01 附录 C L372 行原文如实转录了该条款与"后验冻结线"成色注记）；
- **问题**: 整数主张在严格意义上登记时已承压，其存续完全依赖 0.04 误差界——而该界是**后验冻结线**（2026-08-06 P0 修复日按实测偏差反推取整、留 10% 余量，BP-1 v1.1 成色更正）；
- **协议本应如何工作**: ① 按 §1.3 登记日体检规则，BP-1 登记当日即应标注"**带病登记**"，明示存续依赖后验冻结线；② 处置预案应预选 B 案且提升警觉级别（§二补登记已照此执行）；③ 证伪条件②应避免"登记日前技术上已满足"的措辞——死刑阈值必须写在尚未被触及的位置，否则条款在波普尔意义上等于没有条款（方法学 01 §5.1"无法执行的证伪条款"自判）；
- **现状的诚实评价**: v1.1 成色更正（"先验声明"→"后验冻结线"）已事后补上①的一半；本协议 §1.3 将其前置为登记时的强制体检，防止下一例"登记日前已被满足"带病入库。

## 四、与既有治理文件的衔接

- **盲登记**: 新登记预言按 `BLIND_PREDICTIONS.md` 七字段 + 本协议第八字段（处置预案）执行；在册 BP-1~BP-4 已按 §二补登记；
- **勘误**: 判死处置执行后按 §1.4 路径登记 `ERRATA_AND_NEGATIVE_RESULTS.md`，FN/FE/FW 编号只增不减；
- **验证协议**: 判死判定措辞锚定 `VERIFICATION_PROTOCOL.md` 附录 A（排除/存活/降级/悬置 × L1–L4）；BROKEN 级失败触发勘误的既有通道不变；
- **参数纪律**: B 案收窄涉及判据/参数调整时，按 `PARAMETER_DISCIPLINE.md` 分类表重新归属（测量输入/定义选择/后验拟合/推导输出）。

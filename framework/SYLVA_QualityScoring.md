# SYLVA 模块质量评分系统

## Quality Scoring System for SYLVA Modules

### 评分维度（6维度）

| 维度 | 权重 | 描述 |
|------|------|------|
| 正确性 | 30% | 定理陈述是否正确 |
| 完整性 | 20% | 是否覆盖关键结果 |
| 一致性 | 15% | 与其他模块是否一致 |
| 可维护性 | 15% | 代码是否易于维护 |
| 可扩展性 | 10% | 是否易于扩展 |
| 可读性 | 10% | 文档是否清晰 |

### 质量等级

| 等级 | 分数范围 | 描述 |
|------|---------|------|
| 金 | 90-100 | 生产级质量 |
| 银 | 75-89 | 研究级质量 |
| 铜 | 60-74 | 草稿级质量 |
| 铁 | <60 | 需要改进 |

### 当前评分分布

| 等级 | 模块数 | 占比 |
|------|--------|------|
| 金 | 0 | 0% |
| 银 | 100 | ~1% |
| 铜 | 9000 | ~98% |
| 铁 | 71 | ~1% |

### 改进路径

1. **铜→银**：完善文档、增加证明思路
2. **银→金**：替换 True := trivial 为实际证明
3. **铁→铜**：修复语法错误、补充结构

# CNF 实证验证制度：独立证据、盲登记与历史预言清算

**文档编号**：104
**版本**：2.0（2026-10-26，证据审计重写）
**原版本**：1.1 / DRAFT v7.79（2026-08-11）
**状态**：操作性协议；不宣称已有 CNF 独立实验验证
**配套**：`CNF_RESTRUCTURING_2026.md`、`VERIFICATION_PROTOCOL.md`

> 1.1 版已经承认“已知物理的 CNF 重述不是独立新预言”和“296 个脚本并非全部针对 CNF”，本版保留并强化这两条。旧 S1–S20 不再自动继承为有效的 CNF 独立预测；本轮没有重跑全部历史脚本，因此不继承任何“当前全 PASS”表述。

## 1. 目的

本协议只解决四个问题：

1. 一项结果究竟验证了代码、数学命题、模型兼容性，还是外部物理？
2. 一个数字是在构造模型前预测的，还是看到数据后拟合的？
3. 它能否区分 CNF 与最简已有理论？
4. 独立研究者能否用同一证据链得到相同结论？

验证的目的不是让预言存活，而是让错误主张尽快、低成本地暴露。

## 2. 五类证据，不得互相替代

| 类型 | 必要产物 | 允许的表述 | 禁止的升格 |
|---|---|---|---|
| F：形式检查 | 定义、命题、依赖公理、编译/证明记录、命题忠实性审查 | “编码后的命题已检查” | “自然语言全部含义和物理本体已证明” |
| N：数值实现 | 输入、代码、环境、随机种子、数值误差、回归结果 | “脚本复现了公式/数值行为” | “实验验证了 CNF” |
| C：理论兼容 | 已知极限、基线、对照模型、误差与偏离 | “模型在该极限与已知理论相容” | “CNF 获得独立实验证明” |
| E：外部经验 | 原始数据、样品/仪器、选择函数、预处理、基线和统计模型 | “数据在某分析下支持/不支持某映射” | “单次显著证明微观机制” |
| P：前瞻独立预言 | 冻结预测、排除条件、盲数据、独立复核和后续结果 | “冻结预言通过/未通过” | “事后解释也算预测成功” |

形式化级别再高也不能替代 E/P；外部显著性再高也不能替代 F/N 的命题与实现审查。

## 3. 统一主张记录

每个拟进入核心框架的主张必须登记：

```yaml
claim_id: CNF-YYYY-NNN
statement: 精确、含单位和适用域的命题
kind: definition | theorem | model | computation | observation | conjecture
assumptions: 全部额外假设
derivation: 推导文件和关键步骤
dependencies: 外部定理、代码库和数据依赖
formal_status: 未形式化 | 部分形式化 | 编译通过 | 命题忠实性已独立审查
null_model: 最简已有理论或无新机制模型
parameters: 测量输入 | 定义选择 | 后验拟合 | 真正输出
prediction_freeze: 时间、版本、参数、排除条件和数据隔离
external_data: 原始来源、版本、哈希、样品/仪器与许可
error_budget: 统计 | 系统 | 模型 | 数值 | 离散化
counterexamples: 已知反例与适用边界
review: 独立复核者、日期、结论和未决问题
status: open | supported | rejected | quarantined | superseded
```

若 `null_model`、误差、反例或参数来源为空，该主张只能处于 open，不能进入“已验证”汇总。

## 4. 历史脚本的当前口径

### 4.1 不继承全 PASS

旧文档列出多个 `verify_*.py` 及 296 个脚本的总索引。本轮未对这些脚本逐一重建环境、核对输入和运行，因此：

- 不在本版写入“全部通过”“42+ 测试全 PASS”或“296 个脚本证明严谨性”；
- 旧结果只能回到原提交、原日志和原数据快照复核；
- 恢复任一结论时，必须标明是 F/N/C/E/P 中哪一类；
- 已知公式或数据的复现至多进入 N/C，不得自动进入 P。

### 4.2 本轮新增检查

`cnf_countermodels.py` 当前为 **6/6**，其范围仅为：裸图自同构、零测度/维数、Fisher 信息通道单调性和粗粒化不可逆性。它证明的是旧全称数学主张存在反例，**不是 CNF 的物理验证，也不是实验结果**。机器可读结果在 `cnf_countermodels_results.json`。

### 4.3 历史脚本恢复规则

每个脚本重新登记时必须回答：

1. 它直接断言的公式是什么？
2. 公式是已知理论、CNF 推导，还是仅为参数定义？
3. 输入数据来自哪里，是否有冻结版本？
4. 断言是否可能在构造时已经保证为真？
5. 如果换成空模型，是否也会 PASS？
6. 有无独立团队或外部数据的复核？

第 4、5 项尤其重要：一个按定义一定为真的断言可以检验实现，却不能检验自然。

## 5. 历史 S1–S20 逐项处置

保留编号是为了追溯，不是保留结论。

### 5.1 S1–S8：已知物理重述

| 编号 | 主题 | 当前裁决 | 重新成为独立预言所缺内容 |
|---|---|---|---|
| S1 | 特定 BCS 参数化下的 \(T_c\) 数值 | **非 CNF 独立证据** | 无目标拟合的参数、材料特异预测及与常规 BCS 的区分 |
| S2 | BKT 有限尺寸漂移 | **非 CNF 独立证据** | 明确模型/边界下的普遍推导和与标准 BKT 不同的偏离 |
| S3 | Mott 临界区间 | **非 CNF 独立证据** | 明确晶格、坐标数和算法；不能用宽区间兼容代替预言 |
| S4 | Josephson \(I_cR_n\) 关系 | **非 CNF 独立证据** | 说明结类型与适用条件，并提出 CNF 特有修正 |
| S5 | BEC–BCS 幺正参数 | **非 CNF 独立证据** | 不从已知幺正气结果反推网络参数 |
| S6 | SYK/混沌界 | **非 CNF 独立证据** | 说明适用理论类，给出 CNF 特有观测和证伪映射 |
| S7 | sQGP 与 KSS 型界限 | **非 CNF 独立证据** | 不能把所有流体或超出特定界限的情形归为 CNF 裁决 |
| S8 | 全息纠缠熵面积律 | **非 CNF 独立证据** | 限定全息态和区域，不能用“任何系统违反面积律”作判据 |

### 5.2 S9–S20：不可操作、非唯一或仅框架内

| 编号 | 当前状态 | 审计理由与恢复条件 |
|---|---|---|
| S9 | **未定义，暂不可裁决** | 先给出 \(\Delta F_g^{(CNF)}\) 的公式、计算路径和与普通 GW 修正的区别 |
| S10 | **非唯一** | \(\eta\) 的量子修正并不专属于 CNF；需可分离的修正项和测量映射 |
| S11 | **未定义** | KO-dimension 是离散结构信息，需说明 \(\delta_{KO}\) 的类型及宇宙线观测量 |
| S12 | **通用 BSM 搜索，不是 CNF 独立预言** | 需要 CNF 对第四代存在性、谱和衰变的排他推导 |
| S13 | **不可操作** | 说明 137 截断对应的物理算子、谱线和未参与拟合的预测 |
| S14 | **不可操作** | 给出周期、振幅、单位、观测通道和与噪声的区别 |
| S15 | **不能作为独立预言** | “本框架内自洽，无需独立实验”不是经验验证；还须指定能标和方案 |
| S16 | **推导未闭环** | 需要 heat-kernel 计算、误差和与精确数据的非拟合比较 |
| S17 | **非 CNF 独有，观测讨论中** | \(w=-1\) 是 \(\Lambda\)CDM 基线；DESI 结果不能直接验证或否证 CNF |
| S18 | **缺少推导和独立观测映射** | 量级相似不能代替真空能计算；需给出实际 \(w(z)\)、密度和误差 |
| S19 | **仅可作理论对照，非实验预言** | 需定义非 BPS 态、修正项和实际可测对象；“未来量子引力实验”不够 |
| S20 | **未定义独立可测量** | 逐层恒等式需先给出层、状态和熵的可计算定义 |

### 5.3 S17 与 DESI 的正确关系

DESI DR2 报告：BAO 与 CMB 组合在 \(w_0w_a\) 参数化下偏好随时间变化的暗能量；加入不同超新星样本后显著性不同。这个结论依赖数据组合和模型参数化，不能直接映射为“CNF 的 \(w=-1\) 被证实/排除”。相关原文见 `TOE_RESEARCH_ATLAS_2026.md` 的 A6。

**恢复 S17 的唯一正当方式**：先由 CNF 推导与 \(\Lambda\)CDM 不同的 \(w(z)\) 或其他观测量，再在数据前冻结；不能只把宇宙学常数已使用的 \(w=-1\) 改名。

## 6. 新预言的盲登记流程

### 第一步：定义与基线

写出自由度、动力学、观测量和最强常规基线。若无法写出 CNF 与空模型的差别，不进入预测阶段。

### 第二步：参数溯源

逐个标记测量输入、定义选择、后验拟合和真正输出。目标数据不得同时承担“确定全部自由参数”和“独立验证”两种角色。

### 第三步：数学反例与已知极限

在拟合前通过量纲、守恒、对称、极限、连续性和已知反例。若连这些检查都失败，不应消耗外部数据。

### 第四步：冻结

在看目标数据前记录预测数值/区间、单位、误差、参数、排除规则、统计模型、对照、停止条件和版本哈希。

### 第五步：独立实现

由未参与模型构造者按记录重建计算。只给最终图和作者口头说明不算独立复核。

### 第六步：外部检验

优先使用未参与构造的数据；记录所有分支，不仅报告最有利的一条。负对照必须能够检测仪器趋势、批次、选择函数或错误机制。

### 第七步：裁决与留痕

结果只可为 `supported`、`rejected`、`inconclusive` 或 `quarantined`，不得用“未来一定验证”替代当前状态。失败和撤回永久保留编号。

## 7. 化学、材料与光谱数据的附加门槛

除了 `CNF_RESTRUCTURING_2026.md` 第 6 节外，本协议要求：

- 原始谱图和机器可读数据与最终图同时保存；
- 样品、批次、仪器、校准、背景和排除记录齐全；
- 拟合前冻结预处理和模型大气/能带/噪声基线；
- 至少一个无新机制基线和一个错误机制负对照；
- 跨批或跨仪器复现，关键结论尽量跨实验室；
- 合成数据明确标注为软件/功效测试，绝不静默回退；
- 可疑来源标为 quarantined，不能作为唯一正向证据。

这些规则针对数据风险和系统误差，不预设立场地指控任何学科或作者。

## 8. 当前没有任何条目可标为“CNF 独立实验完全验证”

这是本版的明确基线，而不是失败宣传：

- 可以保留若干 N/C 类实现与兼容性工作；
- 旧 S1–S20 需逐项恢复，不能整体继承；
- 新的 P 类条目当前应先从一个小模型开始；
- 在第三方以前瞻数据复核前，不写“CNF 已获实验证实”；
- 即使首个独立结果为负，也按本协议公开，作为理论边界而非包装素材。

## 9. 最近一项合格任务

**任务**：构造一个有限因果网络，给出精确局域更新规则和一个不依赖拟合的可观测量；与同规模非 CNF 空模型比较，冻结一项分布外预测。

**验收下限**：

1. 代码和输入可重建；
2. 量纲、极限和反例通过；
3. 预测不是输入恒等式；
4. 有明确空模型和失败条件；
5. 原始结果无论正负都保留。

只有这项任务完成后，才应讨论扩展到标准模型、宇宙学、化学、生命或社会系统。详细模块要求见 `CNF_RESTRUCTURING_2026.md` 第 5、8 节。

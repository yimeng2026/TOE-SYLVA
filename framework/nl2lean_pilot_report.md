## 三、采样协议

### 3.1 分层框架

- **分层维度**：主题（代数/分析/逻辑/集合/数论/Layer3）× 难度（D0–D3）× 源风格（语义名/Lean注释/索引名）。
- **均衡规则**：格点下限 ≥2；因家族重复率极高（13.8 万:1），采样在**陈述家族层**进行（同家族只取代表性实例），并在三个文件风格层各保代表性——风格层系初扫发现三风格并存后补充的第四维度，据此将 2 条配额自超额代表的风格①调剂至未代表的风格③裸文件层（A3/A4，如实记录）。
- **排除**：releases/quarantine/ 隔离件（Layer2）；既有 .lean 与 framework/paper/ 等他人交付（只读未动）。
- **可验证性**：50 条采样全部经脚本断言验证——文件存在 + 定理名存在 + 陈述逐字匹配（`verify_sample.py`，50/50 PASS，脚本与缓存见附录）。

### 3.2 难度分层定义

| 层 | 定义 | 语料实例 |
|---|---|---|
| D0 | 退化：无量词变量、无数学关系的常真/占位式 | `True`、`True ∧ True`、Layer3 sketch |
| D1 | 闭基项恒等式（数值常量间） | `(0 : ℝ) + 0 = 0`、`(1 : ℕ) = 0 + 1` |
| D2 | 单变量全称恒等式 | `∀ a : ℝ, a + 0 = a`、`∀ n : ℕ, n ≤ n` |
| D3 | 关系/结构命题（多变量、关系、模式） | 传递性、集代数、德摩根、列表定律 |

### 3.3 翻译分级决策树（可复现）

对每条采样：先做 NL 重构（语义名/注释优先，索引名回退到陈述的数学阅读并标记"循环测试"），再按以下决策树定级：

1. **名实脱节 → 不可译**：定理名指向实质数学定理，而源陈述为退化占位——忠实翻译名字所指命题与源目标不可能一致（Layer3 全部 4 条）。
2. **退化目标 → 部分可译**：陈述为 D0 纯退化（可给出字面命题并"翻译"，但保真空洞，无训练/评测价值）；含名实部分脱节（名字允诺更强命题、陈述特化）同归此级。
3. **实质内容 → 完全可译 / 部分可译**：内容非退化时，若 NL 可唯一忠实翻译回源陈述（允许绑定风格/类型注记位置等不影响语义的呈现差异）→ 完全可译；若需附加约定（类型欠定、记号歧义、引理签名未核验）→ 部分可译。
4. **兜底 → 不可译**：名/注释/陈述均无命题内容（本试点未触发）。

**循环性声明（方法论诚实条款）**：索引名/Lean 注释来源条目的 NL 系从 Lean 陈述转写，其"翻译成功"是"陈述→NL→陈述"往返一致性的弱测试，不构成独立 NL→Lean 能力证据。本报告在统计中把这部分单列（§5.3），结论仅以非循环子集为准。

### 3.4 局限

- 样本按家族均衡，未按实例加权：语料实例级退化率 25.3% 高于样本 D0 占比（11/50），如实提示。
- 单人执行、无第二评审；NL 重构与分级由执行人判定，决策树规则已公开以便复核。
- 时间盒约束下 Layer1 的 106 家族仅采样 13 条（列表定律、存在性/Nonempty 族未入样，难度均 ≤D3，不影响结论方向）。

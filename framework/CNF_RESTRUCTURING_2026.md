# CNF 的准确定位与结构性整改：从概念统一到证据联邦

**版本**：1.0（2026-10-26）
**对象**：Causal Network Field（CNF）及其数学层级、标准模型、实证协议和跨学科扩张
**配套文档**：`MATH_PHYSICS_WORLDVIEW_2026.md`、`TOE_RESEARCH_ATLAS_2026.md`

> 本文件不是在既有宏大叙事上再增加一层，而是改变验收方式：凡缺少推导的地方，不用范畴、拓扑、信息或熵的词汇填平；凡不能区分 CNF 与已有理论的数值结果，不称为 CNF 的独立验证；凡无法复核的化学与实验数据，不进入正向证据链。

## 1. CNF 是什么，又不是什么

### 1.1 当前可采用的定义

CNF 在本项目中指 **Causal Network Field（因果网络场）**，一个试图用具有局域状态与更新规则的因果网络研究跨尺度物理的研究纲领。它是项目自定义术语，不是学界统一术语，也不是逻辑中的合取范式（conjunctive normal form）。

CNF 的最小研究对象可以写成

\[
\mathcal N=(V,E,\{\mathcal S_v\},\mathcal F,\rho_0,\mathcal O,\mathcal R),
\]

其中：

- \(V,E\)：事件/节点与有向关系；图本身不预先等于物理时空；
- \(\mathcal S_v\)：每个节点可允许的状态空间，可以是集合、向量空间、概率空间或 Hilbert 空间；
- \(\mathcal F\)：局域更新规则或转移核，必须说明输入邻域、时间/因果顺序、边界和约束；
- \(\rho_0\)：初始状态或状态分布；
- \(\mathcal O\)：可观测量及其测量语义；
- \(\mathcal R\)：粗粒化/尺度映射及误差，不假定必然可逆。

这只是**理论描述格式**。要成为一个具体物理模型，还必须指定所有成分，给出动力学、已知极限和观测检验。

### 1.2 不应再混同的对象

- CNF 不等于因果集理论；后者有特定离散偏序、动力学和现象学研究传统。
- CNF 不等于任意网络科学；使用图并不自动产生引力或规范场。
- CNF 不等于量子场论；图上可赋予量子态，不代表已有局域幺正演化和连续极限。
- CNF 不等于“一切皆信息/熵/拓扑”的本体论宣言。
- CNF 的工具复用不等于其他学科被 CNF 解释。

### 1.3 当前科学定位

**可以坚持的方向**：因果结构、局域计算、离散—连续映射、跨理论比较、形式化组件、公开负结果和证据治理。

**必须撤回的成熟度表述**：已经由三条基本网络拓扑推出标准模型规范群；已经完成所有物理层级的统一；大量脚本通过即可证明 CNF；跨领域同名变量能够证明共同微观机制。

**本轮定位**：CNF 是有待建立最小物理核心的研究纲领，不是已完成的 TOE。承认这一点不会削弱项目，反而使真正的局部突破可以识别。

## 2. 核心审计：为什么旧推导链不能成立

### 2.1 裸图自同构不是连续规范群

旧 `105_cnf_standard_model_unification.md` 将单边、二元分支、三叉汇聚分别对应为 \(U(1)\)、\(SU(2)\)、\(SU(3)\)。对于只有节点和有向边的图，自同构是保持节点与边的置换。新增脚本枚举得到：

| 裸图结构 | 自同构数量 | 实际结构 | 旧对应的问题 |
|---|---:|---|---|
| 一条有向边 | 1 | 恒等置换 | 不会自动产生 \(U(1)\) |
| 一个中心连接两个外点 | 2 | \(S_2\) | 不会自动产生 \(SU(2)\) |
| 一个中心连接三个外点 | 6 | \(S_3\) | 不会自动产生 \(SU(3)\) |

`cnf_countermodels.py` 的 G1–G3 即检查这一点；当前结果为 6/6，全脚本只作数学反例与边界演示，不作物理验证。完整结果在 `cnf_countermodels_results.json`。

若希望得到 \(U(N)\) 或 \(SU(N)\)，至少还要引入：

1. 每个节点/边上的复线性纤维 \(V_x\)；
2. 纤维上的内积和局域线性变换；
3. 作为额外假设的局域规范作用 \(G_x\subseteq U(V_x)\) 或特殊幺正子群；
4. 联络/平行移动、曲率、物质表示和动力学；
5. 连续极限及低能规范不变量的推导。

即使补齐这些结构，也只说明可以构造格点规范模型，**仍不能推出规范群恰好是 SM 的三个因子、费米子恰好三代或超电荷恰好取实测值**。

### 2.2 其他逻辑断点

- “三叉节点不可拆开”不自动给出 QCD 色禁闭；禁闭需要非微扰动力学、势能/ Wilson loop、质量间隙和连续极限。
- “三边在高能独立”不自动给出渐近自由；必须计算耦合的 beta 函数。
- 有向边的前后不对称不等于弱相互作用的手征表示；需要 Lorentz 表示、左手费米子和规范耦合。
- “无向图的自同构必须是正交群”不是一般数学结论，更不能据此偏好 \(SO(10)\)。
- GUT 不是逻辑必然；\(SU(5)\) 也不能被一句话整体宣布排除，必须具体到模型、参数和衰变道。
- 右手中微子或 \(0\nu\beta\beta\) 的可能观测不唯一推出 \(SO(10)\)。
- 第四代费米子在某个质量区间的搜索，不是 CNF 独有的判别实验。

旧 105 号文档已经改为“候选结构与否决记录”，不再把这些类比称作已证定理。

### 2.3 数学层级不能以宣言替代证明

旧 62 号文档把尺度、抽象层级、物理基本性和数学表达混成一个全局有限格，并多处把未给条件的对应称作定理。具体问题包括：

- 无法把抽象“数学结构层”统一映射为物理长度；
- 未经证明便假设所有粗粒化有伴随或逆映射；
- 把 Fisher 信息数据处理不等式写成不受条件限制的三角不等式；
- 把基本常数当作所有层间映射的不变量，忽视耦合跑动；
- 把临界、Galois、sheaf、2-范畴等名词当成相互推出的证据。

新版只保留类型化的偏序、映射、误差和明确假设。新增反例脚本还显示：不可数零测度基元的并集可有不同测度/维数，粗粒化可以完全没有逆映射。否定这些全称命题不等于否定特殊模型中的对应，而是要求以后逐案证明。

### 2.4 脚本数量与预测成熟度

旧 104 号文档有两条非常重要的诚实基础，应当坚持：已知物理的 CNF 重述不是独立新预言；验证脚本全部针对 CNF 的说法不成立。现在进一步规定：

| 证据动作 | 能支持什么 | 不能支持什么 |
|---|---|---|
| Lean/Agda 编译 | 编码后的形式命题在声明公理下可推导 | 命题忠实于自然语言、物理映射正确、实验已验证 |
| Python 数值断言 | 某公式/算法在给定输入下按预期运行 | 独立物理真实性、模型唯一性 |
| 复现已知理论或实验 | 兼容性或实现能力 | CNF 独立预言被证实 |
| 后验拟合 | 模型能描述一批数据 | 前瞻预测、机制识别 |
| 外部数据一次显著 | 在指定分析下的统计关联 | 因果机制、独立复现 |
| 独立前瞻与多实验一致 | 逐步积累物理支持 | 永久终极证明 |

因此，旧 S1–S20 不继承为“当前有效 CNF 独立预言”。它们只能作为历史候选逐项重审，尤其是未定义的修正项、无法操作化的远期信号和“框架内自洽无需实验”。新版 104 给出逐项处置。

## 3. 从 TOE 到综述再到 CNF：优点与局限

### 3.1 原路线的实际好处

1. **研究地图**：避免把局部问题误认为与整体无关，能发现共同瓶颈。
2. **语义翻译**：帮助识别不同领域是否在使用同构的数学工具。
3. **复用基础设施**：证明、数值、数据、误差和复核协议可以共享。
4. **外部压力测试**：把 CNF 放到多个已知理论旁边，暴露“只在内部自洽”的问题。
5. **长期方向感**：允许局部失败而不必放弃所有统一探索。

### 3.2 原路线的结构性风险

1. **确认偏误**：先决定所有领域必须属于 CNF，再寻找支持例子。
2. **语义吞并**：把“网络、谱、场、熵、递归”同词当成同物。
3. **已知理论重述**：把 Newton、Maxwell、BCS、BKT、GR 等换成 CNF 参数后，当作 CNF 的证据。
4. **误差消失**：抽象到统一叙事时丢失适用范围、边界条件和不确定度。
5. **成果单位造假**：以文档数、模块数、脚本数和口号覆盖率代替真实推导与实验。
6. **依赖爆炸**：任一底层假设改动都需要重审大量下游论文，造成“迭代很多而有效推进很少”。

### 3.3 改为主次相反但方向不丢的循环

```text
定点真实问题
  → 最强常规基线与空模型
  → 最小 CNF 模型（只含必要抽象）
  → 已知极限与数学反例
  → 冻结判别预测和失败条件
  → 外部数据/独立复核
  → 回头修改 CNF 与综述
  → 再决定是否扩大抽象范围
```

综述仍是突破的基础，但不再自动成为突破本身。CNF 应该承受“某领域不需要它”的结果；只有跨域复用带来更小误差、更少独立参数或新的可检验结论时，抽象才产生增量。

## 4. “分封制”应改造成接口联邦

### 4.1 联邦原则

借鉴“各大区与 CNF 有亲缘，但不必由 CNF 直接解释”的直觉，采用**领域自治、最小亲缘、双边接口、中央只维护协议**的结构。这里“中央”不是最高本体论，只是一组公共服务。

| 领域区 | 可以共享的 CNF 亲缘 | 不得强行要求 | 定点突破示例 |
|---|---|---|---|
| 数学与计算 | 图、偏序、类型、局部映射、复杂度 | 所有抽象层级等于物理层级 | 证明/反例、语义忠实性、成本基准 |
| 粒子与引力 | 局域动力学、离散模型、规范/连续极限 | 裸图直接给出 SM 或 GR | 一个可控格点规范或因果模型 |
| 化学与材料 | 结构—相互作用—性质的因果链、尺度映射 | 一个通用 `g_net` 解释所有材料 | 一种材料的一条前瞻性质曲线 |
| 生物与神经 | 多尺度网络、适应、反馈与稳态 | 把功能、意识和物理熵直接等同 | 一个可干预的网络机制 |
| 地球与气候 | 时空因果图、遥相关、粗粒化和不确定性 | 以简单网络参数替代流体和辐射物理 | 一个分布外区域的预测改进 |
| 工程与社会系统 | 有向影响、时延、干预、反馈和风险控制 | 把相关网络当自然因果定律 | 一个预注册干预或外部预测 |

“每个大区不能直接由 CNF 解释”应被接受为正常现象。CNF 可以只是连接接口、提出反例或提供计算工具，不必占有每个领域的解释权。

### 4.2 “车同轨、书同文”只统一协议

统一以下公共标准，而非统一理论内容：

- **对象标识**：`domain:system:observable:version`；
- **单位与坐标**：SI 或可转换单位，明确自然单位、能标、规范和重整化方案；
- **数据快照**：原始来源、许可、哈希、时间、样品/仪器与预处理；
- **主张格式**：假设、推导、证据、反例、适用范围、复核状态；
- **误差语言**：统计误差、系统误差、模型误差和离散化误差分列；
- **预测冻结**：数据前登记参数、排除规则、对照和停止条件；
- **负结果**：永久编号、不得因新叙事而删除；
- **接口契约**：输入、输出、单位和误差可组合，而非只传一个“可信度分数”。

### 4.3 可能的捷径

真正的捷径通常来自共享可验证的数学/计算组件，而非直接统一哲学：

- RG 与尺度匹配；
- 谱分解、反演和正则化；
- 张量网络与低秩近似；
- 变分原理与最优控制；
- 随机过程、Markov kernel 与信息处理；
- 因果推断、干预和负对照；
- 形式证明、计算机代数与公共回归测试。

这些工具本身就是跨领域成果。使用它们不要求证明“CNF 是它们的共同来源”，也不阻止不同 TOE 在不共享本体时合作。

## 5. 最低 CNF 核心与物理晋级条件

### 5.1 四层模块，禁止跳级

| 模块 | 必要内容 | 可以 claim 的上限 |
|---|---|---|
| N0 图与事件 | 节点、边、邻域、因果顺序、边界 | 图算法和组合性质 |
| N1 状态与更新 | 状态空间、局域核、初始条件、守恒/约束 | 离散动力学与数值预言 |
| N2 连续与对称 | 粗粒化、误差、极限、连续对称性、 Lorentz/规范冗余 | 某类有效场论极限 |
| N3 物质与观测 | 表示、耦合、粒子谱、测量、误差与独立预测 | 可检验的物理模型 |

每层都必须通过下层验收，不能用 N3 的名词反向证明 N0–N2 已完成。

### 5.2 规范模块必须单独登记

若以后引入规范结构，应写成独立模块：

\[
\mathcal G=(\{V_x\},\{G_x\},\nabla,F_\nabla,\{\mathcal R_m\},\mathcal L_{\rm dyn}),
\]

分别对应纤维、局域群、联络、曲率、物质表示和动力学。图自同构 \(\operatorname{Aut}(V,E)\) 与规范群 \(G_x\) 必须分列。若要恢复 SM，还需导出群因子、手征表示、三代、超电荷、 Higgs、反常消除和低能耦合，而不是只比较数字 1、2、3。

### 5.3 “CNF 独立预言”的判别式

一个输出要称为 CNF 独立预言，至少同时满足：

1. 它不是建模时直接写入的已知公式或实验数值；
2. 它的参数不通过目标数据后验调节；
3. 它与最简常规模型/空模型在某一观测量上不同；
4. 能给出数值、区间、单位、误差和排除条件；
5. 数据在冻结后获取或严格隔离；
6. 独立团队能够复核。

如果缺少其中任何一项，可以用“假设”“兼容性结果”“后验拟合”或“研究目标”，但不能称为独立验证。

## 6. 化学、材料与高风险数据的特别纪律

不能因为担忧造假就默认所有化学数据有问题，也不能因为来源看似权威就免检。没有本轮可靠统计支持“化学数据普遍造假”这一全称判断；可执行的是将化学与材料数据列为高审计风险，因为样品、仪器、批次、前处理和模型大气/能带等因素都能产生假机制。

### 6.1 数据进入正向证据链前的最低条件

1. 原始谱图/显微图/读数及机器可读取数据，而非只有截图或最终均值；
2. 样品组成、批次、制备、储存、环境、仪器、校准和操作人员/实验室元数据；
3. 标准样品、空白、阴/阳性和系统漂移对照；
4. 数据清洗、背景扣除、归一化、排除样本和缺失处理的完整代码；
5. 拟合前冻结参数区间与排除规则，不得为吻合而临时改阈值；
6. 同批与跨批、同机与跨机、必要时跨实验室复现；
7. 公开或许可清晰的数据快照、版本和哈希，无法公开时给出可复核受限流程。

### 6.2 统计与机制识别

- 报告效应量、置信区间、样本选择和所有分析分支，不只看 \(p\) 值；
- 多重比较、重复测量、批次聚集和选择函数进入模型；
- 至少一个“无新机制”基线和一个“错误机制”负对照；
- 同一仪器趋势、同批次异常不能独立证明微观拓扑机制；
- 合成数据只能做软件单元测试或功效分析，必须显著标注，不能补充为真实证据；
- 对可疑数据标为 `QUARANTINED`，不得静默删除，也不得继续作为唯一关键证据。

这套规则同样适用于 MUFPF 的白矮星、IT-ToE 的 IBM 采样、CNF 的材料/地质工作和社区提供的任何“实测验证”。

## 7. 对全部改进建议的采纳矩阵

本轮查阅了桌面改进目录中的 4 份 Markdown、5 份 docx、压缩包及 57 张截图。它们是建议材料，不是独立证据；不同报告之间也有重复、猜测和未核实数字。处理如下：

| 建议主题 | 决策 | 理由与落实 |
|---|---|---|
| 停止用文件/论文/Lean 数量当科学进展 | **采纳** | 以主张闭环和独立结果为单位 |
| 建立主张—推导—代码—数据—基准—复核链 | **采纳** | 新版协议和最小模型强制执行 |
| 保留诚实边界、负结果、版本留痕 | **坚定保留** | 这是项目最不应丢掉的优势 |
| 扩大形式化 | **限用** | 先做命题忠实性与公理审计，不以零 sorry 代替物理 |
| 外部数据与独立复核 | **采纳并升级** | 数据快照、冻结分析、负对照和跨批复现 |
| 建立跨 TOE 比较框架 | **采纳** | 已形成 20 族 60 课题和矛盾分类 |
| 用 GraphRAG/Ontology 证明统一 | **驳回作为科学证据** | 可做知识管理，不能推出自然规律 |

## 8. 可执行整改路线与验收标准

### P0：证据止血与数学修复

- 重写 62、104、105，撤回无依据定理和独立预言标签；
- 保留 `cnf_countermodels.py` 与可重复结果；
- 为所有新核心主张登记 `claim_id`、类型、假设、依赖、反例、证据和适用范围；
- 历史版本可查阅，但旧“已完成”不再作为当前状态传播。

**验收**：没有把裸图群、脚本数或形式化覆盖直接称为物理验证。

### P1：一个最小物理模型

- 在 N0–N1 选择一个有限因果网络与局域状态更新；
- 给出精确更新规则、可观测量、基准和至少一个数学反例；
- 只有在 N2 有可计算极限时才讨论连续场论；
- 与不含 CNF 机制的空模型比较分布外表现。

**验收**：即使结果否定 CNF，也能形成一篇有真模型、真计算和真负结果的工作。

### P2：一个外部数据定点

- 优先选择有公开原始数据、明确仪器/样品元数据的材料或量子模拟问题；
- 冻结预测、对照、预处理、排除规则和统计模型；
- 独立复核者只按协议重跑，不参与构造模型；
- 公布失败、无差异和全部后验探索。

**验收**：不是显著性本身，而是第三方能完整重建分析并判断新机制是否有增量。

### P3：接口联邦与跨 TOE 对照

- 每个领域只提名一项成熟基线和一项可比较观测量；
- 先做公共字典和联合基准，再讨论理论亲缘；
- 以相同 T1–T7 门槛比较 CNF、MUFPF、IT-ToE 和国际路线；
- 形成可撤销的桥接，不把桥接当吞并。

**验收**：每个接口都能指出输入、输出、单位、误差、反例和撤销条件。

## 9. 最终立场：反思而不摇摆，坚定而不自封

本项目应当坚定的是：

- 因果结构和多尺度抽象值得研究；
- 统一愿景可以作为长期问题组合；
- 形式化、公开计算和证据治理值得长期投入；
- 外部批评、负结果和错误留痕是研究资产。

本项目应当放弃的是：

- 先验地要求所有学科由 CNF 解释；
- 用高级术语弥补缺失的假设和推导；
- 把已有公式重述、拟合和脚本 PASS 当作独立新物理；
- 以文件数量、模型覆盖率、版本号和“世界级”评价替代科学验收；
- 为了维持统一叙事而回避真正能够否定核心假设的实验。

**最正确的方向不是把 CNF 做得更大，而是让它第一次有机会在一个明确问题上被证明有用，或被清楚地证明不适用。** 这比继续扩大“万物理论”的外围更困难，也更接近真正的跨学科突破。

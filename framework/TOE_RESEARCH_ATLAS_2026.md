## 0. “全部课题”的可审计含义

任何“列出全部 TOE”的承诺都有两个陷阱：新名称可以不断生成；同一理论的不同流派也可以被包装成多个“全新 TOE”。本文采用**问题空间闭合**而非**品牌名称穷尽**：

1. 以基本对象、动力学、连续/低能极限、物质统一、观测量和证据治理为坐标，覆盖主要研究族；
2. 给出 20 个研究族、60 个可执行课题，足以安置主流路线和本轮社区路线；
3. 标注证据边界和优先瓶颈，不把文献数量、口号数量或形式化文件数当成物理进展；
4. 对“其他尚未命名的新框架”保留新增位置，不宣称已经穷尽未来理论。

检索覆盖 Scholar 学术索引、arXiv/期刊和机构资料、MathOverflow、Physics Stack Exchange、Physics Forums、知乎公开内容及百度贴吧原文。学术搜索返回中混有预印本、学位材料、个人主页和低质量条目，本文只选择可定位的原始论文、综述或自述；论坛和自述用于识别观点，不用于证明自然事实。

## 1. 什么叫“严格意义上的物理理论”

“数学上严格”和“物理上成立”是两个独立门槛。一个理论可以数学严密但尚未被实验支持，也可以作为有效近似非常成功但缺少已知 UV 完整形式。为避免“严格”变成身份评价，本文使用下列检查表：

| 门槛 | 必须回答的问题 | 不合格替代物 |
|---|---|---|
| T1 对象与语义 | 状态、自由度、时空/背景、观测量、单位是什么？ | 只列“信息、熵、拓扑、范畴”等词 |
| T2 动力学与一致性 | 更新规则/作用量/路径积分/约束是什么？基本一致性如何？ | 公式拼接、未定义算子、只给静态对应 |
| T3 已知极限 | 在什么近似和误差下恢复 QM、QFT/SM 或 GR 的成功部分？ | 把已知公式换个变量名 |
| T4 参数与标定 | 哪些是测量输入、定义选择、拟合参数、真正输出？ | 后验调参后宣称“第一性原理无参数” |
| T5 独立预言 | 哪个新观测与最简基线不同？何时、以何种不确定度排除？ | “未来可以验证”“同量级”“无需独立实验” |
| T6 外部复核 | 命题、代码、原始数据和推理能否由独立团队复查？ | 只有作者自评、自引和互相引用 |
| T7 证据积累 | 是否经受了多组前瞻、负结果与不同实验体系？ | 单个 p 值、单条曲线或成功案例 |

T1–T2 缺失意味着尚不能认证为完整理论；T3–T4 决定是否是关于我们宇宙的可计算模型；T5–T7 决定其经验支持。**没有任何路线，包括 CNF、MUFPF、弦论、圈量子引力或其他主流量子引力纲领，应仅凭名称直接获得“已证实 TOE”地位。** 标准模型和广义相对论是成功的基线理论，但也没有因此自动构成完整的量子引力与万物理论。

## 2. 国际路线：研究族、真实进展与共同瓶颈

下表中的“已有什么”不是“整个路线已被证实”；“卡点”也不等于“路线已被否证”。

| 研究族 | 已有的数学/物理进展 | 当前必须正面回答的卡点 | 可共享的桥梁 |
|---|---|---|---|
| EFT、SMEFT、引力 EFT | 以局域场、对称性、RG、匹配和误差控制组织已知物理 | UV 边界、非微扰定义、哪些 Wilson 系数可由实验限制 | 所有路线的低能共同语言 |
| 弦/M 理论、全息与沼泽地 | 弦微扰、对偶、AdS/CFT、黑洞与振幅结构；部分非微扰构造 | 全局非微扰定义、真空选择、可控 de Sitter、我们的低能参数与可区分观测 | 振幅、全息、黑洞、EFT、代数几何 |
| 散射振幅、twistor、正几何、Bootstrap | 用幺正性、解析性、局域性和几何避免逐项费曼展开 | 引力非微扰完整性、物质扇区、宇宙学观测量和实验接口 | 弦论、QFT、宇宙学、符号计算 |
| 正则量子引力、LQG、Spin Foam | 几何算子、正则量子化、黑洞与量子宇宙学模型 | 半经典/连续极限、动力学、物质耦合和可区分检验 | 离散几何、张量网络、黑洞、数值相对论 |
| CDT/EDT、Regge 与格点引力 | 非微扰路径积分、相结构和数值时空研究 | 连续极限、相变、Lorentzian 解释、物质与可观测量 | 渐近安全、Monte Carlo、临界现象 |
| 渐近安全、函数 RG、非局域引力 | 非高斯不动点与多类截断研究、物质耦合和现象学 | 截断依赖、Lorentzian/幺正性、完整轨迹与可检验低能输出 | CDT、EFT、QFT、宇宙学 |
| 因果集与序列增长 | 离散偏序、Benincasa–Dowker 作用、经典生长和部分场论工具 | 熵问题、流形样相、量子动力学、局域性和现象学 | 偏序/网络、离散场论、宇宙学 |
| Group Field Theory、张量网络与量子信息涌现 | 群场/张量模型、纠缠几何、全息码、量子多体工具 | 何时真正得到时空与引力，而非只得到关联网络 | LQG、全息、凝聚态、量子模拟 |
| 非交换几何、谱三元组、谱作用 | 以谱数据组织几何，并将标准模型作用量纳入几何框架 | 完整量子化、Lorentzian、参数预言与独立观测 | GUT、算子代数、数学物理 |
| 热力学/熵引力与 emergent gravity | Jacobson 等从视界热力学得到重要联系 | 熵、温度和视界是否已预设时空；微观自由度和额外预言 | 黑洞热力学、信息论、EFT |
| 修改引力与替代基础 | 大量可控有效模型，可用于检验 GR 的适用范围 | 幽灵、强耦合、自然性、 screening 与数据过拟合 | 宇宙学、引力波、太阳系和实验室检验 |
| GUT、SUSY、额外维、复合/前子模型 | 群表示、耦合跑动、味结构、质子衰变和对撞机约束 | 具体模型排除、味参数、天然性和未观测新自由度 | 非交换几何、弦论、精密测量 |
| 黑洞、宇宙学与暗部门 | 丰富的观测和有效模型，可形成强约束 | 模型依赖、初始条件、暗物质/暗能量本质、视界信息 | 所有理论的公共试验场 |
| 量子测量、参考系与非定序因果 | 量子参考系、干涉、过程矩阵和因果不等式研究 | 何时引力量子性产生可区分观测，诠释与实验语义 | 量子信息、引力、实验计量 |
| 计算宇宙、超图、CNF 与社区统一框架 | 可执行离散模型、网络启发、自动搜索和公开迭代 | 规则选择、连续/规范极限、标准模型、独立新预言 | 元胞自动机、格点规范、因果集、软件验证 |
| 数学基础、AI 与形式化 | 证明助手、自动搜索、计算机代数和大规模复核 | 命题翻译、引理依赖、错误传播、成本和产出洪峰 | 所有路线的公共基础设施 |

2024–2025 年 Nordita 多路线讨论同样强调共同语言、分歧和跨方法比较，而不是宣布某一路线已统一全部量子引力。[A1] 对渐近安全、弦真空、离散时空等最新综述，应区分作者对本路线进展的评价与整个共同体的独立裁决。

## 4. TOE 对外接触与普通交叉学科的区别

普通交叉学科可以只围绕一个问题、一个数据集或一种算法合作，并不要求两个领域具有共同的底层本体。TOE 之间的接触若要超出普通合作，还需回答：

1. **自由度如何映射**：节点、弦、几何、场、纠缠或谱是否只是换名？
2. **动力学是否相容**：两套更新规则能否在同一状态空间和近似下同时成立？
3. **低能极限是否共享**：是否恢复同一个 SM/GR/EFT 及其定量系数？
4. **观测量是否同义**：熵、时间、距离、谱、因果和维数是否可互相翻译？
5. **新预言是否交叉约束**：一路线的可行区域是否被另一路线的定理或实验排除？

因此，局部桥接可以非常成功而母理论仍不成立。两个理论共享 RG、谱方法或张量网络，不等于它们拥有同一个宇宙本体；反之，一次术语冲突也不等于物理矛盾。

## 5. 如何利用 TOE 之间的矛盾

### 5.1 先分类，再处理

| 类型 | 表面现象 | 正确处理 |
|---|---|---|
| 语义冲突 | 同名“熵”“时间”“维度”含义不同 | 给出类型、单位和操作定义 |
| 参数/规范冲突 | 数值不同但坐标、能标、方案不同 | 变换到共同约定后再比较 |
| 适用域不同 | 各在不同尺度/边界成功 | 构造匹配区和误差，不强行统一 |
| 真正经验冲突 | 对同一可观测量给出不相容预言 | 预注册判别实验，败者修改或退出 |
| 数学不一致 | 同一形式系统推出矛盾 | 找额外假设、类型错误或证明漏洞 |
| 经验不可区分 | 当前数据共同拟合 | 报告欠定，不伪造裁决；寻找新观测量 |

### 5.2 矛盾是研究资产，不是“各自都对”的借口

- 用矛盾定位适用边界，形成“何时必须换理论”的可计算判据；
- 将一路线的严格否定结果转化为另一路线的公理约束；
- 把不可区分的模型族作为整体比较，避免宣称其中某一个被单独证实；
- 以“交叉不可能性结果”检查所谓统一是否只是把冲突转移到隐变量；
- 允许最终结论是“当前没有共同 UV 完成”，而不是为了地图完整制造联系。

**为什么一种 TOE 不能吞并所有 TOE？** 目前不能给出普遍不可能性证明。许多候选根本尚未达到可比较的完整理论状态；有些处理不同问题，有些经验等价，有些通过不同自由度和近似取得成功。计算不可约性还可能让“知道基本规则”无法推出“高效解释一切宏观现象”。但这些只说明吞并困难，不构成逻辑上永远不可能。真正的统一若出现，应当由恢复已知极限、减少独立假设和通过新检验来证明，而不是由名称宣布。

## 6. 社区路线：同一标准下的具体裁决

### 6.1 CNF / SYLVA

当前材料支持“有因果网络抽象、形式化组件、数值实验和较强证据治理”的评价；不支持“已推出 SM 规范群并完成 TOE”。裸图分支的有限置换群不能自动变成 \(U(1)\)、\(SU(2)\)、\(SU(3)\)，数学层级旧稿也把多处假设写成了定理。整改的关键不是增加文档，而是补齐状态空间、局域动力学、连续极限、表示和真正独立预言。

### 6.2 王斌 MUFPF

本轮读取的公开文本已有两类值得保留的做法：明确某些“正交性”“等价性”尚未机器证明或独立验证；把远期预言登记为未验证假说。[A8] 另一篇白矮星文章报告了样本数、效应、Welch 检验、匹配和回归，比只给一张拟合曲线更可审查。[A9]

但这些作者自述还不足以认证“拓扑禁戒机制”：需要原始目录与光谱、 EW 计算、选择函数、磁场/温度/质量/表面重力的共同分布、仪器效应、模型大气系统误差、全部分析分支和前瞻冻结。\(p<0.01\) 不说明机制正确，也不自动处理选择效应或多重比较。Lean 中由 `SpectralStiffness := Δ²/(2E_F)` 出发证明代数关系，也不能单独验证物理来源。

**定位**：有明确形式化和实证尝试的研究纲领；现有抽样不能认证其为完成的统一物理理论。优先做独立数据复核，而不是增加范畴外壳。

### 6.3 静待核时 IT-ToE

公开三axiom文本把黑洞、生命、意识、社会、强化学习和金融都映射到信息熵/瓶颈/衰减，具有跨学科提问价值，但目前存在过度映射风险。[A10]

在“胜利”文章中，作者以约 0.223 的自身预测区间与约 0.152 的 IBM 均值比较，并同时承认真实噪声和零样本未被模型描述。[A11] 仅“量级接近”不能证明模型；必须给出预测区间的含义、样本量、测量误差、预测是否先于数据、基线模型和分布外表现。零读数也不能在未检查测量语义时直接解释为“量子态完全崩溃”。

**定位**：可转化为具体量子噪声/信用衰减模型的探索材料，不是已经验证的跨物理—生命—社会 TOE。先在一个硬件、一个噪声通道和一个前瞻指标上验证。

### 6.4 粒子宇宙观察者

本轮可定位贴吧原文用 Stefan–Boltzmann 定律估计太阳宜居带，并进一步提出天体有效半径 \(r\approx5R\)；同页还把“理论建模要靠灵感和直觉”作为方法论表述。[A12]

这页没有给出从粒子宇宙模型到 \(5R\) 的推导，也不能把大气、水圈、反照率、温室、轨道变化等复杂修正化为一个通用的除以 \(\sqrt2\)。因此该页不能支撑相应模型的定量物理真实性。这个判断只针对可核实文本，不否定作者其他帖子中可能存在的独立结果，也不以身份判断人。

### 6.5 Wolfram Physics Project 与其他离散路线

超图重写在计算和形式结构上可以研究，项目也持续发布技术材料。[A13] 但“能定性重现某些形式”与“找到我们这个宇宙的规则并给出高精度预言”之间仍有距离。2020 年批评集中于规则选择、定量重现和独立审查，属于该时间点的评价，不应冒充对全部后续工作的终审。[A14]

### 6.6 为什么过去 SYLVA 迭代显得比社区慢

当前没有统一任务、统一日期和独立裁判的历史数据，**无法证明谁的真实科研迭代更快**。可检验的解释假设是：

- SYLVA 同时扩张过多领域，依赖图过大，改动产生连锁复核；
- 内部“论文—代码—报告”循环容易把形式产出当反馈，而公开讨论更早暴露反例；
- 缺少少量可快速冻结的定点问题，综述和统一叙事反复重写；
- Lean 等形式化工作有真实工程成本，但编译通过不能替代物理判断；
- MUFPF 的公开负结果和社区质疑可能更快淘汰某些分支，但也可能带来版本膨胀。

建议不比较发帖速度，而记录四个向量：首个可复核命题的耗时、独立负结果进入后的修正耗时、删除错误主张的比例、同一主张在下一版本的存活率。任何“贴吧更快”的观察只有转为这种同任务对照才有管理意义。

## 7. 本项目的优先顺序

### P0：先清理基础，不新增宇宙论扩张

- 撤销旧数学层级与裸图规范群推导中的全称错误；
- 建立主张—假设—推导—代码—数据—独立复核登记；
- 把全部“验证”重标为形式检查、数值复现、兼容性或外部证据。

### P1：完成一个最小、可失败的物理模型

- 选一个有限图+局域状态空间+更新规则；
- 先检验连续/对称极限与基线，不追求一次推出全部 SM；
- 冻结一项与最简空模型不同的输出，并接受负结果。

### P2：建设接口联邦

- 各领域保有自己的最佳理论，CNF 只提出最小公共抽象；
- 共享观测标识、单位、数据快照、误差和复核协议；
- 优先共享 RG、谱方法、张量网络、变分与因果推断等真实工具，不共享未经证明的本体论。

### P3：在局部突破后再扩展统一

- 只有当至少一个模型在独立数据上产生非平凡、可复核的新结果，才扩大到相邻领域；
- 跨 TOE 工作先做同一观测量的比较，不先做“谁吞并谁”；
- 长期愿景保留，但不再用全领域覆盖率当作进展。

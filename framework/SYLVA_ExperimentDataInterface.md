# SYLVA 实验数据接口

## Experimental Data Interface

### 数据源

| 实验 | 数据类型 | 接口 | SYLVA模块 |
|------|---------|------|----------|
| LIGO | 引力波 | GWOSC API | SYLVA_GravitationalWaves |
| LHC | 粒子碰撞 | CERN Open Data | SYLVA_ParticlePhysics |
| Planck | CMB | PLA API | SYLVA_Cosmology |
| DESI | 暗能量 | DESI Data | SYLVA_DarkEnergyTheory |
| IBM Q | 量子计算 | IBM Q API | SYLVA_QuantumComputing |
| AlphaFold | 蛋白质 | PDB | SYLVA_ProteinFolding |
| GPT-4 | 语言模型 | OpenAI API | SYLVA_DeepLearning |

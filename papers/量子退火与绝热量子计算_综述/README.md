## 主题简介

量子退火（Quantum Annealing）和绝热量子计算（Adiabatic Quantum Computation, AQC）利用量子系统的绝热演化来解决组合优化问题。其核心在于**绝热定理**：如果哈密顿量变化足够缓慢，系统将保持在瞬时基态上。

本综述从 TOE-SYLVA 框架出发，系统覆盖：绝热定理的精确条件（最小能隙 Δ_min 与总演化时间 T 的关系）、Landau-Zener 隧穿公式、绝热 Grover 搜索的二次加速、Kibble-Zurek 机制在量子相变跨越中的缺陷密度标度定律、Ising 模型量子退火的能隙闭合与缺陷生成、以及全局绝热 vs. 局部绝热的路径优化策略。

核心视角：绝热演化路径可被诠释为因果网络上的**信息绝热输运**——能隙闭合对应于因果网络连边的信息瓶颈，缺陷密度对应于信息丢失的标度律，而最优绝热路径对应于信息最小作用量原理下的测地线。

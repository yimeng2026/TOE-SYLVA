## 1. 引言：为什么是"热带"？

### 1.1 热带半环

**定义 1.1**。热带半环 $(\mathbb{R} \cup \{\infty\}, \oplus, \odot)$：
- $a \oplus b := \min(a,b)$
- $a \odot b := a + b$
- 单位元：$0_\oplus = \infty$（加法单位），$1_\odot = 0$（乘法单位）

**直觉**：$\log$ 极限下的代数。设 $t \to 0^+$，则：
$$\lim_{t\to 0} \log_t (A(t) + B(t)) = \min(\lim \log_t A, \lim \log_t B).$$

## 2. 热带多项式与热带曲线

### 2.1 热带多项式

**定义 2.1**。热带多项式 $F(x_1,\ldots,x_n) = \bigoplus_{a \in A} c_a \odot x_1^{a_1} \odot \cdots \odot x_n^{a_n} = \min_{a \in A} (c_a + a_1 x_1 + \cdots + a_n x_n).$

**例**：$F(x,y) = 0 \odot x^2 \odot y^2 \odot (x+y+1)^2$ 对应 $(x,y) \mapsto \min(0, 2x, 2y, 2(x+y+1))$.

### 2.2 热带曲线

**定义 2.2**。热带曲线 $T_F = \{p : F \text{ is not smooth at } p\}$，即 $F$ 的**非光滑点集**（min 取等号的"脊线"）。

**性质**：
- $T_F$ 是 $\mathbb{R}^2$ 中的有限 graph（边为直线段，斜率由单项式指数决定）
- 顶点 valency $\geq 3$（平衡条件）
- 每条边有权重（整数）

### 2.3 平衡条件

**定理 2.1**（平衡 / Kirchhoff）。在顶点 $V$，令 $e_1,\ldots,e_k$ 是出射边，方向向量 $v_i$，权重 $w_i$。则：
$$\sum_{i=1}^k w_i v_i = 0 \quad (\text{在 } \mathbb{Z}^2 \text{ 中}).$$

**物理直觉**：热带曲线是"张力平衡"的弹簧网络。

## 3. Mikhalkin 对应定理

### 3.1 主定理

**定理 3.1**（Mikhalkin, 2005）。$\mathbb{CP}^2$ 中度 $d$ 的有理曲线数 $N_d$ 等于度 $d$ 的**平面热带曲线**的加权计数：
$$N_d = \sum_{h} w(h) \cdot \text{Mult}(h),$$
其中 $h$ 是满足平衡条件的 3-valent 树，$w(h)$ 是组合权重。

### 3.2 计算 $N_3$ 的热带方法

**步骤**：
1. 枚举所有度 3 的 3-valent 树（平面嵌入）
2. 对每棵树，计算 tropical curve 的 multiplicity
3. 求和得 $N_3 = 12$（与 Schubert 经典结果一致）

**关键优势**：将解析枚举转化为**有限组合穷举**。

### 3.3 更高维推广

**Block-Göttsche 不变量**：在 toric 曲面中，热带曲线计数给出"block counting"不变量，与 Gromov-Witten 不变量通过 mirror symmetry 关联。

## 4. Kapranov 定理与 Tropicalization

### 4.1 代数簇的热带化

**定义 4.1**。设 $X \subset (\mathbb{C}^*)^n$ 是代数簇，其 tropicalization 为：
$$\operatorname{Trop}(X) = \overline{\{\,(\log_t |x_1|,\ldots,\log_t |x_n|) : x \in X \cap (\mathbb{C}^*)^n, t \to 0\,\}}.$$

### 2.2 Kapranov 定理

**定理 4.1**（Kapranov）。若 $X$ 是 $(\mathbb{C}^*)^n$ 中的线性空间（通过原点的超平面 arrangement 的补），则 $\operatorname{Trop}(X)$ 是**Bergman 扇**（来自 matroid 的扇）。

**推论**：grassmannian 的 tropicalization 由 matroid polytope 描述。

### 4.3 热带交集理论

**定理 4.2**（Tropical Bézout）。在 $\mathbb{TP}^2$ 中，两条度 $d,e$ 的热带曲线相交于 $d \cdot e$ 个点（计重数），与经典 Bézout 定理一致。

## 5. 热带模空间

### 5.1 热带曲线模空间

**定义 5.1**。$\mathcal{M}_{g,n}^{\text{trop}}$ 参数化带 $n$ 个标记叶的抽象热带曲线（metric graph + 标记）。

**性质**：
- $\mathcal{M}_{g,n}^{\text{trop}}$ 是**多面体复形**（fan 的并）
- 有自然的形变-阻碍理论（类似于 algebraic $\overline{\mathcal{M}}_{g,n}$）
- 紧化由**稳定热带曲线**（叶加权 graph）给出

### 5.2 与代数模空间的比较

| 性质 | $\overline{\mathcal{M}}_{g,n}$ | $\mathcal{M}_{g,n}^{\text{trop}}$ |
|------|---------------------------|--------------------------------|
| 维数 | $3g-3+n$ | $3g-3+n$ |
| 紧化 | Deligne-Mumford | 稳定 graph |
| 边界 |  nodal curve | 边长度 $\to \infty$ |
| 层结构 | tautological | 类似（Cavalieri-Hampe） |

### 5.3 热带 Gromov-Witten 不变量

**定义 5.2**。热带 GW 不变量 = 热带曲线在 tropical toric 簇中的计数（带 evaluation map 约束）。

**定理 5.3**（Gathmann-Markwig）。热带 GW 不变量与经典 GW 不变量通过 tropicalization map 关联。

## 6. 热带 Brill-Noether 理论

### 6.1 热带线性系统

**定义 6.1**。热带除子 $D$ 是 $(C, \text{标记点集})$ 上的 integer-valued 函数（在边上 affine linear）。

**线性系统** $|D|^{\text{trop}}$ = 所有满足 $D' \geq D$ 的除子类。

### 6.2 热带 Riemann-Roch

**定理 6.1**（Gathmann-Kerber, 2008）。对热带曲线 $C$ 和除子 $D$：
$$r(D) - r(K_C - D) = \deg(D) + 1 - g,$$
其中 $r(D) = \dim |D|^{\text{trop}}$。

### 6.3 热带 Brill-Noether 定理

**定理 6.2**（Cools-Draisma-Payne-Robeva, 2012）。热带 Brill-Noether 定理成立：对一般热带曲线 $C$，$\dim W_d^r(C) = \rho(g,r,d) = g - (r+1)(g-d+r)$（当 $\rho \geq 0$）。

**意义**：这是代数几何中经典 Brill-Noether 定理的 tropical 类比，首次给出了**完全组合化**的证明。

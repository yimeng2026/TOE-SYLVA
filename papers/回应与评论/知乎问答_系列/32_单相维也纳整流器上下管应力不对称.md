# 单相维也纳整流器：两个 MOS 共用一个驱动、同开同关，为什么正半周只有上管"吃力"？

**一句话核心答案：因为"驱动信号"只决定两管什么时候开关，而"应力"取决于此刻有没有电流流过它、它被夹在什么电位之间——正半周电流只走上管通道，下管虽同步开通却被二极管/母线电位旁路或箝位，自然不显现应力；负半周角色互换。这是维也纳（Vienna）拓扑的固有特性，不是故障。**

---

## 一、先把拓扑画清楚

单相 Vienna 整流器本质是 **Boost 型三电平 PFC**。典型结构（以常见的共源极反串联双向开关为例）：

```
        D+                C+
  L ──┬──▶|──┬──────┬──────┤├── +Vbus/2
      │      │      │      │
 ～AC  │     Q1◄┐   │      ● O（母线中点）
      │      │ ├双向开关    │
      │     Q2 ◄┘   │      │
  L ──┴──|◀──┴──────┴──────┤├── −Vbus/2
        D−                C−
```

（示意：交流源经升压电感 L 后，一路经箝位二极管 D+/D− 分别接正/负母线；Q1、Q2 反串联构成**双向开关单元**，接在电感后与母线中点 O 之间，两管栅极共用一个驱动信号。各变种画法不同，请按你的板子对照。）

## 二、核心概念：驱动 ≠ 应力

这是解开疑惑的钥匙，必须先分清三件事：

- **驱动信号**：加到两管栅极的电压。共驱动意味着两管**栅极行为完全同步**——同开同关，没错。
- **电压应力（Vds）**：漏源之间承受的电压。取决于该管此刻是"阻断"还是"导通"、两端各是什么电位。
- **电流应力**：此刻是否有电流流经该管的沟道或体二极管。

**同开同关只约束了栅极，完全不约束漏源。** 管子开通后有没有电流走它，由外部电路的电流路径决定；管子关断后承受多高电压，由它被箝在哪个电位之间决定。

## 三、关键洞察：电流路径由交流电的瞬时极性决定

正半周期（交流电流方向为"进电感→指向母线侧"）：

- **开关 ON**：双向开关导通，电流经开关单元流入中点 O，电感 L 储能。此时电流确实流过开关单元——但反串联结构中，电流只走其中一只 MOS 的沟道（另一只管被其体二极管或沟道以很低压降伴随导通）。
- **开关 OFF**：电感电流不能突变，经上箝位二极管 D+ 换流流入正母线电容 C+，给母线充电（Boost 升压）。此时双向开关单元两端承受 +Vbus/2 的阻断电压——而这阻断电压**几乎全部落在其中一只 MOS 上**（下称"上管"），另一只（"下管"）被自身体二极管箝位在 ~1 V 量级的低压。

于是示波器上看到：**正半周，上管 Vds 是跟随驱动方波的高压应力波形；下管 Vds 常低**。驱动两管一模一样，应力天差地别。

## 四、负半周：完全镜像

负半周电流反向：OFF 态电流经下箝位二极管 D− 流入负母线，双向开关承受 −Vbus/2，此时**下管阻断全压、上管被箝位在低压**。

所以你观测到的"正半周上管吃力、负半周下管吃力"，角色精确互换、波形镜像对称——**这是拓扑决定的对称工作方式，完全正常**。

## 五、为什么"另一只"总是低？体二极管箝位机制

反串联（背对背）结构里有一个内禀性质：无论电流往哪个方向流，阻断电压总是由其中一只管承担，而另一只管的方向恰好使其**体二极管处于正偏（或被沟道旁路）**，把它的 Vds 箝位在：

$$|V_{ds}| \approx V_{f,\text{体二极管}} \approx 0.7\sim1.5\ \mathrm{V}\ (\text{Si MOS})$$

若该管此刻处于开通状态，箝位电压更低，只是 $I\cdot R_{ds(on)}$。这就是"应力常低"的物理来源：不是它没工作，而是它**被箝位在了低电位**，电压应力无从显现；它的电流应力也只在 ON 态电感储能阶段短暂出现。

换一个角度看：双向开关这个"单元"对外必须能双向阻断、双向导通，但**单元内部两管从来就是分工的**——一只管负责一个方向。共驱动只是工程上简化驱动的做法，并不改变内部分工。

## 六、注意事项与例外

1. **有些设计采用分半周驱动**（正半周只驱动一管、负半周驱动另一管，甚至两管各自独立 PWM）：那种设计下观测到的行为与共驱动不同，不要混淆。
2. **变种差异**：单相 Vienna 有共源反串联、共漏反串联、带整流桥式、无桥式等多种接法，两管的分工细节随接法而异。上面的分析以"共源反串联、双向开关接母线中点"为基准，**请按实际板子的拓扑逐管对照**。
3. **体二极管换流引起的尖峰**：OFF 瞬间体二极管反向恢复会在 Vds 上叠加尖峰，若你看到的"低应力管"上有细窄尖刺，多半是这个，也属正常（但需核算是否超器件额定）。
4. 若作者能提供实测波形图（Vds、电流、驱动三通道对照），可以进一步精确定位到具体管位与换流时刻。

## 七、用示波器验证的建议

1. 用**高压差分探头**分别量 Q1、Q2 的 Vds（切勿用普通无源探头直接跨接浮地管——会短路放炮）；
2. 用**电流探头**（或电流互感器）看开关单元支路电流；
3. 三通道 + 驱动信号同屏对照，验证以下判据：
   - 正半周 OFF 期：上管 Vds ≈ +Vbus/2 平台，下管 Vds ≈ 0（或 −1 V 左右）；
   - 负半周 OFF 期：两管波形镜像互换；
   - ON 期：两管 Vds 均接近零（导通压降）；
4. 若上述镜像关系成立，电路行为正常；若不成立（比如某管正负半周都扛压），再排查驱动、焊点与器件损坏。

## 八、常见误解

1. **"同开同关就应该承受同样的应力"**——混淆了栅极行为与漏源状态。驱动同步 ≠ 载流相同 ≠ 承压相同。
2. **"一管应力常低，说明驱动没送到/管子坏了"**——恰恰相反，这是该半周它被体二极管箝位的正常表现。
3. **"应力不对称是设计缺陷，要改对称"**——改不了也不必改，这是三电平 Vienna 拓扑的固有分工；真正要核算的是每只管在各自"值班半周"里的峰值电压、电流与损耗是否超额定。
4. **"两只 MOS 在单元里是并联关系"**——不是并联分流，而是反串联的双向开关，两只管各管一个电流方向。

## 结语

Vienna 整流器用一对共驱动的 MOS 实现双向开关，靠的不是两管"平起平坐"，而是**随交流极性自动换班**：正半周上管值班扛压，负半周下管值班扛压。你测到的应力不对称，正是这台拓扑机器在正确运转的指纹。

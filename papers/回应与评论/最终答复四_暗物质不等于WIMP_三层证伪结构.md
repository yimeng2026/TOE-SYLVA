## 二、概念澄清：三层命题，三种死法

"暗物质"这个词在实际科学使用中包含三个不同的命题，它们的证伪方式完全不同：

**L1（存在层）："宇宙中存在对引力有贡献但几乎不与光耦合的物质成分。"**
证据：旋转曲线、引力透镜、子弹星团、CMB 声学峰、结构形成、BBN——六条独立通道。**它的死法不是"某实验没找到粒子"，而是"出现一个不用任何新物质成分就能同时解释全部六条通道的理论"**（以太式死亡：死于冗余）。目前没有这样的理论；MOND 家族过不了 CMB+子弹星团。

**L2（成分层）："这种成分是 X。"**（X = WIMP / 轴子 / 原初黑洞 / 惰性中微子 / …）
每个 X 有自己的参数空间和死刑条款。**杀死 X 只杀死 X，不杀死 L1**——这就是我一直在说的"逐格行刑"的真实对象。LZ/XENONnT/PandaX 杀的是 L2 里的 WIMP，从来不是 L1。一个候选死了，L1 还在，候选者更替（历史上强作用重子暗物质就是这样死掉的）。

**L3（性质层）："这种成分只有引力，没有任何非引力相互作用。"**
这是你这一问的真正焦点。下面专门答。

你的批评"杀死 WIMP 不等于证伪暗物质"对 L1 完全成立——但请注意：**它从来没有被这样声称过。** 排除线画的是 L2 的版图，不是 L1 的。

## 三、答核心问题："只有引力、没有电磁作用"的暗物质，怎么证伪？

你说："它有没有弱相互作用都无所谓。"——言下之意，一个纯引力暗物质在粒子探测上永远无法证伪，所以不可证伪。

**恰好相反："只有引力"本身是一个可检验、可证伪的候选类（L3 候选），它自带一组专属预言：**

1. **无碰撞、无压、冷**。这决定小尺度结构：纯引力冷暗物质在矮星系中心形成尖峰（cusp），若观测到普遍的平核（core），纯 CDM 就需要额外物理（自相互作用/重子反馈）——这些替代机制各自又可证伪。
2. **与重子解耦**。子弹星团式的"质量-光偏移"是纯引力成分的身份证；如果暗物质与普通物质有任何可观测的非引力耦合，偏移不会那么干净。
3. **早期无自由流**。太轻的纯引力候选会被结构形成下限排除（warm/hot DM 的 Lyman-α 森林约束就是这么杀候选的）。
4. **无湮灭、无衰变信号**。间接探测（费米-LAT、AMS-02）对湮灭截面和寿命的限制同样适用于"纯引力"假设的检验——若有信号，L3 死；若永远无信号，L3 与观测相容，但不能说它"不可证伪"，因为上面 1-3 三条都在持续接受行刑。

**关键是：一个"纯引力"的暗物质，它的刑场不在液氙罐里，而在动力学与宇宙学里。** 它每一步都在被检验——只是检验者是星系巡天、CMB、Lyman-α 森林和引力透镜，而不是 LZ。可证伪性从粒子物理通道转移到了天体物理通道，并没有消失。

## 四、答逃生门："太阳系恰好没有暗物质"

这是全篇最精巧的一句，我必须给它最高礼遇：**它在逻辑上不可直接排除，但它有代价，而且代价可以用测量写出来。**

1. **本地密度不是"假设到处均匀"得来的。** 直接探测用的 ρ⊙ ≈ 0.3 GeV/cm³ 来自银河系动力学建模（旋转曲线 + 本地恒星计数 + 逃逸速度测量）——这些测量约束的是**引力势本身**，不预设暗物质存在。换句话说，我们是先量到了这里的引力，再问"它由什么组成"。你说"恰好没有"，那你需要先解释：为什么这个位置有引力却没有质量？
2. **"太阳系例外"需要新物理，而且是可以被检验的新物理。** 一个"别处有暗物质、太阳系没有"的宇宙，要求在 ~kpc 尺度上存在暗物质分布的巨洞或剧烈不均匀——这本身就是可观测的（引力透镜对银河系晕的层析、Gaia 对本地引力势的测量）。你没有给这个例外开免责权：它必须自己站出证据。
3. **奥卡姆的账。** "处处有、只是没发现"（一个假设）与"处处有、但这里恰好没有"（一个假设 + 一个特设补丁）之间，科学默认选前者，直到补丁自己带来预言。**逃生门不是免费的——每一扇都明码标价。**
4. **最后一层**：即使接受"太阳系恰好没有 WIMP"，那也只是本地条件问题，不影响 L2 版图上其他候选（轴子腔是共振扫描，对本地密度依赖弱得多；原初黑洞靠透镜与并合率）——更不会触碰 L1（六条通道里没有一条在太阳系内）。

所以这句话的正确翻译是：**"直接探测可能证伪不了我的本地版本"**——对，所以科学还准备了另外五个法庭。

## 五、最终结论：证伪结构的全图

把四轮合起来，这场辩论的最终答案是一张三层图：

```
L1 暗物质存在 ──死法── 出现一个无新物质却解释全部六通道的理论（以太式死亡）
   │   证据：旋转曲线/透镜/子弹星团/CMB/结构形成/BBN（六链联合）
   │
L2 成分是 X ──死法── X 的参数空间被扫完（WIMP 平面逐格行刑，正在进行）
   │   法庭：LZ/XENONnT/PandaX（散射）、ADMX/IAXO（共振）、LIGO/透镜（PBH）
   │
L3 只有引力 ──死法── 动力学与宇宙学联合绞杀（cusp-core/卫星计数/自由流/湮灭窗口）
       法庭：星系巡天/Lyman-α/费米-LAT/盖亚
```

- 你问"暗物质怎么证伪"——**看你想杀哪一层。** 每层都有指定的刽子手。
- 你说"杀死 WIMP 不等于证伪暗物质"——对，所以 WIMP 的死刑通知单上从来没写过"暗物质"三个字，写的是"WIMP"三个字。
- 你说"太阳系恰好没有"——门是开的，但门口挂着价签。

**这场辩论到这里，我们对"可证伪"的理解其实已经合流：一个理论可证伪，不是因为它有一个死刑按钮，而是因为它的每一个可存活版本都预登记了死法。** 暗物质研究现在有，而且正在执行。

你如果还要继续，下一层的入口只有两个：① 给出一个解释六条通道却不用新物质成分的理论（杀 L1）；② 给"太阳系恰好没有"找一个独立的观测预言（给你的逃生门补票）。这两个活儿，哪个成了，都是头条。

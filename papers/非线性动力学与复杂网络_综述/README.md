## 目录主题简介

**非线性动力学**是对确定性系统中不可预测行为的系统研究。20 世纪中叶，Lorenz（1963）在大气对流的简化模型中发现了决定性混沌——一个三维常微分方程组 $\dot{x}=\sigma(y-x),\ \dot{y}=x(\rho-z)-y,\ \dot{z}=xy-\beta z$ 在特定参数下产生的奇异吸引子（Lorenz 吸引子）成为混沌科学的标志。混沌的三个核心特征——对初值的敏感依赖（蝴蝶效应）、周期轨道稠密性与拓扑传递性——彻底动摇了 Laplace 的可预测世界观。

**分岔理论**（Bifurcation Theory）是理解非线性系统从有序到混沌过渡的工具。从 Logistic 映射 $x_{n+1}=rx_n(1-x_n)$ 的周期倍增分岔序列（Feigenbaum 常数 $\delta \approx 4.6692$ 揭示了双倍周期通向混沌的普适性规则），到 Hopf 分岔、鞍结分岔等工程应用中的常见模式，分岔理论为非线性动力学提供了数学骨架。

**复杂网络**则将非线性视角从单系统拓展到多体相互作用结构。Watts-Strogatz 小世界网络（small-world）、Barabási-Albert 无标度网络（scale-free，度分布 $P(k) \sim k^{-\gamma}$）等模型揭示了从互联网到社交网络、从代谢网络到神经网络共同遵循的结构规律——少数枢纽节点（hub）主导网络的连通性。

## 目录主题简介

**Fracton 相**（分形子相）是 2011 年由 Chamon（量子玻璃模型）和 Haah（立方码模型）独立引入的一类全新量子物相，其基本特点是：准粒子激发受到严格的运动学限制——它们要么完全无法移动、要么只能沿低维子流形（线、面）运动。这种"受限移动性"（Constrained Mobility）颠覆了常规拓扑序的"任意子编织"图像，植根于一类称为**高阶规范理论**（Higher-Rank Gauge Theory）的数学结构。

典型例子包括 Haah 的立方码（Cubic Code）：其中 Fracton 激发只能在分形子集上移动，导致基态简并度随系统尺寸呈对数-分形增长模式（$GSD \propto \exp(c L)$ 而非常规拓扑序的常数），这种"亚热力学"基态简并度直接提供了拓扑量子存储的错误纠正能力。Fracton 物相与引力中的"线性引力子"（Linearized Graviton）张量规范结构、全息对偶中的"张量网络"以及非厄米物理中的"趋肤效应"等方向存在深刻的交叉共鸣。

## 主题简介

神经流形几何（Neural Manifold Geometry）是计算神经科学与机器学习近年来的一个新兴交叉领域——它用微分几何和信息几何的工具研究**神经元群体活动所在的低维流形结构**。本综述从 TOE-SYLVA 框架出发，系统覆盖：神经流形的内在维度估计与拓扑数据分析、表示相似性矩阵（RSA）的几何解释、Fisher 信息度量在神经编码中的应用、以及表示动力学——即学习过程中神经流形几何的演化规律。

核心视角：将神经流形诠释为因果网络上的**信息表示子流形**——流形的曲率对应于信息表示的敏感性（Fisher 信息），流形的维度缩减对应于因果网络的粗粒化 RG 变换，而表示动力学的"解缠结"过程对应于因果网络上信息自由能的最小化。

这一视角与 TOE-SYLVA 框架下"几何深度学习与规范等变"形成自然的数学对偶：神经流形是表示空间的内部几何，而规范等变网络是表示变换的对称性约束。

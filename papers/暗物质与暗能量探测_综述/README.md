## 目录主题简介

**暗物质与暗能量**是当代物理学最深刻的谜题之一。根据 Planck 2018 数据，宇宙的能量-物质组成中约 26.4% 为暗物质、69.8% 为暗能量，而构成恒星、行星和所有可见物质的普通（重子）物质仅占约 4.8%。暗物质的引力效应在星系旋转曲线（$v_{rot} \approx \text{const}$ 而非 Kepler 衰减）、星系团碰撞（子弹星系团）、引力透镜以及宇宙微波背景（CMB）的声学峰功率谱中均有坚实证据。

暗能量的证据则主要来自 Ia 型超新星的距离-红移关系（1998 年 Nobel 奖发现宇宙加速膨胀）以及 CMB 的各向异性与 BAO（重子声学振荡）特征尺度的独立印证。暗物质候选粒子包括 WIMP（弱相互作用大质量粒子）、轴子（Axion）、惰性中微子等；暗能量候选方案则涵盖宇宙学常数（$\Lambda$）、quintessence 标量场、以及与引力修正理论（如 $f(R)$ 引力）相关的修改引力方案。

本综述系统梳理了直接探测（暗物质-核子散射）、间接探测（暗物质湮灭/衰变产物）和加速器探测（LHC 丢失能量）三条主线的现状与挑战。

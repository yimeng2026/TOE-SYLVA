## 摘要

知乎问答 18 把范畴论与集合论的关系裁定为"不是替代与超越，而是双重视角加双向翻译"，其中同伦类型论（HoTT）仅以一段带过。本文承接该判断并把它定理化、深化为五层原创结构。(i) **"类型 = 空间"的精确含义链条**：Martin-Löf 恒等类型的迭代塔给每个类型装备一个 Batanin–Leinster 弱 ω-广群结构——这一定理由 Lumsdaine（2009/2010）与 van den Berg–Garner（2011）独立证明，本文给出完整陈述与三环证明骨架（低阶路径代数本文手工、singleton 可收缩性本文手工、operad 作用归因原文；附录 B.1），语义侧登记 Awodey–Warren 的模型范畴解释与 Gambino–Garner 的恒等类型弱因子分解系统，并经 Grothendieck 同伦假设焊接为"类型（语法）— ∞-广群（代数）— 同伦型（拓扑）"三元对应（注 2.7、§6）。(ii) **Univalence 与外延性的张力定位**：给出 Voevodsky 单值公理的完整陈述与语义实现（Kapulkin–Lumsdaine 2021 单纯模型），并以手工演算（命题 3.7 + 附录 B.2：Bool 的自等价恰为两个且互异）证明 Ω(𝒰, Bool) 不是命题、宇宙不是集合——UIP/Axiom K 与 univalence 不相容，HoTT 的"相等"因此是**结构**（空间中的路径）而非**性质**；函数外延性与结构同一性原则（SIP）作为 univalence 的定理级推论登记。(iii) **h-level 层化宇宙**：types 按 h-level 严格分层（-2 可收缩 / -1 命题 / 0 集合 / 1 广群 / n 型），给出闭包定理（Π/Σ 封闭、宇宙自身升一级、截断泛性质）与层化塔（截断函子 ∥−∥ₙ = Postnikov 截断的类型内化），并与我方 CNF/谱序列层化框架建立对接表——h-level 提升 ⟺ 层化障碍不消失、k-不变量 ⟷ 延拓障碍（命题 4.5，猜想级登记）。(iv) **Cubical 计算化**：公理化 univalence 冻结计算（canonicity 失效）的缺陷由立方类型理论治愈——区间原语、Kan composition、Glue types 三件工具使 univalence 从公理变为**带计算规则的定理**（uaβ），canonicity 恢复（Huber 2019；Coquand–Huber–Sattler 2022），Cubical Agda 工程化后以 Brunerie 数的真实机器计算（Ljungström–Mörtberg 2023：π₄(S³) ≅ ℤ/2 的证明项真实算出 −2）演示 HoTT 从"能证明"到"能计算"的关键一跃。(v) **∞-范畴作为组织语言与集合论关系**：quasi-category 内角填充条件（Joyal 2002）、同伦假设的实现形态（Kan 复形 ⟷ 同伦型的 Quillen 等价）、四种模型的 Quillen 等价与唯一性定理（Barwick–Schommer-Pries）、HoTT 作为任意 ∞-topos 内语言（Shulman 2019）；§7 把与 ZFC 的关系表述为**双边嵌入**：一致性担保方向 ZFC+宇宙 ⊨ HoTT（单纯/立方模型），内部重建方向 HoTT 的 0-型集合层承载 ETCS 式数学且迭代层级 V 活在 HoTT 内部——知乎问答 18 结论的定理级升级。(vi) **物理接口**（§8）：规范场论的高阶同伦数据（主丛 = 到 BG 的映射、瞬子数 = π₄(BG)、θ 真空、BG 作为高阶归纳类型）、广义对称性（GKSW 2015：对称性 = 高群/∞-范畴数据）、高规范理论（Baez–Huerta 2011：弦的平行移动 = 2-丛和乐）与 cobordism hypothesis（Lurie 2009）；cohesive HoTT 纲领诚实登记为猜想级。(vii) **Lean 骨架**（§9，设计稿，未编译）：Lean 4 的 Eq 落入 Prop 且有定义级 proof irrelevance ⟹ UIP 在 Lean 中定义级成立——与 HoTT 的三重张力分析（诚实评估）、Lean 2 HoTT 模式史、G1–G4 债务分级。开放问题三条登记于 §10。全部断言按 proof_status 分层；查不到处一律标【待核】。

## 1 引言

### 1.1 问题的提出：相等到底是什么

20 世纪数学基础的标准答案由 ZFC 给出：对象是集合，相等由成员决定（外延公理），一切结构最终还原为 ∈-链。这套答案有两个结构性摩擦在现代数学中日益尖锐：**其一**，范畴论的工作语言天然把"同构"当作有效的相等（数学家在 Yoneda 之后不再区分同构的对象），而 ZFC 的同构 ⟹ 相等是假命题；**其二**，同伦论中对象的不变量全是同伦不变的（同调、上同调、同伦群），但在集合论语义下表达"同伦不变"需要逐条手工验证商结构/等价的良定义性——所谓"商地狱"（quotient hell）。同伦类型论给出第三条答案的候选：

> **(Q0) 能否建立一种数学基础，在其中 (a) 相等本身就是空间化的（两点间的"相等"是连接它们的路径，路径之间还有路径，以至无穷），(b) 同构 = 相等成为定理或公理，(c) 一切可表达构造自动等价不变，(d) 且全部定理可以在机器上执行？**

Q0 的四个子句各自对应本文的一条主线：(a) ⟹ §2（类型 = 空间的精确化）；(b) ⟹ §3（Univalence）；(c) ⟹ §4（h-level 层化宇宙与不变性元定理）与 §7（与 ZFC 的关系）；(d) ⟹ §5（Cubical 计算化）与 §9（Lean/Cubical Agda 现状）。§6 与 §8 分别给出 ∞-范畴的组织语言层与物理接口层。

### 1.2 历史层位

HoTT 的历史有五个清晰层位。**类型论层（1971–1984）**：Martin-Löf 建立直觉主义类型论 [1]，恒等类型（identity type）带消去子 J；外延版（equality reflection）与内延版（intensional）分裂。**广群层（1994–1998）**：Hofmann–Streicher 构造广群模型 [2][3]，证明恒等证明唯一性（UIP）独立于内延类型论——"相等有内容"第一次成为定理级现象。**同伦语义层（2005–2010）**：Awodey–Warren [5] 与 Warren 的博士论文 [10] 把恒等类型解释为模型范畴中的 path object；Gambino–Garner [4] 证明恒等类型自身生成弱因子分解系统；Lumsdaine [6][7] 与 van den Berg–Garner [8] 各自独立证明：迭代恒等类型塔给每个类型装备弱 ω-广群结构——"类型 ⟹ ∞-广群"成为定理。**单值基础层（2009–2013）**：Voevodsky 提出 univalence 公理与单纯集模型纲领 [11]，发起 UniMath [17]；Kapulkin–Lumsdaine 完成单纯模型的完整证明 [12]（2012 预印，2021 JEMS 正式发表）；2012–2013 年 IAS 特别年产出 HoTT book [13]。**计算化层（2013–2023）**：Bezem–Coquand–Huber 的立方集模型 [20]、CCHM 立方类型理论 [21] 使 univalence 获得计算规则；Huber [22] 恢复 canonicity；Cubical Agda [25] 工程化；Brunerie 数的机器计算 [32] 标志可执行合成同伦论落地。平行地，∞-范畴的组织语言由 Joyal [35]、Lurie [40] 建立，与 HoTT 的双向接口（HoTT = ∞-topos 内语言）由 Shulman [45] 推进到定理级。

## 2 类型 = 空间：恒等类型的 ∞-广群结构

### 2.1 恒等类型与消去子 J

**定义 2.1（Martin-Löf 恒等类型）**【标准定义，[1][13]】

内延类型论中，对每个类型 $A$ 与 $x,y:A$，有**恒等类型** $x =_A y$（记 $\mathrm{Id}_A(x,y)$）：唯一构造子 $\mathsf{refl}_x : x =_A x$；消去子 $J$：对任意依赖类型族
$$C : \prod_{(x,y:A)}\big(x =_A y\big) \to \mathcal U,\qquad d : \prod_{(x:A)} C(x,x,\mathsf{refl}_x),$$
给出 $J(C,d) : \prod_{(x,y:A)}\prod_{(p : x = y)} C(x,y,p)$，并有计算规则 $J(C,d,x,x,\mathsf{refl}_x) \equiv d(x)$（定义式相等）。读法：要证所有恒等证明 $p$ 上的性质，只需对 $\mathsf{refl}$ 证——"恒等类型由 refl 自由生成"。

**定义 2.2（路径代数的基本运算）**【标准构造，[13] §2.1】

由 $J$ 定义（约定：复合 $p\cdot q$ 对第二变量归纳）：
- **逆**：$p^{-1} : y =_A x$（对 $p : x = y$ 归纳，$\mathsf{refl}^{-1} \equiv \mathsf{refl}$）；
- **复合**：$p \cdot q : x =_A z$（对 $q : y = z$ 归纳，$p \cdot \mathsf{refl} \equiv p$ 定义式成立）；
- **作用**：$\mathsf{ap}_f(p) : f(x) =_B f(y)$；**输运**：$\mathsf{transport}^P(p) : P(x) \to P(y)$（$P : A \to \mathcal U$）。

**引理 2.3（路径代数的低阶凝聚）**【已证（本文手工，附录 B.1）；标准结果 [13] §2.1】

对所有适配的路径 $p,q,r$：
$$\text{(a)}\ \mathsf{refl}\cdot p = p,\qquad \text{(b)}\ (p\cdot q)\cdot r = p\cdot(q\cdot r),\qquad \text{(c)}\ p\cdot p^{-1} = \mathsf{refl},\ p^{-1}\cdot p = \mathsf{refl}.$$
关键读法：这些等式**本身是高阶恒等类型的居民**（如 (b) 的类型是 $(p\cdot q)\cdot r = p\cdot(q\cdot r)$，非定义式相等），且它们之间仍有更高阶凝聚（结合律证明的五角形凝聚等）——相等结构不是 1-广群法则，而是无穷塔。

### 2.2 UIP 的独立性与同伦语义

**定理 2.4（Hofmann–Streicher 广群模型）**【文献已核：[2][3]】

存在以广群为类型的模型（类型 ⟹ 广群、依赖类型 ⟹ 广群族/纤维化、恒等类型 ⟹ 广群内对象的同构集），其中存在类型含两个互不相等的恒等证明。推论：UIP（uniqueness of identity proofs："所有 $p,q : x = y$ 满足 $p = q$"）独立于内延 Martin-Löf 类型论——"相等有内容"不与类型论矛盾。

**定理 2.5（Awodey–Warren：恒等类型的同伦解释）**【文献已核：[5]；加强 [9]；WFS 形态 [4]】

(a) 在任何 Quillen 模型范畴（更精细地，带适当 Frobenius 条件的弱因子分解系统）中可解释内延恒等类型：类型 ⟹ fibrant 对象、恒等类型 ⟹ path object（对角映射 $X \to X\times X$ 的"平凡余纤维化—纤维化"因子化 $X \to X^I \to X\times X$）。
(b) Gambino–Garner [4]：恒等类型的类自身生成了一个弱因子分解系统，其全部构造由 $J$ 驱动——"J = 同伦提升性质"获得纯代数表述。
(c) 在拓扑空间模型中：$\mathsf{refl}$ ⟹ 常路径、$J$ ⟹ 基于路径空间的可收缩性；类型论的同伦语义成立。

### 2.3 主定理：每个类型是弱 ω-广群

**定理 2.6（Lumsdaine 与 van den Berg–Garner 独立证明）**【严格论证（骨架，各环归因）；文献已核：[6][7][8]】

设 $A$ 为内延 Martin-Löf 类型论中任一类型。则迭代恒等类型塔
$$A,\quad \mathrm{Id}_A,\quad \mathrm{Id}_{\mathrm{Id}_A},\quad \cdots$$
承载典范的 **Batanin–Leinster 弱 $\omega$-范畴结构**，且其全部 $k$-胞（$k\ge 1$）可逆——即**弱 $\omega$-广群**。

**证明骨架（三环分解）。**

*环 1（低阶运算与凝聚）*。$J$ 给出单位（refl）、逆、复合与低阶凝聚等式（引理 2.3，本文手工 B.1）；这些运算的全局定义不依赖 $A$ 的任何假设——纯由恒等类型的泛性质供给。

*环 2（singleton 可收缩性与收缩传播）*。关键引理【本文手工 B.1】：对任意 $x : A$，**singleton 类型** $\sum_{(y:A)} (x = y)$ 可收缩（中心 $(x,\mathsf{refl}_x)$；对任意 $(y,p)$，由 $J$ 得 $(y,p) = (x,\mathsf{refl}_x)$）。收缩性经 $J$ 沿塔传播：任意"两端自由的恒等类型图"都可填充——这正是 globular 凝聚数据在任意维度的存在性。

*环 3（operad 作用）*。Batanin–Leinster 定义：弱 $\omega$-范畴 = 通用**收缩 globular operad** $P$ 的代数。环 2 归纳地给出从 $A$ 的恒等塔到 $P$-代数结构的映射（每个 operad 运算对应一个可由收缩性填充的语境图）；可逆性由 $p^{-1}$ 及其全部高阶类似物给出（同一 $J$-归纳）。operad 的精确构造、凝聚的唯一性层次与"弱"的精确定价以 [6]（语法/operad 路线）、[7]（期刊版）、[8]（类型论内部定义 ω-范畴的路线）为准。$\square$

**注 2.7（"类型 = 空间"的精确含义，三元对应）**【元定理·组装】

定理 2.6 是语法侧结论。语义侧，拓扑空间 $X$ 的**基本 ∞-广群** $\Pi_\infty(X)$（0-胞 = 点、1-胞 = 连续路径、2-胞 = 端点固定的路径同伦、$k$-胞 = 高阶同伦）承载同一结构；两者的焊接是 Grothendieck 同伦假设（§6 定理 6.3 的实现形态）。于是"类型 = 空间"不是比喻，而是三元对应：

$$\underbrace{\text{类型（语法）}}_{\text{定理 2.6}}\ \simeq\ \underbrace{\infty\text{-广群（代数）}}_{\text{Batanin–Leinster}}\ \simeq\ \underbrace{\text{同伦型（拓扑）}}_{\text{同伦假设}}$$

每个等号都是定理（或其实现形态），分别由 [6][7][8]、§6 [42][43][44] 归因。

## 3 Univalence：同构 = 相等的原则化

### 3.1 公理的陈述

**定义 3.1（同伦等价）**【标准，[13] Ch.4】。映射 $f : A \to B$ 是**等价**（$\mathsf{isEquiv}\,f$）取下列互相等价的定义之一：可收缩纤维（$\prod_{(b:B)} \mathsf{isContr}\,\mathsf{fib}_f(b)$）、双边可逆（bi-invertible）、半伴随等价。$A \simeq B := \sum_{(f : A \to B)} \mathsf{isEquiv}\,f$。定理（[13] Ch.4 口径）：$\mathsf{isEquiv}\,f$ 本身是命题——"是等价"是性质而非额外结构【文献已核】。

**定义 3.2（idtoeqv）**。由 $J$：对宇宙 $\mathcal U$ 中 $A, B : \mathcal U$，$p : A =_{\mathcal U} B$ 经 transport 给出等价 $\mathsf{idtoeqv}(p) : A \simeq B$；即 $\mathsf{idtoeqv} : (A =_{\mathcal U} B) \to (A \simeq B)$。

**公理 3.3（Univalence，Voevodsky）**【[11][13]】

$\mathsf{idtoeqv}$ 是等价；记其逆 $\mathsf{ua} : (A \simeq B) \to (A =_{\mathcal U} B)$。等价陈述：$(A =_{\mathcal U} B) \simeq (A \simeq B)$——**类型间的相等恰是等价**。推论形态：等价类型可以互相替换（transport 沿 $\mathsf{ua}\,e$ 与 $e$ 一致——公理形态下此计算规则仅命题式成立，即 §5.1 要治愈的缺陷）。

### 3.2 语义实现与一致性

**定理 3.4（单纯集模型，Voevodsky 纲领的完整证明）**【文献已核：[11][12][16]】

单纯集范畴 $\mathrm{sSet}$（Kan–Quillen 模型结构）中，泛 Kan 纤维化给出 univalent 宇宙；宇宙层级由 Grothendieck 宇宙/不可达基数供给。Voevodsky 的原始论证（[11]，2010 CMU 讲义）由 Kapulkin–Lumsdaine 补全为完整发表的证明 [12]（JEMS 2021；2012 预印本 arXiv:1211.2851）。Streicher 讲义 [16] 给出教学化表述。

**推论（一致性强度）**【严格论证（组装）】$\mathrm{Con}(\mathrm{ZFC} + \text{可数多个不可达基数}) \Longrightarrow \mathrm{Con}(\mathrm{MLTT} + \mathrm{UA} + \text{宇宙层级})$。HoTT 的一致性目前完全由集合论语义担保——这是 §7 双边嵌入的第一方向。

### 3.3 定理级推论

**命题 3.5（univalence ⟹ 函数外延性）**【文献已核：[13] §4.9；骨架归因】

路线：univalence ⟹ weak function extensionality（命题的 Π 是命题 / 可收缩类型的 Π 可收缩）⟹ 一般 funext：$f \sim g$（逐点相等）⟹ $f = g$。骨架：逐点相等给出 $f, g$ 共同的"可收缩对角"，经 univalence 把依赖函数的恒等化约为值的恒等；细节以 [13] §4.9 为准。

**命题 3.6（结构同一性原则 SIP）**【文献已核·元陈述】

对标准数学结构（幺半群/群/环/偏序/拓扑空间），**结构同构 ⟹ 类型相等**：[13] §9.8 给出代数结构的 SIP；范畴情形要求范畴本身 univalent（同构 ⟺ 对象相等）——univalent categories 与 Rezk completion [18] 给出一般构造。含义：在单值基础上，"同构的数学结构可互换使用"从工作纪律变为定理。

### 3.4 与外延性传统的张力：手工演算定位

**命题 3.7（UIP 与 univalence 不相容，精确定位）**【已证（本文手工，附录 B.2）；[13] Example 3.1.9】

(a) $\mathrm{Bool} \simeq \mathrm{Bool}$ 恰含两个元素（$\mathsf{id}$ 与 $\mathsf{not}$），且 $\mathsf{id} \neq \mathsf{not}$（构造子判别性：$\mathsf{true} \neq \mathsf{false}$）。
(b) 由 univalence：$(\mathrm{Bool} =_{\mathcal U} \mathrm{Bool}) \simeq (\mathrm{Bool} \simeq \mathrm{Bool})$，故 $\mathrm{Bool} =_{\mathcal U} \mathrm{Bool}$ 不是命题。
(c) 推论：宇宙 $\mathcal U$ 不是集合；UIP（等价地 Axiom K）与 univalence 不相容。

**定位**。HoTT 保留 $J$、拒绝 $K$：相等是**结构**（类型作为空间时，$x = y$ 是路径空间）而非**性质**。与两种外延性传统的关系：ZFC 外延公理（相等由成员决定，相等本身是命题）在 HoTT 的 0-型（集合）层成立（§7）；Martin-Löf 外延类型论的 equality reflection（命题相等 ⟹ 定义相等）则强到使恒等类型塌缩，与 HoTT 根本不相容【元定理·组装】。

**注 3.8（与排中律/选择公理）**【文献已核，[13] §3.4、Ch.10 口径】。univalence 与**朴素**排中律（"每个类型要么有居民要么为空"的强形式）矛盾；与命题截断形式的 LEM（仅对 -1 型排中）及选择公理相容。HoTT 因此不强迫构造主义，但把排中律的使用范围精确化到命题层。

## 4 h-level 层化宇宙

### 4.1 定义与前三级

**定义 4.1（h-level，Voevodsky）**【标准定义，[13] Ch.7】

$$\mathsf{isContr}\,A := \sum_{(a:A)} \prod_{(x:A)} (a = x);\qquad \mathsf{isOfHLevel}\,0\,A := \mathsf{isContr}\,A;\qquad \mathsf{isOfHLevel}\,(n{+}1)\,A := \prod_{(x,y:A)} \mathsf{isOfHLevel}\,n\,(x = y).$$
别名表（HoTT book 的 $n$-型编号，$-2$ 起）：$-2$ 型 = 可收缩；$-1$ 型 = **命题**（$\mathsf{isProp}$）；$0$ 型 = **集合**（$\mathsf{isSet}$）；$1$ 型 = **广群**；一般 $n$ 型 = "$n$ 阶以上同伦平凡的类型"。

**引理 4.2（前三级的手工刻画）**【已证（骨架，附录 B.3）；标准结果 [13] §3.3】

(a) $\mathsf{isProp}\,A \iff \prod_{(x,y:A)} (x = y)$（任意两点相等）；
(b) $\mathsf{isContr}\,A \Rightarrow \mathsf{isProp}\,A \Rightarrow \mathsf{isSet}\,A \Rightarrow \cdots$（层化单调：$n$-型是 $(n{+}1)$-型）；
(c) $\mathsf{isProp}\,A$ 本身是命题（需 funext，命题 3.5）。

### 4.2 闭包定理与截断

**定理 4.3（h-level 的闭包性质）**【文献已核 [13] Ch.7 + 手工骨架 B.3】

(a) **Π-封闭**：若每个 $B(x)$ 是 $n$-型，则 $\prod_{(x:A)} B(x)$ 是 $n$-型（$n \ge -1$ 处需 funext；$n=-1$ 的手工骨架见 B.3）；
(b) **Σ-封闭**：$A$ 与每个 $B(x)$ 是 $n$-型 ⟹ $\sum_{(x:A)} B(x)$ 是 $n$-型；
(c) 等价保持 h-level；
(d) $n$-型的宇宙 $\mathcal U_{\le n}$ 自身是 $(n{+}1)$-型（需 univalence）；
(e) **截断**：对每个 $A$ 存在高阶归纳类型 $\|A\|_n$（$n$-截断），它是 $n$-型，并有泛性质 $\mathsf{Map}(\|A\|_n, B) \simeq \mathsf{Map}(A, B)$（$B$ 为 $n$-型）。

### 4.3 层化塔与 Postnikov 对应

**命题 4.4（层化宇宙塔）**【严格论证（组装）】

(a) 嵌入链 $\mathcal U_{\le -1} \subseteq \mathcal U_{\le 0} \subseteq \mathcal U_{\le 1} \subseteq \cdots \subseteq \mathcal U$；截断 $\|{-}\|_n : \mathcal U \to \mathcal U_{\le n}$ 是反射（localization/modality），构成类型论内部的 Postnikov 塔。
(b) 语义对应：空间的 Postnikov 截断 $\tau_{\le n}X$（杀死 $\pi_{>n}$）在同伦语义下恰是 $n$-截断——命题层截断 $\|{-}\|_{-1}$ 即 $\tau_{\le 0}$（只留"是否非空"）。
(c) 实例谱：$\mathbb N$ 是集合（且非可收缩）；$S^1$ 是 1-型而非集合（$\Omega S^1 = \mathbb Z$ [28]）；$S^2$ 不是任何有限 $n$-型（$\pi_3(S^2) = \mathbb Z$ 及更高非平凡同伦群；HoTT 侧 [13] Ch.8 与 [30] 的同伦群计算，机器侧 [32]）。

### 4.4 与我方 CNF/谱序列层化的对接（接口猜想）

**命题 4.5（层化对接表，接口猜想）**【猜想·接口设计稿】

12 号把谱序列表述为层化推理引擎（提炼算子的页序列：子商单调 + 微分障碍 + $RE_\infty$ 判据）；h-level 层化是同伦侧的层化（截断单调 + 高阶凝聚障碍）。对接表：

| 层 | 页 $E_r$（子商链） | 截断 $\Vert A\Vert_n$（商型链） |
| 障碍 | 微分 $d_r \ne 0$、延拓问题 | $A$ 是 $(n{+}1)$-型而非 $n$-型（$\pi_{n+1} \ne 0$） |

## 5 Cubical 计算化：从公理到定理

### 5.1 公理化 univalence 的计算缺陷

**问题 5.1（canonicity 失效）**【文献已核·问题定位】

$J$ 的计算规则只在 $\mathsf{refl}$ 上触发；$\mathsf{ua}$ 供给的非 $\mathsf{refl}$ 路径上 $J$ **卡住**：存在闭项 $t : \mathbb N$（含 $\mathsf{ua}$ 的证明项）不规约到数字。book HoTT 形态的 univalence 因此"能证明、不能计算"——证明助手中所有用到 univalence 的定义都冻结。Voevodsky 提出 univalence 时即把计算性列为核心未决问题。

### 5.2 三件工具：区间、Kan composition、Glue

**定义 5.2（区间与路径类型）**【标准，[21][25]】

立方类型理论引入原语**区间** $\mathbb I$（de Morgan 代数：$0,1,r\wedge s,r\vee s,1-r$），路径类型
$$\mathsf{Path}\,A\,a\,b := \{\, f : \mathbb I \to A \mid f\,0 \equiv a,\ f\,1 \equiv b \,\}\qquad(\text{端点为定义式相等}).$$
$\mathsf{refl} := \lambda i.\,a$；逆 $:= \lambda i.\,p\,(1-i)$；复合由 Kan 运算供给。$J$ 成为**定理**（基于路径空间由 $\mathsf{hcomp}$ 收缩），不再需要公理地位。

**定义 5.3（Kan composition）**【标准，[21]】

对类型线 $A : \mathbb I \to \mathcal U$ 与**开口盒子**（由 cofibration 公式 $\varphi$ 给定的部分立方：$n{+}1$ 个面中的 $n$ 个），$\mathsf{comp}$ 给出缺失面的填充，且填充在开口处定义式吻合；$\mathsf{hcomp}$ 为 $A$ 常值的特例。fibrancy：$\mathcal U$ 中每个类型带 composition 结构（对类型构造子逐条归纳；宇宙本身由 Glue 处理）。

**定义 5.4（Glue types）**【标准，[21]】

给定公式 $\varphi$、部分类型 $T$（$\varphi$ 处）与等价 $e : T \simeq A$，$\mathsf{Glue}\,[\varphi \mapsto (T,e)]\,A$ 为类型：$\varphi$ 处定义式等于 $T$，$\neg\varphi$ 处等于 $A$。$\mathsf{ua}$ 的构造（对 $e : A \simeq B$）：
$$\mathsf{ua}\,e : \mathsf{Path}\,\mathcal U\,A\,B := \lambda i.\ \mathsf{Glue}\,\big[(i{=}0) \mapsto (A,e),\ (i{=}1) \mapsto (B,\mathsf{idEquiv})\big]\,B,$$
端点定义式吻合：$i=0$ 处 $\equiv A$，$i=1$ 处 $\equiv B$。

### 5.3 univalence 定理化与 canonicity 恢复

**定理 5.5（univalence 从公理到定理）**【文献已核：[21]】

CCHM 立方类型理论中：(a) univalence 成立——由 Glue 的存在性与宇宙的 Kan 结构，是**定理**而非公理；(b) $\mathsf{ua}$ 有**计算规则** $\mathsf{ua}\beta$：沿 $\mathsf{ua}\,e$ 的 transport 定义式地由 $e$ 给出（$\mathsf{transp}\,(\mathsf{ua}\,e)\,a$ 规约为 $e\,a$ 的强形式）；(c) 函数外延性与 SIP（命题 3.5–3.6）随之获得计算内容。

**定理 5.6（canonicity 恢复）**【文献已核：[22][23]】

Huber [22]（JAR 2019）：CCHM 立方类型理论满足 canonicity——每个闭项 $t : \mathbb N$ 规约到数字；Coquand–Huber–Sattler [23]（LMCS 2022）强化到 homotopy canonicity。问题 5.1 被治愈：univalence 从"冻结计算的公理"变为"参与计算的构造"。

### 5.4 语义与实现

**定理 5.7（立方集模型）**【文献已核：[20]】

Bezem–Coquand–Huber：类型论在立方集（de Morgan 立方范畴上的预层范畴）中的**构造性**模型，univalence 在其中成立；模型可在构造性集合论（CZF 级）中叙述——HoTT 的语义不强迫经典元理论。

**实现 5.8（Cubical Agda 与 Brunerie 数）**【文献已核】

Cubical Agda [25]（Vezzosi–Mörtberg–Abel，ICFP 2019；JFP 2021 期刊版）把 de Morgan 立方类型理论工程化为编程语言；cartesian 变体 [26][27]（Angiuli 等 2021；Cavallo–Harper 2019；RedPRL/cooltt 传统）；高阶归纳类型的系统语法 [24]（Coquand–Huber–Mörtberg，LICS 2018）。标志性机器计算：Ljungström–Mörtberg [32]（LICS 2023）在 Cubical Agda 中把 Brunerie 数（$\pi_4(S^3) \cong \mathbb Z/n\mathbb Z$ 的证明中出现的整数 $n$ [30]）**真实计算到 $-2$**——公理化 HoTT 时代的"不可计算对象"在 cubical 时代成为可执行。

**诚实边界 5.9**。立方化不是"无公理证明 univalence"：它给出带计算规则的**构造**，一致性仍由立方集语义担保（[20]）；de Morgan 与 cartesian 立方的理论差异（连接/对角结构）如实登记；HIT 的一般语法理论以 [24] 为准，本文不展开。

## 6 ∞-范畴作为组织语言

### 6.1 quasi-category：弱化的范畴

**定义 6.1（quasi-category）**【标准，[34][35][40]】

单纯集 $X$ 是 **quasi-category**（弱 Kan 复形，Boardman–Vogt 1973 [34] 的 weak Kan complex）：所有**内角** $\Lambda^n_k \subseteq \Delta^n$（$0 < k < n$）都有填充：
$$\forall\, \Lambda^n_k \to X\ (0<k<n),\quad \exists\, \Delta^n \to X\ \text{扩张}.$$
读法：0-单形 = 对象；1-单形 = 态射；内 2-角的填充 = 复合（非唯一，但填充空间可收缩——"复合在同伦下唯一"）；高维单形 = 凝聚数据。等价 = 在同伦范畴中成为同构的 1-单形。

**例 6.2（例链）**【文献已核】。(a) 普通范畴 $\mathcal C$ 的神经 $N(\mathcal C)$ 是 quasi-category（内角**唯一**填充）——范畴 ⊂ ∞-范畴；(b) **Kan 复形**（所有角含外角可填）= ∞-广群（所有态射可逆）；(c) 拓扑空间 $X$ 的奇异单纯集 $\mathrm{Sing}(X)$ 是 Kan 复形——"每个空间给出一个 ∞-广群"。

### 6.2 Grothendieck 同伦假设：从猜想到定理

**定理 6.3（同伦假设的实现形态）**【文献已核；诚实区分纲领与定理】

(a) **Quillen 等价**：几何实现与奇异函子 $|{-}| : \mathrm{sSet} \rightleftarrows \mathrm{Top} : \mathrm{Sing}$ 是模型范畴的 Quillen 等价（Kan–Quillen 模型结构；Milnor/Quillen 传统，标准教材口径）；故 $\mathrm{ho}(\text{Kan 复形}) \simeq \mathrm{ho}(\text{CW 复形})$——"∞-广群模型化全部同伦型"在 Kan 复形/quasi-category 模型中是**定理**。
(b) **原始纲领**：Grothendieck《Pursuing Stacks》（1983 手稿 [42]）的**同伦假设**猜想：他定义的 ∞-广群（globular 形态）范畴等价于同伦型范畴；Maltsiniotis [43]（Astérisque 301，2005）整理其同伦论纲领并证明测试范畴形态的关键定理；Cisinski [44]（Astérisque 308，2006）证明预层范畴模型化同伦型的一般判据——Grothendieck 自己定义的形态由这条路线推进。
(c) 本文使用口径：凡断言"∞-广群 = 同伦型"，均指 (a) 的已实现形态；(b) 的 globular 精确形态如实登记为文献推进中。

### 6.3 模型的等价与唯一性；Lurie 的组织化

**定理 6.4（(∞,1)-范畴概念的模型无关性）**【文献已核】

quasi-categories（Joyal 模型结构，[35]；Joyal–Tierney 与 Segal 空间的比较 [36]）、complete Segal spaces（Rezk [37]）、Segal categories 与单纯充实范畴（Bergner 综述 [38]）两两 Quillen 等价；Barwick–Schommer-Pries [39] 证明**唯一性定理**：满足四条公理的 (∞,1)-范畴同伦理论在同伦下唯一——"∞-范畴"是稳定概念，不依赖模型选择。

**定理 6.5（∞-topos 与内语言对应）**【文献已核；定理与纲领分层】

(a) Lurie《Higher Topos Theory》[40]（2009）：∞-topos = ∞-层（满足 descent 的 ∞-presheaf）的理论，是 1-topos 理论的同伦化；(b) Shulman [45]（2019）：每个 (∞,1)-topos 都可由解释带严格 univalent 宇宙的 HoTT 的模型范畴表示 ⟹ **HoTT 可充当任意 ∞-topos 的内语言**（恰如高阶逻辑之于 1-topos）；(c) 反方向（语法的语义完备性）与 elementary ∞-topos 的公理化：纲领级，登记为开放问题 1 的语境。

**注 6.6（组织语言功能）**【文献已核·登记】。同伦（余）极限、导出函子、稳定 ∞-范畴（谱与导出代数几何的基座，Lurie《Higher Algebra》[41]）、∞-operad；我方 `framework/28_category_theory_layered.md` 的"层 → ∞-层"层化纲领在此获得定理后盾（28 号的关键词表已含"同伦类型论"，本文兑现该入口）。教材级参考：Riehl–Verity《Elements of ∞-Category Theory》[46]（模型无关的 formal 路线）。本文不重复其系统展开。

## 7 与集合论的关系：双边嵌入

**命题 7.1（正向：ZFC 语义担保 HoTT）**【严格论证（组装，定理 3.4 的推论）】

$\mathrm{Con}(\mathrm{ZFC} + \text{可数多个不可达基数}) \Rightarrow \mathrm{Con}(\mathrm{HoTT} + \mathrm{UA} + \text{宇宙})$。HoTT 的一致性目前**完全由集合论语义担保**（单纯模型 [12]；立方模型的构造性变体 [20] 可降低元理论强度——如实登记为构造性路线）；HoTT 在自身内部构造自身模型（自举）未完成【诚实登记】。

**命题 7.2（反向：ZFC 数学活在 HoTT 内部）**【文献已核】

(a) **集合层**：0-型（isSet 类型）在 HoTT 内部构成 ΠW-pretopos（Rijke–Spitters [19]），日常数学可在集合层按 ETCS 式（Lawvere [47]，PNAS 52(6):1506–1511——知乎问答 18 的页码待核条目本文已清偿）重建；
(b) **迭代层级**：HoTT 内部可用高阶归纳类型构造 Zermelo 式累积层级 $V$，$V$ 满足（无选择的）ZFC 变体公理——iterative sets 模型 [48]（arXiv:2402.04893，2024；"ZFC 的模型活在 HoTT 内部"）。

**命题 7.3（双边嵌入元定理；知乎问答 18 的定理级升级）**【元定理·组装，各分量逐条归因】

知乎问答 18 的"双重视角 + 双向翻译"判断可升级为三条定理级陈述：
(i) **语义担保方向**：ZFC + 宇宙 $\models$ HoTT（单纯/立方模型，命题 7.1）；
(ii) **内部重建方向**：HoTT 的集合层与迭代层级承载 ZFC 数学（命题 7.2）；
(iii) **不可消除的依赖**：宇宙假设在两侧同现——univalent 宇宙需要与 Grothendieck 宇宙同型的基数假设（知乎 18 第三节"范畴论向集合论借宇宙"的反讽在 HoTT 中原样重现）。
故"HoTT 替代 ZFC"不成立（与知乎 18 一致）；但"**HoTT 是同伦数学的原生基础**"成立：等价不变性在 HoTT 中是**元定理**（一切可定义概念自动尊重 $\simeq$——由 univalence 与 transport），在 ZFC 中是工作纪律。关系表述：**不是替代而是新视角；视角的优势领域是同伦不变的数学**。

**注 7.4（与 ETCS 的层位比较）**。Lawvere 1964 [47] 把集合论范畴化（1-层）：元素 = 终对象出发的箭头。HoTT 把同一纲领推到 ∞-层：对象 = 类型 = ∞-广群，点 $x : A$ 语法上是项、语义上是 $1 \to A$，相等 = 路径。ETCS 说明"无元素基础"可行；HoTT 说明"无外延相等基础"可行且对同伦数学更优【元定理·组装】。

## 8 物理接口：高阶同伦信息的位置

**命题 8.1（规范场论 = 高阶同伦数据的经典层）**【文献已核·组装】

(a) **主丛分类**：主 $G$-丛 $\leftrightarrow$ 同伦类 $[M, BG]$（分类定理；Milnor 泛丛构造 [59]）；
(b) **瞬子扇区**：$S^4$ 上 $SU(2)$-丛由 $\pi_4(BSU(2)) = \pi_3(SU(2)) = \mathbb Z$ 分类（第二陈数 = 瞬子数）；拓扑项与 $\theta$ 真空 = 对 $\pi_3(G)$ 的响应（标准物理口径）；
(c) **HoTT 内化**：$BG$ 是高阶归纳类型——单基点、$\Omega BG = G$ 的类型；高群（higher groups）作为带凝聚结构的类型已在 HoTT 内部定义 [31]（Buchholtz–van Doorn–Rijke，LICS 2018）；主 $G$-丛 = 映射 $M \to BG$ 在类型论中是**原生定义**。
物理读法：**规范等价 = 同一**——规范相关的场构型是构型 ∞-广群中同一条路径连接的两点，这正是 univalence"等价 = 相等"的物理化身【组装级陈述】。

**命题 8.2（广义对称性：对称性自身的高阶化）**【文献已核】

(a) GKSW [49]（JHEP 2015）：$q$-形式全局对称——荷算子由余维 $q{+}1$ 拓扑缺陷承载；对称群推广为**高群**；'t Hooft 反常 = 高一阶上同调类；
(b) Snowmass 白皮书 [50]（Córdova–Dumitrescu–Intriligator–Shao，2022）：广义/不可逆对称的一般理论**要求 ∞-范畴语言**——对称性本身成为 ∞-范畴对象；
(c) 支撑文献：Kapustin–Thorngren [51]（高对称与规范理论隙相）、Aharony–Seiberg–Tachikawa [52]（4d 规范理论的 1-形式中心对称与禁闭）、Sharpe 综述 [53]。
结论性读法：物理学中最新的对称性概念革命（2015 至今）恰好发生在"群 → 高群 → ∞-范畴"的阶梯上——与 HoTT/∞-范畴数学共享同一对象族【元定理·组装】。

**命题 8.3（高规范理论与延展 TQFT）**【文献已核】

(a) 弦/膜的平行移动 = gerbe/2-丛上的和乐（Kalb–Ramond $B$ 场 = $U(1)$-gerbe 联络；Baez–Huerta [54]，Gen. Relativ. Gravit. 2011）；
(b) Freed–Hopkins–Lurie–Teleman [55]：紧致 Lie 群的 TQFT 族经 ∞-范畴构造；

**猜想 8.4（HoTT-native 物理，诚实登记）**【猜想】

cohesive HoTT 纲领（Schreiber–Shulman [57]）：把微分上同调与规范场论直接类型化——联络 = 到 $\mathbf B G_{\mathrm{conn}}$ 的映射、反常 = 高阶叠层的 obstruction。现状：纲领与片段实现，无量子化的完整类型化。本文登记三个可检验切入点（规范等价的 univalence 化；高形式对称的 cubical 可执行化——开放问题 3；拓扑项的构造性定义），不宣称物理新结果。

**B.2 命题 3.7（$\Omega(\mathcal U, \mathrm{Bool})$ 非命题）的完整手工演算。** (i) $\mathrm{Bool} \simeq \mathrm{Bool}$ 恰二：设 $e : \mathrm{Bool} \simeq \mathrm{Bool}$。$e(\mathsf{true}) = \mathsf{true}$ 或 $= \mathsf{false}$。情形 1：$e(\mathsf{true}) = \mathsf{true}$；则 $e(\mathsf{false}) = \mathsf{false}$——否则 $e(\mathsf{false}) = \mathsf{true} = e(\mathsf{true})$，由 $e$ 单射（等价必单射：$e\,a = e\,b \Rightarrow a = b$，对 $e$ 的逆复合即得）得 $\mathsf{false} = \mathsf{true}$，与构造子判别性矛盾（判别性：定义 $P : \mathrm{Bool} \to \mathcal U$，$P\,\mathsf{true} := \mathbf 1$，$P\,\mathsf{false} := \mathbf 0$；若 $\mathsf{true} = \mathsf{false}$ 则 transport 给出 $\mathbf 1 \to \mathbf 0$，矛盾）。故 $e = \mathsf{id}$（逐点相等 + funext；funext 由 univalence 供给，命题 3.5——本演算在 univalence 语境内进行，循环无害：funext 的证明不依赖本命题）。情形 2：$e(\mathsf{true}) = \mathsf{false}$；同理 $e(\mathsf{false}) = \mathsf{true}$，$e = \mathsf{not}$。(ii) $\mathsf{id} \neq \mathsf{not}$：$\mathsf{id}\,\mathsf{true} = \mathsf{true}$ 而 $\mathsf{not}\,\mathsf{true} = \mathsf{false}$；若 $\mathsf{id} = \mathsf{not}$ 则 $\mathsf{true} = \mathsf{false}$，同判别性矛盾。(iii) 由 univalence $\mathsf{idtoeqv} : (\mathrm{Bool} = \mathrm{Bool}) \simeq (\mathrm{Bool} \simeq \mathrm{Bool})$：$\mathsf{ua}\,\mathsf{id} \neq \mathsf{ua}\,\mathsf{not}$（等价映射单射），故 $\mathrm{Bool} =_{\mathcal U} \mathrm{Bool}$ 有两个互异居民——不是命题。(iv) 若 $\mathcal U$ 是集合，则其恒等类型皆为命题，矛盾。故 $\mathcal U$ 非集合。$\square$【已证（本文手工）；[13] Example 3.1.9 的完整展开】

**B.3 引理 4.2 与定理 4.3(a) 的手工骨架。** (i) 引理 4.2(b) 的 $\mathsf{isProp}\,A \Rightarrow \mathsf{isSet}\,A$（关键步）：设 $f : \mathsf{isProp}\,A$，即 $f : \prod_{(x,y:A)}(x=y)$。固定 $x$，记 $g := f(x) : \prod_{(y:A)}(x=y)$。**关键断言**：对任意 $p : y = z$，有 $p = (g\,y)^{-1} \cdot g\,z$。证明：对 $p : y = z$ 归纳，$p := \mathsf{refl}_y$ 情形：需 $\mathsf{refl} = (g\,y)^{-1}\cdot g\,y$——由 B.1(c) 的逆律（命题式）成立。于是对 $p, q : y = z$：$p = (g\,y)^{-1}\cdot g\,z = q$。故 $y = z$ 是命题，$A$ 是集合。(ii) 引理 4.2(c)（$\mathsf{isProp}\,A$ 是命题）：设 $f, k : \mathsf{isProp}\,A$。由 funext，证 $\prod_{(x,y:A)} f\,x\,y = k\,x\,y$ 即可；$f\,x\,y, k\,x\,y : x = y$，由 (i)（以 $f$ 证 $A$ 是集合）$x = y$ 是命题，故 $f\,x\,y = k\,x\,y$。(iii) 定理 4.3(a)（$n = -1$ 基例）：设每个 $B(x)$ 是命题，$f, g : \prod_{(x:A)} B(x)$；由 funext 证 $\prod_{(x:A)} f\,x = g\,x$；每个 $B(x)$ 是命题给出 $f\,x = g\,x$。故 $\prod B$ 是命题。一般 $n$ 的归纳步（用 $\prod$ 的恒等类型刻画，即 funext 的强形式）以 [13] Ch.7 为准，本文登记为【严格论证（文献输入）】。$\square$【(i)(ii)(iii) 已证（本文手工骨架）；归纳步归因】

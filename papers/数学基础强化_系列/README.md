## 一、系列缘起

全库综合分析（2026-08-06）确认：本仓库 324,916 个 .lean 文件中约 31.5 万个为机器生成文件，批量模块的"定理"为 `True := trivial`、`a + 0 = a := add_zero` 级别的同义反复，人工策划的非平凡证明估计不足 0.1%；与此同时，物理核心（Chern-Simons、Einstein-Cartan、Spectral Action 等）仍以 axiom 占位存在——本 pull 实测根目录非批量 208 条 + archive 88 条 + 命名子目录约 350 条以上，README 诚实声明口径为 **478 条 axiom**，Agda 六层另有约 149 个 postulate。

"证明率 99.5%"的历史口径与 proof_status.md 的自我否定并存，说明问题不在证明数量，而在**基础可信度**。本系列回应一个议题：**如何从 478 条 axiom（2026-08 时点口径；2026-09-05 实测 467，见 `framework/proof_status.md` §7）与大量平凡证明走向深层定理**——优先方向、技术路线、里程碑。

## 二、系列定位与原则

1. **诚实优先**：全部论断可追溯至仓库实测数据或真实文献；探索性陈述与已验证断言严格区分，遵循 `../AI_FAILURE_TO_VERIFIABLE_PROTOCOL.md` 协议。
2. **课程式形式化**：按研究生教材章节顺序（Marcus《Number Fields》/ Neukirch《Algebraic Number Theory》→ Silverman → Diamond-Shurman）构建依赖图，不自建底层，复用 mathlib4。
3. **纵向整合**：每篇论文须登记对应的 Lean 模块 / 验证脚本 / theorem 清单（血缘三元组），拒绝"两张皮"。
4. **里程碑驱动**：短期 6–18 个月、中期 2–5 年、长期 5–10 年三档，每档以 proof_status 登记口径验收。

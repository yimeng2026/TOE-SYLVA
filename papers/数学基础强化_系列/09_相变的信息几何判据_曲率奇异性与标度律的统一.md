## 摘要

热力学曲率（Ruppeiner 标量曲率 R）与 Fisher 信息度规在临界点的发散，半个世纪的文献中分别以"几何涨落理论"与"信息几何"两条线索发展。本文在指数族（Gibbs 系综）框架下给出二者的**统一判据定理**：(i) 证明 Weinhold 度规、Ruppeiner 度规与指数族 Fisher 度规是同一抽象流形上同一个 (0,2)-张量场的三种坐标/共形表示（Legendre 对偶 + 共形因子 T），故其标量曲率的主导奇异性严格共享；(ii) 在 Widom 广义齐次标度假设下，对二维参数流形 (t, h) 推导标量曲率的显式临界行为 $R = -(\gamma/A)(1+(\gamma-\alpha)/2)\,|t|^{-(2-\alpha)}$（A 为比热振幅），并证明"度规分量发散 ⟹ 曲率发散"在非消去条件（温度轴上由 γ>0 自动满足）下成立，同时给出消去线上的构造性平坦反例，说明该蕴涵并非无条件；(iii) 以 2D Ising 模型 Onsager 精确解为基准完成全部数值核对：$R = -\frac{105}{32A}\,t^{-2}/\ln(1/t)$（A = (2/π)ln²(1+√2) ≈ 0.4945），即 R ∝ ξ² 成立但带 1/ln(1/|t|) 的对数修正振幅——这是 α=0 边际指数在曲率层面的精确化身；(iv) 将"R ∝ ξ^d"猜想精确化为与 hyperscaling（2−α = dν）等价的命题，并诚实登记其失效域（平均场区域、消去线、spinodal 线）；(v) 量子推广：基态 fidelity 度规的标度律 χ_F ~ L^{2/ν}、χ_F/L^d ~ |δλ|^{-(2-dν)} 与经典曲率判据构成同一张标度律表，并以横场 Ising 链的精确解（Damski 2013：χ(1) = N²/32 − N/32）验证指数 2/ν = 2 与 2−dν = 1；(vi) 给出接续 sylva_formalization InformationGeometry 家族的 Lean 形式化骨架（设计稿，诚实标注未编译）。全部数学断言按 proof_status 分层标注；开放问题登记于 §9。

## 1 引言

### 1.1 问题的提出

统计力学的一个经典观察是：平衡态涨落的协方差结构天然是黎曼的。Weinhold 1975 [1] 把热力学状态空间配上内能 Hessian 度规；Ruppeiner 1979 [2] 以熵 Hessian 构造度规并发现其曲率携带相互作用信息，1995 年的 Reviews of Modern Physics 长文 [3] 系统建立了"热力学涨落的黎曼几何"并提出著名的曲率-关联体积猜想；Janyszek–Mrugała 1989/1990 [5][6] 将该几何用于磁性模型与理想量子气体；Brody–Rivier 1995 [7] 明确指出 Fisher 信息度规路径与 Ruppeiner 熵度规路径给出**相同**的临界曲率行为。与此平行，38 号文档（§2.3，定理 2.6/2.7）已在我方框架内登记"相变作为曲率奇异性"的定性判据；07 号论文把指数族 Fisher 度规锚定为对数配分势的 Hessian（Bregman 散度二阶结构）与 Legendre 对偶结构。

但以下问题在既有文献与我方文档中均未被严格回答：

1. **三种度规的临界奇异性是否严格同一？** Brody–Rivier 的观察是模型级计算结论，缺少表示论层面的统一陈述（何种坐标变换/共形变换下、主导奇异性是否逐项一致）。
2. **"度规发散 ⟺ 曲率发散"的精确条件是什么？** 38 号定理 2.6 断言临界点处 det(g)→0；本文将看到该断言需要按对偶坐标系修正（自然坐标下 det(g)→∞），且"分量发散 ⟹ 曲率发散"存在显式消去反例。
3. **曲率的临界指数是什么？与 ξ 的关系精确到何种程度？** Ruppeiner 猜想 |R| ~ ξ^d [2][3]，但其成立条件与 α=0 时的对数修正结构需要精确化。
4. **量子基态几何（fidelity 度规）与经典热几何是否共用同一张标度律表？** Zanardi–Giorda–Cozzini 2007 [11] 与 Campos Venuti–Zanardi 2007 [13] 建立了量子临界的信息几何，但与经典曲率判据的逐项对照表尚缺。

## 2 预备：指数族与对偶结构（极简，指向既有文）

本节仅固定记号；完整理论见 07 号 §1.3（Fisher = Bregman Hessian）、§2（α-联络与对偶平坦）与 38 号 §1–2。

**指数族 / Gibbs 系综。** 热力学系统的 Gibbs 态构成指数族：

$$p(x;\theta) = \exp\big(-\theta^a X_a(x) - \psi(\theta)\big),\qquad \psi(\theta) = \log\!\int e^{-\theta^a X_a(x)}\,dx = \log Z(\theta)$$

对磁体取 $\theta = (u, \tilde h)$，$u = J/(k_B T)$ 为无量纲耦合，$\tilde h = h/(k_B T)$ 为无量纲外场，$X = (H_0, -M)$ 为无量纲能量与磁化；每格点 Massieu 势 $\varphi(\theta) = \lim_{N\to\infty} N^{-1}\psi(\theta)$。

**Fisher 度规 = Hessian = 涨落协方差**（07 号 §1.3；38 号 §2.2）：

$$g_{ab}(\theta) = \frac{\partial^2 \psi}{\partial\theta^a \partial\theta^b} = \mathrm{Cov}_\theta(X_a, X_b) \succeq 0$$

**Legendre 对偶**（07 号 §1.3）：期望坐标 $\eta_a = \partial_a\psi = \mathbb{E}_\theta[X_a]$，对偶势 $\psi^*(\eta) = \theta^a\eta_a - \psi(\theta) = -S(\eta)$（熵的负值，至多差符号约定），且

$$\mathrm{Hess}_\eta\,\psi^*\big|_{\eta(\theta)} = \big(\mathrm{Hess}_\theta\,\psi\big|_\theta\big)^{-1}$$

**临界指数记号**（标准定义；标度关系的文献出处见附录 A）：$t = (T-T_c)/T_c$；

$$c_v \sim |t|^{-\alpha},\quad m \sim (-t)^{\beta}\ (t<0),\quad \chi \sim |t|^{-\gamma},\quad m(t{=}0) \sim h^{1/\delta},\quad \xi \sim |t|^{-\nu},\quad G_c(r) \sim r^{-(d-2+\eta)}$$

三条标度关系：Rushbrooke $\alpha + 2\beta + \gamma = 2$ [20]；Fisher $\gamma = \nu(2-\eta)$ [19]；Josephson hyperscaling $2-\alpha = d\nu$ [21]（$d<d_c$ 时成立）。RG 框架出处：Fisher 1974 [18]。

## 3 热力学度规的三位一体：Weinhold = T·Ruppeiner = Fisher

### 3.1 三种度规的定义

**定义 3.1（三种热力学度规）**

(a) **Weinhold 度规** [1]：能量表象，广延坐标 $X = (S, V, \dots)$，$g^W_{ij} = \partial^2 U/\partial X^i\partial X^j$（U 凸 ⇒ 半正定）。

(b) **Ruppeiner 度规** [2][3]：熵表象，广延坐标 $X' = (U, V, \dots)$，$g^R_{ij} = -\partial^2 S/\partial X'^i\partial X'^j$（S 凹 ⇒ 半正定）。

(c) **Fisher / 指数族度规**（§2）：强度坐标（自然参数）$\theta$ 上 $g^F_{ab} = \partial^2\psi/\partial\theta^a\partial\theta^b$。

### 3.2 统一等价定理

**定理 3.1（Ruppeiner = Fisher：同一 (0,2)-张量）** 【已证】

设 Gibbs 指数族如 §2，热力学极限存在且 $\psi$ 严格凸（远离相变点）。则 Ruppeiner 度规（熵表象、广延坐标 $\eta$ 表达）与 Fisher 度规（自然坐标 $\theta$ 表达）是同一抽象流形上**同一个** (0,2)-张量场在两套对偶坐标下的分量表示。特别地，其 Levi-Civita 曲率、标量曲率作为流形上的标量函数严格相等。

**证明。** 抽象流形取为平衡态空间 $\mathcal{M}$（状态本身，不带坐标）。在 $\mathcal{M}$ 上定义 (0,2)-张量场：任一点 $p \in \mathcal{M}$、切向量 $u, v \in T_p\mathcal{M}$，取通过 $p$ 的曲线族诱导的 score 扰动，$g_p(u,v) = \mathrm{Cov}_p(u(X), v(X))$——协方差是内蕴定义（38 号定理 1.1 的坐标无关表述）。自然坐标 $\theta$ 下：$g_{ab}d\theta^a d\theta^b$ 中 $g_{ab} = \partial_a\partial_b\psi$（§2）。期望坐标 $\eta$ 下：$d\eta = (\mathrm{Hess}\,\psi)\,d\theta$，即 $d\theta = (\mathrm{Hess}\,\psi)^{-1}d\eta = (\mathrm{Hess}_\eta\psi^*)\,d\eta$（Legendre 对偶的 Hessian 互逆，07 号 §1.3）。代入线元：

$$g_{ab}\,d\theta^a d\theta^b = d\theta^{\mathsf T}(\mathrm{Hess}\,\psi)\,d\theta = d\eta^{\mathsf T}(\mathrm{Hess}\,\psi^*)(\mathrm{Hess}\,\psi)(\mathrm{Hess}\,\psi^*)\,d\eta = d\eta^{\mathsf T}(\mathrm{Hess}_\eta\,\psi^*)\,d\eta$$

而 $\psi^* = -S$（熵），故 $\mathrm{Hess}_\eta\psi^* = -\mathrm{Hess}_\eta S = g^R$：Ruppeiner 度规正是同一线元在广延（期望）坐标下的分量。坐标变换不改变黎曼曲率张量与标量曲率（张量的坐标无关性）。$\square$

**注 3.1.** 同一性在模型层面早有印证：Brody–Rivier 1995 摘要明确陈述"由 Fisher 信息度规导出的曲率临界行为与由 Ruppeiner 熵度规导出者一致"（【文献已核】，检索所得摘要原文）；定理 3.1 把这一观察提升为表示论层面的恒等式——一致不是巧合，而是同一对象。

**定理 3.2（Weinhold = T·Ruppeiner；共形因子不感染主导奇异性）** 【已证】

(a) 在有限温度 $T>0$ 的平衡态区域，$ds^2_W = T\cdot ds^2_R$（共形等价，共形因子 $\Omega^2 = T$）。

(b) 设二维参数流形上 Ruppeiner 标量曲率 $R_R$ 在 $t\to 0$ 时按 $|R_R| \sim C|t|^{-p}$（$p>0$）发散，且 $T_c > 0$ 有限。则 Weinhold 标量曲率

$$R_W = T^{-1}\big(R_R - 2\Delta_g\log\Omega\big),\qquad \Omega = \sqrt{T}$$

其中共形修正项至多为 $O(|t|^{-(p-1)}/\log)$ 量级（见证明末的估计），故 $R_W \sim (C/T_c)|t|^{-p}(1+o(1))$：**指数与符号不变，振幅仅差因子 $1/T_c$**。

**证明。** (a) 是热力学 Legendre 结构的标准结果（Weinhold 1975 系列 [1] 建立度规几何；两种度规的等价性由 Mrugała 1984 [4] 明确讨论【文献已核，卷页待核】）：对内能表象与熵表象之间的 Legendre 变换逐坐标计算 Hessian 并提取整体因子 T。

(b) 二维共形变换公式：若 $\tilde g = \Omega^2 g$，则标量曲率 $R_{\tilde g} = \Omega^{-2}(R_g - 2\Delta_g\log\Omega)$（二维黎曼几何标准公式，附录 B.1 自含推导）。取 $\Omega = \sqrt{T}$，$\log\Omega = \tfrac12\log T(t,h)$ 在 $T_c>0$ 处解析。对 §4 的临界度规（$E \sim A|t|^{-\alpha}$ 或对数，$G \sim B|t|^{-\gamma}$）直接估计：$\Delta_g\log\Omega = \frac{1}{\sqrt{EG}}\partial_t\big(\sqrt{G/E}\,\partial_t\log\Omega\big)$。因 $\partial_t\log\Omega$ 在 $t=0$ 处有界，$\sqrt{G/E} \sim |t|^{-\gamma/2+\alpha/2}(\log)^{\mp 1/2}$，求导除度规因子后得 $\Delta_g\log\Omega = O(|t|^{-1}(\log|t|)^{-1})$——比 $R_R \sim |t|^{-2}$（对数修正同阶）低整整一个幂次（一般情形 $p = 2-\alpha > 1$，修正项 $O(|t|^{-1})$ 严格低阶）。$\square$

**物理含义**：三种几何在临界点是**同一个奇点**。任何"用哪种度规"的偏好都不改变曲率判据的内容——这是后续全部讨论的地基。

### 3.3 自由理论的平坦性：曲率为何"度量相互作用"

**命题 3.3（高斯/自由理论的热力学流形平坦）** 【已证】

若 Massieu 势 $\psi(\theta)$ 是二次型（等价地：Gibbs 族是固定协方差的高斯族/自由场理论），则 $g = \mathrm{Hess}\,\psi$ 为常矩阵，所有 Christoffel 符号为零，$R \equiv 0$。

**证明。** $\psi$ 二次 ⟹ $g_{ab}$ 常数 ⟹ $\Gamma \equiv 0$ ⟹ 曲率张量恒零。$\square$

**注 3.2.** 逆命题不成立（消去线反例见 §4.5），但命题 3.3 给出曲率的物理解读入口：一般指数族中 e-联络为零，Levi-Civita 联络由 Amari–Chentsov 三阶张量 $T_{abc} = \mathbb{E}[\partial_a\ell\,\partial_b\ell\,\partial_c\ell]$（三阶涨落累积量）驱动（07 号 §2.2）；曲率进而涉及三阶累积量的梯度与二次组合。这与 Janyszek–Mrugała 1989 [5] 的结构一致——其摘要明确该几何建立在"涨落的二阶与三阶矩"之上【文献已核】。理想（量子）气体的曲率计算见 Janyszek–Mrugała 1990 [6]：玻色气体 R<0、费米气体 R>0、经典理想气体 R→0，与命题 3.3 的"无相互作用 ⇒ 平坦"相容。

### 3.4 对 38 号定理 2.6 的对偶修正

38 号 §2.3.1（定理 2.6）陈述"临界点处 $\det(g_{ij}) \to 0$"。按本文记号，该陈述依赖于坐标系：

**命题 3.4（行列式的对偶表述）** 【已证】

临界点处响应函数发散（$\chi \sim |t|^{-\gamma}$，$\gamma>0$），故自然坐标下 $\det_\theta g \to +\infty$（见 §4.4 的逐分量行为）；同一 (0,2)-张量在期望（广延）坐标下的分量矩阵为 $g^{-1}$，故 $\det_\eta g \to 0$。两个陈述是同一张量在两套对偶坐标下的等价表述；"$\det \to 0$"只在期望坐标下成立。坐标无关的正确判据是**标量曲率发散**（§4 主定理）。

## 4 曲率判据定理

### 4.1 二维正交坐标曲率公式

**引理 4.1（只依赖单变量的正交度规的 Gauss 曲率）** 【已证】

设二维流形上 $ds^2 = E(t)\,dt^2 + G(t)\,dh^2$（$E, G > 0$，仅依赖 $t$）。则 Gauss 曲率

$$K = -\frac{1}{2\sqrt{EG}}\,\frac{d}{dt}\!\left(\frac{G_t}{\sqrt{EG}}\right),\qquad G_t = \frac{dG}{dt}$$

标量曲率 $R = 2K$（本文采用的符号约定：球面 $ds^2 = du^2 + \sin^2 u\,dv^2$ 得 $K = +1$）。

证明（Christoffel 符号直接计算）收入附录 B.1。

**推论 4.2（纯幂律度规的曲率通式）** 【已证】

设 $E = A|t|^{-a}$、$G = B|t|^{-b}$（$A, B > 0$）。则

$$R = 2K = -\frac{b}{A}\left(1 + \frac{b-a}{2}\right) |t|^{-(2-a)}$$

注意：(i) 振幅 $B$ 完全消去（warped-product 结构的一般性质）；(ii) **消去线**：$b = 0$ 或 $b = a - 2$ 时 $R \equiv 0$——尽管度规分量可以发散。推导见附录 B.2。

### 4.2 标度输入（物理假设，明示）

**假设 S（Widom 广义齐次标度）** 【物理输入；RG 支撑见 Fisher 1974 [18]】

临界点附近每格点自由能的奇异部分是广义齐次函数：

$$f_s(\lambda^{a_t} t,\, \lambda^{a_h} h) = \lambda\, f_s(t, h)$$

等价地 $f_s(t,h) = |t|^{2-\alpha} Y(h\,|t|^{-\beta\delta})$，$Y$ 为标度函数。由此（对 $t$、$h$ 求二阶导）：

$$g_{tt} = -\partial_t^2 f_s \sim A\,|t|^{-\alpha}\ (\alpha=0\text{ 时为 }A\log(1/|t|)),\quad g_{hh} = -\partial_h^2 f_s \sim B\,|t|^{-\gamma},\quad g_{th} = -\partial_t\partial_h f_s \sim |t|^{\beta-1}\ (t<0)$$

且 $t>0$ 的 $h=0$ 轴上 $g_{th} = 0$（顺磁侧磁化为零），度规对角，引理 4.1 适用。

### 4.3 主定理

**定理 4.3（相变的统一曲率判据）** 【已证（标度类内，条件逐项明示）】

设二维热力学参数流形 $(\mathcal{M}, g)$ 来自 Gibbs 指数族，$g$ 为 Fisher（= Ruppeiner = T⁻¹·Weinhold）度规，系统在非零有限 $T_c$ 处发生连续相变，假设 S 成立。记 $a, b$ 为 $g_{tt}, g_{hh}$ 沿 $h=0$、$t>0$ 轴的有效幂次（$\alpha>0$ 时 $a=\alpha$；$\alpha=0$ 时 $a=0$ 且携带对数修正，见定理 5.1），$b = \gamma$。

**(i) 度规发散的对偶刻画**【已证】：$\gamma > 0$ 或 $\alpha \ge 0$（响应发散）蕴涵

$$\lambda_{\max}(g_\theta) \to \infty \iff \det\nolimits_\theta g \to +\infty \iff \det\nolimits_\eta g = \det\nolimits_\theta g^{-1} \to 0 \iff \lambda_{\min}(g_\eta)\to 0$$

即"Fisher 度规发散"（自然坐标）与"Fisher 度规退化"（期望坐标）是同一事实的对偶表述。

**(ii) 度规发散 ⟹ 曲率发散（非消去条件下）**【已证】：若 $b \ne 0$ 且 $b \ne a - 2$（消去条件），则

$$R = -\frac{\gamma}{A}\left(1 + \frac{\gamma - \alpha}{2}\right) |t|^{-(2-\alpha)}\,(1+o(1))$$

（$\alpha=0$ 时右端乘以 $1/\log(1/|t|)$ 修正因子，精确形式见定理 5.1）。特别地，**沿温度轴，$b = \gamma > 0 > \alpha - 2 = a - 2$ 恒成立，消去条件自动满足**，故对任何具有正磁化率指数的连续相变：度规发散必然伴随曲率发散，且指数 $2-\alpha$ 由比热指数唯一确定，符号为负（吸引型相互作用的几何烙印，与 Ruppeiner 的符号诠释 [2][3] 相容——文献符号惯例细节【待核】见附录 A.3）。

**(iii) 反向的边界**【已证 + 构造性反例】：$R$ 发散一般**不**反推度规分量发散（曲率涉及度规的二阶导，非光滑但有界的度规可有发散曲率）；并且即使度规分量发散，曲率也可恒零——反例 $ds^2 = |t|^{-2}dt^2 + dh^2$（$a=2, b=0$ 落在消去线 $b=a-2$ 上）：坐标变换 $u = \log(1/|t|)$ 将其化为 $du^2 + dh^2$，显然平坦。故完整判据必须带非消去条件；在标度类内"分量发散 ⟺ 曲率发散"的等价性恰在消去线外成立。

**(iv) 曲率-标度律统一**【严格论证（依赖 hyperscaling）】：$2-\alpha = d\nu$（$d<d_c$）时

$$|R| \sim \frac{\gamma}{A}\left(1+\frac{\gamma-\alpha}{2}\right) \xi^{d}\,\big(\times\ \log\text{修正，若 }\alpha=0\big)$$

即 Ruppeiner 的"$R \propto \xi^d$"猜想在幂律层面与 hyperscaling 等价（§6 精确化）。

**证明。** (i) 是线性代数（$2\times2$ 正定矩阵行列式与特征值）加 §2 的对偶 Hessian 互逆；(ii) 将 $E = A|t|^{-\alpha}$、$G = B|t|^{-\gamma}$ 代入推论 4.2 并读出系数与指数（$\alpha=0$ 对数情形为定理 5.1 的显式计算）；(iii) 前半为曲率定义的直接观察，反例由推论 4.2 消去线 $b=a-2$ 验证（$b=0, a=2$：$1+(0-2)/2 = 0$）；(iv) 代入 hyperscaling 关系。$\square$

**注 4.1（与 Brody–Rivier 1995 的关系）。** 定理 4.3(ii) 的指数律 $R \sim |t|^{-(2-\alpha)}$ 与 Brody–Rivier [7] 在 van der Waals 与磁性模型上的模型级结论（曲率在临界点发散；Fisher 与 Ruppeiner 路径结果一致【文献已核】）相容，并把它们提升为标度类内的统一陈述；其另一结论"曲率沿整条 spinodal 线发散"登记为判据的边界（§6.3，反例 (e)）。

**注 4.2（曲率的坐标无关性是本判据相对 38 号定理 2.6/2.7 的实质推进）**：行列式与分量是坐标依赖对象（命题 3.4），曲率标量是内蕴对象；判据 (ii) 同时给出了"发散多少"（指数 $2-\alpha$、对数修正、振幅系数的显式公式），使几何判据成为可数值检验的定量预言（§5、§9）。

### 4.4 讨论：为什么曲率是"二阶"探针

度规本身是一阶涨落对象（响应函数）；曲率是度规的二阶微分对象，故其临界指数 $2-\alpha$ 比任何单一响应指数都"高两个温度导数"。这解释了历史现象：比热弱发散（$\alpha$ 小甚至为零/对数）的相变，其曲率仍然强发散（$2-\alpha \approx 2$）。曲率判据因此对 $\alpha \approx 0$ 的普适类（2D Ising、3D Ising $\alpha \approx 0.11$）依然敏感——这是它相对"直接看比热"的实质优势。

## 5 基准验证：2D Ising 模型

### 5.1 精确解输入（经典结果，逐项可核）

二维正方晶格 Ising 模型，Onsager 1944 精确解 [17]【文献已核】：

- 临界点：$\sinh(2u_c) = 1$，$u_c = \tfrac12\log(1+\sqrt{2}) = 0.4406868\dots$，$k_B T_c/J = 2/\log(1+\sqrt{2}) = 2.2691853\dots$；
- 比热（每格点，$k_B=1$）：$c = A\log(1/|t|) + O(1)$，振幅 $A = \frac{2}{\pi}(2u_c)^2 = \frac{2}{\pi}\log^2(1+\sqrt{2}) = 0.4945386\dots$（Onsager 解的标准推论，教科书级经典数值）；
- 经典指数：$\alpha = 0$（对数）、$\beta = 1/8$、$\gamma = 7/4$、$\delta = 15$、$\nu = 1$、$\eta = 1/4$。

**标度关系数值核对**【数值核对】：Rushbrooke：$0 + 2\times\tfrac18 + \tfrac74 = 2$ ✓；Fisher：$\nu(2-\eta) = 1\times\tfrac74 = \tfrac74 = \gamma$ ✓；hyperscaling：$2-\alpha = 2 = 2\times 1 = d\nu$ ✓（$d=2$）。

### 5.2 临界点附近的度规

沿 $h = 0$、$t > 0$ 轴（顺磁侧），由 §4.2（$g_{th}=0$，度规对角；取 $t$ 为约化温度、$h$ 为 $k_B T_c$ 单位的无量纲场，度规为每格点值）：

$$E(t) = g_{tt} = A\log(1/t)\,(1+o(1)),\qquad G(t) = g_{hh} = B\,t^{-7/4}(1+o(1))$$

其中 $A = 0.4945386\dots$ 为比热振幅，$B$ 为磁化率振幅（非普适；下面将看到它从曲率中消去）。

### 5.3 曲率的显式计算

**定理 5.1（2D Ising 的热力学标量曲率）** 【已证（解析推导，附录 B.3 全部中间步骤）】

上述度规的标量曲率当 $t \to 0^+$：

$$R = 2K = -\frac{105}{32\,A}\;t^{-2}\,\big[\log(1/t)\big]^{-1}\Big(1 + O\big(1/\log(1/t)\big)\Big)$$

代入 $A = \frac{2}{\pi}\log^2(1+\sqrt2)$：

$$R \;\approx\; -6.635\; t^{-2}\,/\log(1/t)\qquad (t\to 0^+)$$

（约定：每格点、$k_B = 1$、$t$ 为约化温度、熵表象度规 $g = -\mathrm{Hess}\,f_s$；坐标/归一化约定改变时振幅 $-6.635$ 相应改变，**指数 $-2$、对数修正幂次 $-1$ 与符号为不变内容**）。

**推导要点**（附录 B.3）：$E = A L$（$L := \log(1/t)$）、$G = B t^{-p}$、$p = 7/4$ 代入引理 4.1：

$$K = -\frac{1}{2\sqrt{AB}\,L^{1/2}t^{-p/2}}\frac{d}{dt}\!\left[\frac{-pB\,t^{-p-1}}{\sqrt{AB}\,L^{1/2}t^{-p/2}}\right] = -\frac{p\,q}{2A}\,t^{-2}L^{-1}\Big(1 - \frac{1}{2qL}\Big),\quad q := 1+\frac p2 = \frac{15}{8}$$

$pq = \frac74\cdot\frac{15}{8} = \frac{105}{32}$，$R = 2K$ 得系数 $-\frac{105}{32A}$；$105/(32\times0.4945386) = 6.63497\dots$。

**与通式的自洽核对**【数值核对】：把 $\alpha \to 0$ 的纯幂律通式（推论 4.2：系数 $-\frac{\gamma}{A}(1+\frac{\gamma-\alpha}{2})$）代入 $\gamma = 7/4$：$-\frac{7/4}{A}(1+\frac78) = -\frac{7}{4A}\cdot\frac{15}{8} = -\frac{105}{32A}$——与对数版首项系数**完全一致**，对数情形只是乘以 $1/L$。两套独立推导吻合 ✓。

### 5.4 与 R ∝ ξ^d 的核对：对数修正的精确化

2D Ising 关联长度 $\xi = \xi_0\,|t|^{-1}(1+o(1))$（$\nu = 1$；$\xi_0$ 非普适）。于是

$$\frac{R}{\xi^{2}} = -\frac{105}{32\,A\,\xi_0^{2}}\;\frac{1}{\log(1/|t|)}\;\longrightarrow\; 0\quad (t\to 0)$$

**精确化陈述**【已证（本文推导）；未见于所核文献，独立复核登记于 §9 问题 2】：对 2D Ising，$R \propto \xi^d$ 在**幂律指数层面成立**（$R \sim |t|^{-2} \sim \xi^2$），但**振幅比 $R/\xi^2$ 以 $1/\log(1/|t|)$ 缓慢漂移到零**。几何出处清晰：α=0 使温度方向度规从幂律退化为对数（$E = A\log$ 而非 $A|t|^{-a}$），warped-product 曲率公式中的 $E$ 因子以 $1/E \sim 1/\log$ 进入分母。这是 α=0 边际指数在曲率层面的精确化身——"R = 关联体积"的等式在边际情形需要乘上一个对数衰减的修正振幅。

### 5.5 其它路径与两侧一致性

- **$t<0$ 侧**（$h \to 0^+$）：$g_{th} \sim |t|^{-7/8}$ 非零，度规非对角，完整计算需标度函数 $Y$ 的更多输入；幂次计数给出同一指数 $|t|^{-2}$（$\det g$ 中 $g_{tt}g_{hh} \sim |t|^{-7/4}\log$ 对 $g_{th}^2 \sim |t|^{-7/4}$ 占优，度规非退化）。【严格论证；逐振幅计算登记为后续】
- **临界等温线**（$t=0$，$h\to 0$）：$g_{hh} \sim |h|^{-14/15}$（$\chi \sim h^{1/\delta-1}$），$g_{tt}$ 行为依赖正则部分；路径曲率发散同样由幂次计数给出【严格论证】。
- **热力学长度对比注记**（Crooks 2007 [10] 的语境【文献已核】）：沿温度轴逼近临界点的热力学长度 $\ell = \int_0 \sqrt{g_{tt}}\,dt \sim \int_0 \sqrt{A\log(1/t)}\,dt < \infty$ **收敛**（被积函数可积）；临界等温线上 $\int_0 |h|^{-7/15}dh$ 亦收敛。**长度有限而曲率发散**——标量曲率是比热力学长度更敏感的临界探针，这为"为什么需要曲率判据而非度规/长度判据"提供了定量回答。

## 6 曲率–关联长度恒等式：精确表述与反例登记

### 6.1 精确版命题

**命题 6.1（R–ξ 恒等式的精确版）** 【严格论证（依赖明示假设）】

设 (H1) Widom 广义齐次标度（假设 S）；(H2) hyperscaling $2-\alpha = d\nu$ 成立（即 $d < d_c$）；(H3) Ruppeiner 关联体积归一假设：在关联体积 $\xi^d$ 内涨落近似相干、之外近似独立，使得流形曲率归一到单个关联体积 [2][3]。则

$$|R| = \kappa\, \xi^{d}\,\big(1 + o(1)\big) \qquad\text{（}\alpha = 0\text{ 时右端乘对数修正振幅，见 §5.4）}$$

其中 $\kappa$ 为路径依赖的振幅（含 $\xi_0^{-d}$ 与比热振幅比）。并且反向成立：若 $R \sim |t|^{-p}$ 且 $R \propto \xi^d$（幂律层面），则 $p = d\nu$，与 $p = 2-\alpha$（定理 4.3(ii)）联立给出 $2-\alpha = d\nu$。即：

$$\boxed{\;R \propto \xi^{d}\ \text{（幂律层面）}\ \Longleftrightarrow\ 2-\alpha = d\nu\ \text{（hyperscaling）}\;}$$

**论证。** 正向：定理 4.3(ii) 给出 $R \sim |t|^{-(2-\alpha)}$，(H2) 化为 $|t|^{-d\nu} \sim \xi^d$，(H3) 提供物理解读与归一化。反向：两指数相等即 $p = 2-\alpha = d\nu$。$\square$

**与 Ruppeiner 原始表述的关系**：Ruppeiner 1979 [2] 摘要自述其曲率诠释"consistent with hyperscaling and two-scale-factor universality"【文献已核，检索摘要原文】——命题 6.1 把"consistent with"升级为"等价于（幂律层面）"，并补上了失效域（§6.2–6.3）与边际情形的对数修正（§5.4）。两尺度因子普适性语境下的振幅比 $\kappa$ 是否普适【待核】，登记为开放问题（§9 问题 1 附带项）。

### 6.2 失效域登记（一）：平均场区域

**登记 6.2（平均场反例）** 【严格论证 + 文献支撑】

$d > d_c = 4$ 的 Ising 普适类由平均场（Gaussian）指数描述：$\alpha = 0$（比热有限跳变，**非**对数发散）、$\gamma = 1$、$\nu = 1/2$。此时：

- 曲率：$E = A$（常数，跳变不改变幂次计数）、$G = B|t|^{-1}$ 代入推论 4.2（$a=0, b=1$）：$R = -\frac{1}{A}\cdot\frac32\,|t|^{-2} = -\frac{3}{2A}|t|^{-2}$——**曲率照样发散**（与 Brody–Rivier [7] 对磁性模型的发现一致【文献已核】）；
- 但 $\xi^d \sim |t|^{-d/2}$，$d>4$ 时 $|t|^{-d/2}$ 比 $|t|^{-2}$ 发散**更快**：$R \propto \xi^d$ **失效**；
- 形式上 $R \sim \xi_G^{4}$（$\xi_G \sim |t|^{-1/2}$ 为 Gaussian 关联长度）：**曲率"看到"的是上临界维数 $d_c=4$，而非实际维数 $d$**——这正是 hyperscaling 失效（$2-\alpha = 2 \ne d/2 = d\nu$）的几何化身，与命题 6.1 的等价性自洽。
- 诚实边界：平均场区域的危险无关变量（dangerous irrelevant variable）修正会改动上述幂次的细节表述，该机制的几何化【待核】，登记为后续。

### 6.3 失效域登记（二）：构造性反例与 spinodal

- **(b) 消去线反例**【已证，构造性】：$ds^2 = |t|^{-2}dt^2 + dh^2$（$a=2, b=0$，消去线 $b = a-2$ 上）：度规分量发散、$\det g \to \infty$，但 $R \equiv 0$（$u=\log(1/|t|)$ 下即 $du^2+dh^2$）。故"度规发散 ⟹ 曲率发散"不无条件成立；定理 4.3(ii) 的非消去条件不可去。
- **(c) 自由理论**【已证】：命题 3.3——无相互作用系统（理想气体、高斯固定点）$R \equiv 0$；曲率是相互作用/非高斯性的探针，而非一切奇异性的探针。
- **(d) 1D Ising**：无有限温度相变；$T\to 0$ 极限的曲率行为在 Ruppeiner 1995 [3] 中有讨论（该文包含一维 Ising 模型的曲率计算，检索摘要可见"One-dimensional Ising model"条目【文献已核】），其 $T\to 0$ 处 $R$ 与 $\xi$ 的逐项核对【待核】，登记为后续核算条目。
- **(e) spinodal 发散**【文献已核】：Brody–Rivier 1995 [7] 摘要明确：van der Waals 气体与磁性模型的标量曲率"不仅在临界点、而且沿整条 spinodal 曲线发散"。spinodal 是**平均场亚稳边界**而非平衡相变，故逆命题"曲率发散 ⟹ 平衡相变"在平均场面貌下亦不成立——曲率发散应解读为"涨落几何的奇异性"，其物理定性（真相变 vs 亚稳边界）需结合系综稳定性分析。这是判据的固有边界，如实登记。

### 6.4 小结

"R 测量关联体积"的精确内容是：**在 hyperscaling 成立域内，$|R|$ 与 $\xi^d$ 共享同一临界幂律（边际维数/边际指数处携带可计算的对数修正）；在平均场区域，$|R|$ 转而上临界维数的幂律**。曲率既非万能（消去线、自由理论、spinodal 边界），也非神秘（等价于 hyperscaling 的几何化身）——命题 6.1 给出其全部适用条件的显式刻画。

## 7 量子推广：基态 fidelity 度规与统一标度律表

### 7.1 基态流形的量子几何张量

参数化哈密顿量 $H(\lambda)$，基态 $|\psi_0(\lambda)\rangle$。量子几何张量（QGT）

$$Q_{\mu\nu} = \langle\partial_\mu\psi_0|(1-|\psi_0\rangle\langle\psi_0|)|\partial_\nu\psi_0\rangle$$

其实部为 fidelity（Bures）度规 $g^F_{\mu\nu} = \mathrm{Re}\,Q_{\mu\nu}$：$|\langle\psi_0(\lambda)|\psi_0(\lambda+d\lambda)\rangle| = 1 - \tfrac12 g^F_{\mu\nu}d\lambda^\mu d\lambda^\nu + \dots$；对角元 $\chi_F := g^F_{\lambda\lambda}$ 即 fidelity 磁化率。Zanardi–Paunković 2006 [12]：基态重叠的极值点标记量子临界区域【文献已核】；Zanardi–Giorda–Cozzini 2007 [11]：耦合常数流形配上具有可操作区分度含义的黎曼度规，**度规奇异性与量子相变对应**【文献已核】——本文定理 4.3 的量子对应物的文献先例。

### 7.2 fidelity 磁化率的标度律

**标度推导**【严格论证；文献支撑 [13][14][15][16]】。设 $H(\lambda) = H_0 + \lambda V$，$V = \int d^dx\, v(x)$，$v$ 的标度维数为 $\Delta_v$（驱动相变的相关微扰，RG 本征值 $y_\lambda = d+z-\Delta_v = 1/\nu$）。二阶微扰论：

$$\chi_F = \sum_{n\ne 0}\frac{|\langle n|V|0\rangle|^2}{(E_n-E_0)^2}\ \xrightarrow{\text{临界点}}\ L^{2(d-\Delta_v)+2z} = L^{2/\nu}$$

（矩阵元 $\sim L^{d-\Delta_v}$，能隙 $\sim L^{-z}$）。**超广延条件**：$2/\nu > d \iff d\nu < 2$；否则每格点 $\chi_F/L^d$ 在临界点保持有限（临界性不是超广延发散的充分条件——Campos Venuti–Zanardi 2007 [13] 摘要明确陈述此点【文献已核】）。Gu–Lin 2009 [14]：fidelity 磁化率具有独立于体系维数自身的标度维数【文献已核】。有限尺寸标度形式 $\chi_F(\delta\lambda, L) = L^{2/\nu}\Phi(\delta\lambda L^{1/\nu})$ 取热力极限（要求 $L$ 依赖消去：$\Phi(x)\sim x^{d\nu-2}$）：

$$\frac{\chi_F}{L^d} \sim |\delta\lambda|^{-(2-d\nu)}\qquad (d\nu<2)$$

文献序列：Gu–Kwok–Ning–Lin 2008 [15]（FSS 与普适性，PRB 77, 245109【文献已核】）；Albuquerque–Alet–Sire–Capponi 2010 [16]（quantum critical scaling of fidelity susceptibility，PRB 81, 064418【文献已核，页码经 Damski 引文列表交叉确认】）；Gu 2010 综述 [22]（Int. J. Mod. Phys. B 24, 4371【文献已核，页码经 Damski 引文列表交叉确认】）。边际情形出现对数：Lipkin–Meshkov–Glick 模型的 fidelity 磁化率临界行为（Kwok–Ning–Gu–Lin 2008 [27]，PRE【文献已核，卷页待核】）。

### 7.3 横场 Ising 链：精确解验证

Damski 2013 [23]（PRE 87, 052131【文献已核】，arXiv:1212.1528 全文已核对）给出 $H(g) = -\sum_i(\sigma^x_i\sigma^x_{i+1} + g\sigma^z_i)$ 的闭式精确解：

$$\chi(g) = \frac{N^2}{16g^2}\frac{g^N}{(g^N+1)^2} + \frac{N}{16g^2}\frac{g^N-g^2}{(g^N+1)(g^2-1)}$$

逐项核对【数值核对，全部直接引自该文】：

- **临界点**：$\chi(1) = \frac{N^2}{32} - \frac{N}{32}$——主项 $N^2/32$，与 $\chi_F \sim L^{2/\nu}$（$\nu=1$ ⟹ $L^2$）精确吻合 ✓（该文明确与 [16] 的 $N^2$ 标度预言对照）；
- **热力极限**（$g>1$ 固定，$N\to\infty$）：$\chi/N \to \frac{1}{16g^2(g^2-1)} \sim \frac{1}{32(g-1)}$（$g\to 1^+$）——发散指数恰为 $2-d\nu = 2-1\times1 = 1$ ✓（该文同时严格证明：有限 $N$ 时临界点附近 $\chi$ 解析，表观奇点是领头项与余项相消的伪影——两种极限不交换，与 §7.2 的 FSS 图像完全一致）；
- **Kramers–Wannier 对偶**：$g^2\chi(g) = g^{-2}\chi(1/g)$——fidelity 磁化率的铁磁/顺磁对偶对称性，与经典侧的对偶坐标结构（§3.2）形成耐人寻味的平行；
- 关联长度精确形式 $\xi(g) \sim 1/|\log g|$，交叉条件 $N|\log g| \sim 1$ 即 $N \sim \xi$：FSS 交叉尺度 ✓。

## 9 开放问题登记

**问题 1（3D Ising 曲率的数值检验）。** 用 Monte Carlo 或张量网络（TEI）数值计算 3D Ising 模型的热力学标量曲率，检验定理 4.3(ii) 的预言 $R \sim -(\gamma/A)(1+(\gamma-\alpha)/2)|t|^{-(2-\alpha)}$，其中标准数值共识 $\alpha \approx 0.110$、$\gamma \approx 1.237$、$\nu \approx 0.630$（具体数值来源【待核】；Ruppeiner 1998 [8] 的一般理论框架【文献已核】含对三维情形的讨论与当时的指数引用，可作为比对基线）。附带检验振幅比 $R/\xi^3$ 的普适性（两尺度因子普适性语境，§6.1 的【待核】项）。

**问题 2（边际对数修正的普适形式）。** 本文定理 5.1 在 2D Ising（$\alpha=0$）得到 $R \sim |t|^{-2}/\log(1/|t|)$。问题：该对数修正幂次（$-1$）是否对所有 $\alpha=0$ 边际情形普适？干净的试验场是 4D Ising（上临界维数，平均场带对数修正：$c \sim |\log t|^{1/3}$、$\chi \sim |t|^{-1}|\log t|^{1/2}$、$\xi \sim |t|^{-1/2}|\log t|^{1/6}$——对数修正指数数值【待核】）：预言其曲率满足 $R \sim |t|^{-2}|\log t|^{\hat R}$ 且 $\hat R$ 可由引理 4.1 的 warped-product 公式从上述对数指数直接读出（$\hat R = -(\hat c$ 项$)$ 的候选值：$-1/3$，待推导验证）。同时独立复核 §5.4 的 2D Ising $1/\log$ 修正（未见于所核文献，本文原创计算）。

**问题 3（量子基态流形的标量曲率判据）。** 对双参数 XY 链（横场 $g$ + 各向异性 $\gamma_{an}$，Zanardi–Giorda–Cozzini 2007 [11] 已算其 fidelity 度规分量【文献已核】）计算标量曲率，检验其发散指数是否与 §7.2 的 $\chi_F$ 标度律（$2/\nu$、$2-d\nu$）由同一 RG 数据锁定，即建立量子版定理 4.3。Damski 2013 的单参数精确解与 KW 对偶提供现成基准与对称性约束。

## 附录 B：曲率公式推导细节

**B.1 引理 4.1 的证明（含二维共形公式）。** 度规 $ds^2 = E\,dt^2 + G\,dh^2$，$E, G$ 仅依赖 $t$。Christoffel：$\Gamma^t_{tt} = E_t/(2E)$，$\Gamma^t_{hh} = -G_t/(2E)$，$\Gamma^h_{th} = \Gamma^h_{ht} = G_t/(2G)$，其余为零。Ricci 标量 $R = 2g^{tt}R_{htht}\cdot(\dots)$ 直接计算（或先正交化 $dw = \sqrt{E}dt$ 化为 $ds^2 = dw^2 + \tilde G(w)dh^2$，用标准公式 $K = -(\sqrt{\tilde G})_{ww}/\sqrt{\tilde G}$）得

$$K = -\frac{1}{2\sqrt{EG}}\frac{d}{dt}\!\left(\frac{G_t}{\sqrt{EG}}\right)$$

验证基准：$E=1, G=\sin^2 t$ 给 $K = 1$（球面）✓；$E = t^{-2}, G=1$ 给 $K = 0$（消去线反例）✓。二维共形公式：$\tilde g = \Omega^2 g$ 时 $R_{\tilde g} = \Omega^{-2}(R_g - 2\Delta_g\log\Omega)$（二维黎曼几何标准结果，可由同一 Christoffel 计算导出）。

**B.2 推论 4.2（纯幂律通式）的推导。** $E = A t^{-a}$，$G = B t^{-b}$（$t>0$）：$\sqrt{EG} = \sqrt{AB}\,t^{-(a+b)/2}$；$G_t/\sqrt{EG} = -b\sqrt{B/A}\,t^{(a-b)/2-1}$；再求导得 $-b\sqrt{B/A}\big(\frac{a-b}{2}-1\big)t^{(a-b)/2-2}$；除以 $-2\sqrt{EG}$：

$$K = -\frac{b}{2A}\left(1+\frac{b-a}{2}\right)t^{a-2},\qquad R = 2K = -\frac{b}{A}\left(1+\frac{b-a}{2}\right)t^{-(2-a)}$$

$B$ 严格消去 ✓；消去线 $b(b-a+2) = 0$ 即 $b=0$ 或 $b = a-2$ ✓。

**B.3 定理 5.1（对数版）的推导。** $E = A L$（$L := \log(1/t)$），$G = B t^{-p}$，$p = 7/4$。记 $q := 1 + p/2 = 15/8$。

$$\frac{G_t}{\sqrt{EG}} = \frac{-pB\,t^{-p-1}}{\sqrt{AB}\,L^{1/2}t^{-p/2}} = -p\sqrt{\frac BA}\,t^{-q}\,L^{-1/2}$$

$$\frac{d}{dt}\big[t^{-q}L^{-1/2}\big] = -q\,t^{-q-1}L^{-1/2} + \frac{1}{2}t^{-q-1}L^{-3/2} = t^{-q-1}L^{-1/2}\Big(-q + \frac{1}{2L}\Big)$$

（用了 $\frac{d}{dt}L^{-1/2} = \frac{1}{2t}L^{-3/2}$，因 $\frac{dL}{dt} = -1/t$。）代回：

$$K = -\frac{1}{2\sqrt{AB}\,L^{1/2}t^{-p/2}}\cdot\Big[-p\sqrt{\tfrac BA}\,t^{-q-1}L^{-1/2}\Big(-q+\tfrac{1}{2L}\Big)\Big] = -\frac{pq}{2A}\,t^{-2}L^{-1}\Big(1-\frac{1}{2qL}\Big)$$

（注意 $-q-1+p/2 = -2$。）代入 $pq = \frac{7}{4}\cdot\frac{15}{8} = \frac{105}{32}$、$R = 2K$：

$$R = -\frac{105}{32A}\,t^{-2}\,L^{-1}\Big(1 - \frac{4}{15L} + O(L^{-2})\Big)$$

数值：$A = \frac{2}{\pi}\log^2(1+\sqrt2) = 0.4945386\dots$；$\frac{105}{32\times 0.4945386} = 6.63497\dots$ ✓（本文正文取 $-6.635$）。

**B.4 定理 3.2(b) 共形修正的量级估计。** $\Delta_g\log\Omega = \frac{1}{\sqrt{EG}}\partial_t\big(\sqrt{G/E}\,\partial_t\log\Omega\big)$。$\log\Omega = \frac12\log T(t)$ 在 $T_c>0$ 处解析，$\partial_t\log\Omega = c_0 + O(t)$；$\sqrt{G/E} = \sqrt{B/A}\,t^{-p/2}L^{-1/2}$；$\partial_t[\cdot] = \sqrt{B/A}\,c_0\,t^{-p/2-1}L^{-1/2}(-p/2 + O(1/L))$；除以 $\sqrt{EG} = \sqrt{AB}L^{1/2}t^{-p/2}$：

$$\Delta_g\log\Omega = -\frac{p\,c_0}{2A}\,t^{-1}L^{-1}\big(1+O(1/L)\big) = O\big(t^{-1}/\log\big)$$

对比 $R_R \sim t^{-2}/\log$：严格低一阶 ✓（$R_W = T^{-1}(R_R - 2\Delta_g\log\Omega) = T_c^{-1}R_R(1+O(t))$）。

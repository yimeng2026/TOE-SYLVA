## 2 实证对象的选择

### 2.1 为什么是 T1.2 与 T1.3

在 02 篇的清单中，T1.2（强三角不等式；ℚ\_p 为超度量域）与 T1.3（ℚ\_p/ℤ\_p 完备）是 p-adic 分析的两大基石：超度量性是非阿基米德几何的灵魂（闭单位球因之成为环——ℤ\_p 的定义即 `{x : ℚ_[p] // ‖x‖ ≤ 1}`），完备性是一切极限与级数论证的合法性前提（后续 Hensel 引理、Mahler 展开、p-adic L-函数全部站在其上）。两者在 02 篇中均分类为"复用 mathlib4 + 课程重述"，这使其成为检验"复用层 + 薄胶水层"工艺的最小完备样本：若连这两个定理都不能在零新增公理下落地，02 篇的全部分类判断都要重估。

### 2.2 定理的数学陈述（课程语言）

- **定理 A（T1.2）**：设 `p` 为素数，`x, y ∈ ℚ_p`，则 `|x + y|_p ≤ max(|x|_p, |y|_p)`；对 `x, y ∈ ℤ_p` 同样成立。
- **定理 B（T1.3）**：`ℤ_p` 完备：每个 Cauchy 序列在 `ℤ_p` 中收敛。
- **推论 C**：`ℤ_p` 恰为 `ℚ_p` 的闭单位球（每元范数 ≤ 1）；标准一致化元 `p` 的范数为 `p⁻¹`；特别地 `p^n → 0`（p-adic 拓扑的核心经验）。

### 3.2 实证代码（全文；附录 B 同）

```lean
import Mathlib.NumberTheory.Padics.PadicIntegers
import Mathlib.NumberTheory.Padics.PadicNumbers
import Mathlib.Analysis.SpecificLimits.Normed

open Filter Topology

namespace ZpCourse

variable (p : ℕ) [hp : Fact p.Prime]

/-- 定理一（T1.2 课程重述·基础版）：ℚ_[p] 上范数的强三角不等式 -/
theorem qpadic_norm_add_le_max (x y : ℚ_[p]) : ‖x + y‖ ≤ max ‖x‖ ‖y‖ := by
  have h := IsUltrametricDist.dist_triangle_max (x + y) y (0 : ℚ_[p])
  rw [dist_eq_norm, dist_eq_norm, dist_eq_norm] at h
  simpa using h

/-- 定理一（T1.2 课程重述·Zp 版）：ℤ_[p] 上范数的强三角不等式 -/
theorem zpadic_norm_add_le_max (x y : ℤ_[p]) : ‖x + y‖ ≤ max ‖x‖ ‖y‖ := by
  simp only [PadicInt.norm_def, PadicInt.coe_add]
  exact qpadic_norm_add_le_max p (x : ℚ_[p]) (y : ℚ_[p])

/-- 定理二（T1.3 课程重述）：ℤ_[p] 完备——每个 Cauchy 列收敛 -/
theorem zpadic_complete (s : ℕ → ℤ_[p]) (hs : CauchySeq s) :
    ∃ a : ℤ_[p], Tendsto s atTop (𝓝 a) :=
  cauchySeq_tendsto_of_complete hs

/-- 闭单位球刻画：ℤ_[p] 的每个元素范数 ≤ 1 -/
theorem zpadic_norm_le_one (x : ℤ_[p]) : ‖x‖ ≤ 1 :=
  PadicInt.norm_le_one x

/-- 标准一致化元的范数：‖(p : ℤ_[p])‖ = p⁻¹ -/
theorem zpadic_norm_p : ‖(p : ℤ_[p])‖ = (p : ℝ)⁻¹ :=
  PadicInt.norm_p

/-- 推论（T1.4 课程重述）：p 的幂在 ℤ_[p] 中趋于 0 -/
theorem zpadic_tendsto_pow_p :
    Tendsto (fun n : ℕ => (p : ℤ_[p]) ^ n) atTop (𝓝 0) := by
  apply tendsto_pow_atTop_nhds_zero_of_norm_lt_one
  rw [zpadic_norm_p]
  exact inv_lt_one_of_one_lt₀ (by exact_mod_cast hp.out.one_lt)

end ZpCourse

-- 治理审计输出（写入编译日志作为证据）
#print axioms ZpCourse.qpadic_norm_add_le_max
#print axioms ZpCourse.zpadic_norm_add_le_max
#print axioms ZpCourse.zpadic_complete
#print axioms ZpCourse.zpadic_tendsto_pow_p
```

### 3.3 证明要点与命题-意图对齐（逐条）

1. `qpadic_norm_add_le_max`：以 `dist_triangle_max (x+y) y 0` 取实例 `dist (x+y) 0 ≤ max (dist (x+y) y) (dist y 0)`，经 `dist_eq_norm` 译为 `‖x+y-0‖ ≤ max ‖x+y-y‖ ‖y-0‖`，`simpa` 化简闭合。**对齐说明**：陈述的量词（∀ x y）、类型（ℚ\_p 及其范数）与定理 A 的 ℚ\_p 部分一致。
2. `zpadic_norm_add_le_max`：`simp only` 用 `norm_def`/`coe_add` 把 ℤ\_p 范数与加法归约到 ℚ\_p，由定理 1 闭合。**对齐说明**：ℤ\_p 范数按定义即 ℚ\_p 范数在子类型上的限制，归约忠实。
3. `zpadic_complete`：`cauchySeq_tendsto_of_complete` 直接应用 `CompleteSpace ℤ_[p]` 实例；极限点 `a : ℤ_[p]`，收敛在 ℤ\_p 内（极限唯一性由 T2 性质自动保证，无需显式陈述——核验组确认不构成缺陷）。
4. `zpadic_norm_le_one`：ℤ\_p 定义性质（闭单位球）的直接引用。
5. `zpadic_norm_p`：`PadicInt.norm_p` 直接引用；`(p : ℝ)⁻¹` 为标准一致化元范数。
6. `zpadic_tendsto_pow_p`：唯一带实质胶水的定理——范数 < 1 的幂次趋于零（一般泛函定理）× `norm_p`（具体范数值）× `inv_lt_one_of_one_lt₀`（`p ≥ 2 ⇒ p⁻¹ < 1`）三引理组合，得出 p-adic 分析的核心经验 `p^n → 0`。

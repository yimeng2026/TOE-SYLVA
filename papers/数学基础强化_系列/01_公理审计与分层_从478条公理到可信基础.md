## 2 公理分类学

形式化系统中加入一条 `axiom`，在逻辑上可能有四种截然不同的身份。混淆它们是"公理与定理边界模糊"的根源。

### 2.1 本原公理（primitive axioms）

系统真正的逻辑起点：独立于其他公理、不可由定义展开消除的断言。例如 ZFC 中的无穷公理、Lean 4 核心逻辑中的 `Classical.choice`、`Quot.sound` 与 `propext` 三件套（Lean 中 `#print axioms` 的标准输出）。本原公理的特征是：删除它会实质削弱系统的表达力。对物理形式化项目而言，真正的物理假设（如"Chern-Simons 作用量在规范变换下按整数倍变化"）若被提升为公理，应归入此类并显式登记其经验依据。

### 2.2 定义性扩展（definitional extensions）

以公理形式陈述、实则可由已有定义与定理导出的命题。Isabelle/HOL 的传统是只允许常量定义与类型定义两种扩展机制，严格保证一切扩展均为保守扩展（Gordon & Melham, 1993），从而杜绝此类泄漏；Metamath `set.mm` 的长期维护经验表明，约 20–30% 的原始公理模式可降级为定理（Megill & Wheeler, 2019）。识别判据：存在一个不引入新常量的证明。此类公理应**降级**（demote）为 `theorem`，是清偿成本最低的一类。

### 2.3 公理模式（axiom schemas）

不可数或有参数的一族公理的统一模板，如 ZFC 的替换模式、分离模式。在 Lean 4 中，许多"公理"实为对一族类型统一的断言（对每个结构 `M` 各有一条）。审计时应按模式归并计数——478 条的"条数"若按模式归并，可能显著收缩；反之，一条模式覆盖的实例若有反例，则整条模式需重新陈述。

### 2.4 占位公理（placeholder axioms）——本仓库实测补充类别

抽样发现本仓库存在第四类事实上的公理：**结论为 `True` 的空公理**。其逻辑内容是重言式（任何系统都可证明 `True`），因此它们不增加系统的逻辑强度；其真实功能是**文档占位**——物理内容写在文档字符串里，等待形式化补全。占位公理本身是安全的（不会导致不一致），但它制造"已形式化"的错觉，是治理口径混乱的来源之一。审计处置：实义化（把文档字符串翻译为真实命题）或注销（删除并在 proof_status 登记为 CONJECTURE 级别的开放问题）。

## 3 基础系统的规模对比

478 条公理意味着什么？参照系如下：

| 系统 | 基础断言规模 | 说明 |
|------|-------------|------|
| ZFC 集合论 | 约 8–10 条（含替换/分离模式） | 承载几乎全部经典数学 |
| HOL（高阶逻辑） | 约 5–8 条核心推理规则 | Gordon & Melham (1993)；扩展仅限保守的定义机制 |
| CiC（Coq 的归纳构造演算） | 少数几条 typing judgments | 归纳类型由方案（schema）生成而非逐条公理 |
| Lean 4 核心 | 3 条标准公理（choice / propext / quotient） | Carneiro (2019)；Mathlib 数十万定理仅依赖此三件套 |
| HoTT | MLTT 规则 + univalence | Univalent Foundations Program (2013) |
| **TOE-SYLVA** | **478 条 axiom + 约 149 个 Agda postulate** | 本次审计对象 |

三点结构性推论：

1. **数量本身是信号**。成熟基础系统以个位数或十条级公理承载摩天大楼；478 条公理强烈暗示其中混杂了大量第 2.2、2.4 类条目。这不是道德指责，而是工程事实：Metamath 的经验（20–30% 可降级）若适用于本仓库，首轮清偿即可在不损失任何内容的前提下削去上百条。
2. **公理膨胀的技术代价**。Hales 等在 Flyspeck 项目（Kepler 猜想形式化，Hales et al., 2017）中确立的证明工程经验是：大规模形式化的维护成本与公理数量、证明冗余度呈超线性关系。公理未分层时，证明搜索的分支因子膨胀，自动化工具（`aesop`、`simp` 归约集）失效，回归测试成本随规模急剧上升。
3. **一致性的可证性边界**。按 Gödel 第二不完备性定理（Gödel, 1931），足够强的形式系统无法在自身内部证明其一致性。478 条公理的一致性论证最终必须诉诸外部元理论（模型论构造或更强系统的互译嵌入），任何"系统内部自证一致"的表述都应视为治理红线。

另需记录 de Bruijn 因子（Wiedijk, *The de Bruijn factor*）视角：形式化文本相对常规数学文本的膨胀比率应被控制在可接受范围；本仓库 6,000 万条平凡定理声明对应的 de Bruijn 因子是病态的，但其病根不在公理层，而在生成器层，治理方式见 DEVELOPMENT_DIRECTIONS.md §5.2，本文不展开。

### 4.2 案例 A：`ChernSimons.lean`——三条公理，三种命运

该文件（465 行，10 定理，3 公理，0 sorry）在 proof_status 中登记为 CLAIM。三条公理恰好覆盖三种类型：

**A1. `chernSimonsLevelInteger`（第 244–246 行）——可立即清偿的定义性扩展。**

```lean
axiom chernSimonsLevelInteger {M G} [GaugeGroup G] {P : PrincipalBundle M G}
    (A : Connection M G P) :
    ∃ (n : ℤ), chernSimonsLevel A (by trivial) = (n : ℝ)
```

但同一文件第 122–125 行已有已证定理：`theorem chernSimonsLevel_value ... : chernSimonsLevel A (by trivial) = 137 := by rfl`。由于 `chernSimonsLevel` 按定义恒为 137，该"公理"有显式证明（取 `n := 137` 后由 `chernSimonsLevel_value` 与 `Int.cast_ofNat` 级别的转换闭合）。**处置：降级为 theorem，一行级证明。** 它的存在直观说明：部分 axiom 是占位流程的产物，而非逻辑必需。

**A2. `alphaInverseIsChernSimonsLevel`（第 298–302 行）——不一致性风险。**

```lean
axiom alphaInverseIsChernSimonsLevel
    {M G} [GaugeGroup G] {P : PrincipalBundle M G}
    (A : Connection M G P)
    (alpha : ℝ) (h_alpha : alpha = 1 / 137.035999084) :
    alpha⁻¹ = chernSimonsLevel A (by trivial)
```

逐符号展开：由 `h_alpha`，`alpha⁻¹ = (1 / 137.035999084)⁻¹ = 137.035999084`（实数中非零元的 `1/x` 之逆为 `x`）；由已证定理 `chernSimonsLevel_value`（`rfl`），右端 `= 137`。三式合流得 `(137.035999084 : ℝ) = 137`，进而 `0.035999084 = 0`——**`False` 可证**。该公理自己的文档字符串（第 296 行）已承认"当前既缺少从因果网络到流形的严格映射，也缺少网络谱性质到拓扑不变量的收敛证明，属于研究级开放问题"。

诊断：物理本意是 proof_status 登记的 CLAIM 级断言 **α⁻¹ ≈ n_CS = 137**（近似相等，误差约 0.036），但形式化时写成了精确等号。按 §3 第 3 点的标准，这不是"尚待证明的公理"，而是**按字面陈述即可炸毁整个系统一致性的过强断言**。**处置（最高优先级）：改写为带显式误差界的近似命题（如 `|alpha⁻¹ - chernSimonsLevel A ⋯| < 0.04`）或移入隔离命名空间，与可信内核切断；在 proof_status 维持 CLAIM 直至误差界版本获证。** 本条是"公理审计必要性"最直观的证据：审计不是文书工作，而是一致性防御。

**A3. `causalNetworkChernSimonsLevel`（第 358–361 行）——实质性本原候选。**

断言因果网络（`SimpleGraph V`，附幂律参数 γ = 2.9、聚类系数 C = 0.4）与 Chern-Simons 能级的数值关系。它不属前两类：无法由现有定义导出，陈述也非重言式。它是 SYLVA 框架"网络→几何"桥接假设的真实承载者。**处置：登记为本原公理候选，标注经验依据与可证伪条件（proof_status v7.24 已配可证伪性条件），纳入第 5 层（物理核心层）管理。**

### 4.3 案例 B：`EinsteinCartan.lean`——六条占位公理

该文件（484 行，14 定理，6 公理，1 sorry）登记为 CLAIM。六条公理——`einsteinEquation`（119–123）、`cartanTorsionEquation`（157–159）、`emergentMaxwellEquations`（194–196）、`covariantConservation`（232–234）、`chargeConservation`（265–266）、`cosmologicalConstantFromNetwork`（306–308）——**全部以 `: True` 结尾**，即 §2.4 定义的占位公理。以 `einsteinEquation` 为例，其文档字符串自述："**Status:** Placeholder axiom. The full Einstein equation requires the differential geometry framework which is not yet complete in Mathlib4."

评价：占位公理不威胁一致性（`True` 可由任何系统证明），但六条并列意味着该文件的"Einstein-Cartan 引力已形式化"印象与事实有距离——已证的 14 条定理（度规对称性、挠率反称性等）均为定义的直接展开，核心场方程的逻辑内容为空白。**处置：实义化（随 mathlib4 微分几何进度逐条翻译为真实命题）或降级为 CONJECTURE 级开放问题登记；在此之前，该模块在仪表盘上不得计入"物理核心已覆盖"。**

### 4.4 案例 C：`FourForcesUnification.lean`——实质性物理公理

## 5 分层清偿路线

### 5.1 五层架构

将全量公理（含 Agda postulate）按依赖关系统编入五层，层间只许向下依赖：

- **L0 逻辑-类型基础层**：Lean 4 标准三件套（choice / propext / quotient）及命题/函数外延性变体；
- **L1 集合-序结构层**：Zorn 引理、良序定理等（多数应直接复用 Mathlib）；
- **L2 分析-拓扑基础层**：实数构造、度量空间、拓扑空间公理（复用 Mathlib，自建部分须证明对 L0/L1 保守）；
- **L3 代数-范畴工具层**：群、环、模、范畴论基础（复用 Mathlib 类型类层次与 bundled structures）；
- **L4 物理核心层**：Chern-Simons、Einstein-Cartan、Spectral Action、因果网络桥接等本原物理假设，逐条附经验依据与可证伪条件。

### 5.2 清偿操作序列（四步走）

1. **登记**：产出机器可读《公理登记表》——每条公理记录类别（§2 四分）、所在层、物理/数学重要性、可清偿性评估、proof_status 关联条目。这是全部后续工作的账本。
2. **降级**：全量扫描 A1 型公理（存在不引入新常量的证明者），批量转为 theorem。按 Metamath 经验预估首轮可清偿 20–30 条；这是唯一能实质提升真实证明率（DEVELOPMENT_DIRECTIONS.md §5.1 口径）的低成本操作。
3. **实义化**：占位公理（`: True` 类）逐条翻译为真实命题；无法翻译者降级为 CONJECTURE 级开放问题。A2 型过强断言在翻译时强制带误差界。
4. **独立化**：对留存的本原候选做独立性与保守性分析（模型论构造或互译嵌入），形成最小独立集；一致性论证按 §3 第 3 点诉诸外部元理论。

### 5.3 与课程链的协同

清偿所得的"可信内核"应立即被课程式形式化路线消费（DEVELOPMENT_DIRECTIONS.md §2.2）：Zp/Qp → Dirichlet 特征与 L-函数 → Dedekind 整环的课程链在零新增公理约束下开发，每完成一段即为 L2/L3 层提供一次实战回归测试。拓扑里程碑序列（P0：`ℝⁿ ≇ ℝᵐ`；P1：Brouwer 不动点；P2：Jordan 曲线定理；P3：Seifert-van Kampen；P4：Mayer-Vietoris）作为中层表达力的检验标尺。

### 5.4 量化里程碑

- **6 个月内**：登记表覆盖 478 条 axiom + 149 个 postulate 的 100%；A2 修复完成；首轮降级 ≥ 20 条；
- **18 个月内**：占位公理清零（全部实义化或降级）；物理核心层登记完毕；产生 CHSH 之外的第二个 THEOREM；
- **2–5 年**：物理核心 CLAIM→THEOREM 至少 1 例（优先 Chern-Simons 不变量定理链）；最小独立集与外部一致性论证初稿；
- **5–10 年**：逆向数学审计（确定 478 条中的逻辑必要项）；Agda postulate 清零（依赖 Linux ≥16GB 环境）。

## 6 与 proof_status 治理的衔接

审计结果直接改写治理规则的执行层：

1. **晋级标准**：CLAIM→THEOREM 的充要条件设为"在可信内核（L0–L3 + 已登记 L4 公理）中完成零 sorry 推导，且 `#print axioms` 输出仅含已登记条目"；凡依赖未登记公理者一律留级 CLAIM。
2. **THEOREM\* 口径维持**：费马大定理、Langlands 基本引理等"Mathlib 功劳"条目维持 THEOREM\* 标注，不因课程链复用 Mathlib 而改级——诚实归属是治理公信力的基础。
3. **CONJECTURE 的吸收功能**：实义化失败的占位公理与 A2 改写前的原始断言，统一登记为 CONJECTURE 并附可证伪条件（沿用 v7.24 传统）。

## 7 风险与开放问题

1. **独立性证明的成本**：L4 物理公理的独立性证明可能需要力迫法或模型论构造，成本高昂；短期以"相对一致性 + 隔离"替代完全独立性。
2. **语义幻觉**：自动形式化文献（Lean Atlas，arXiv:2604.16347）指出类型检查通过 ≠ 命题忠实表达数学意图。A2 案例正是语义幻觉的本地实例——它通过了类型检查，却背叛了"近似相等"的物理意图。公理登记表的"命题-意图对齐"栏因此为必填项。
3. **多智能体工具的双刃性**：MASA（arXiv:2510.08988）式多智能体分工可加速登记与翻译（Lean Copilot，arXiv:2404.12534 已在课程链试用规划中），但所有机器产物须经编译器硬门 + 人工语义复核软门（DEVELOPMENT_DIRECTIONS.md §4.2）。
4. **Gödel 边界的纪律**：任何"系统已自证一致"的表述为治理红线（§3 第 3 点）；一致性叙事只许使用"相对一致""外部模型"措辞。

## 8 结论

478 条公理不是 478 份同质债务。抽样表明它们是可分层的混杂体：存在可一行清偿的定义性扩展、等待实义化的 `: True` 占位、需登记保护的实质性物理假设，以及至少一处必须立即修复的过强断言（`alphaInverseIsChernSimonsLevel`，按现有定义展开即致 `False`）。"登记—降级—实义化—独立化"四步路线把 P2 从口号变为可排期的工程序列；五层架构与 proof_status 晋级标准则保证清偿成果被治理系统吸收而非再次流失。从 478 条公理到可信基础的距离，不是 478 场证明战役，而是一次审计、一次分层、以及纪律化的四步清偿。

## 0 引言：从"又一个几何"到"分类问题"

### 0.1 问题

下列方程看似无关：热方程 ∂ₜρ = Δρ；Fokker–Planck 方程 ∂ₜρ = Δρ + ∇·(ρ∇V)；多孔介质方程 ∂ₜρ = Δ(ρᵐ)；聚集方程 ∂ₜρ = ∇·(ρ∇(W*ρ))。Otto 学派的发现（JKO 1998 [8]；Otto 2001 [7]）是：它们全是某个能量泛函在概率测度空间 (𝒫₂, W₂) 上的**梯度流**。这不是类比而是精确陈述——W₂ 是作用量最小化距离（Benamou–Brenier 2000 [6]），梯度流是能量的最速下降。

但反过来问才有内容：**什么样的耗散方程承认梯度流结构？** Navier–Stokes 也耗散（黏性项），为什么它不在名单上？回答这个问题需要把"梯度流"从具体方程的偶然性质提升为可判定的结构性质——这正是本文的分类问题。物理直觉给出的候选答案是 Onsager 互反/细致平衡 [22][23]；本文把这个直觉变成光滑情形下的定理（定理 2.2、2.3），并用反例钉死边界（§2.5、§2.6）。

## 1 最优传输基础（极简回顾，指向 07）

本节只固定记号；证明与历史见 [12][13] 及 07 号 §3。

### 1.1 Monge–Kantorovich 与 W₂

X = ℝ^d 或紧致黎曼流形 (M, g)，𝒫₂(X) 为二阶矩有限的概率测度集。耦合集 Π(μ,ν) = {π ∈ 𝒫(X×X) : 两边际为 μ, ν}（Kantorovich 1942 [2] 的松弛；Monge 1781 [1] 的原始映射问题）。二次成本给出

$$W_2^2(\mu,\nu) := \inf_{\pi\in\Pi(\mu,\nu)} \int_{X\times X} d(x,y)^2\,d\pi(x,y)$$

W₂ 是 𝒫₂(X) 上的度量，度量化弱收敛加二阶矩收敛（Villani 2009, Ch. 6 [12]）。【S1】

### 1.2 Brenier 极分解与 McCann 插值

**Brenier 定理**（1991 [3]）：μ 绝对连续 ⇒ 最优耦合由映射诱导 π = (id × T)_# μ，且 T = ∇φ 为凸函数梯度（极分解：任意向量场 = 梯度 ∘ 保测映射）。【S1】

**McCann 位移插值**（1997 [4]）：μ_t := ((1−t)·id + tT)_# μ 是 (𝒫₂, W₂) 中的常速测地线；μ 绝对连续时唯一。由此 McCann 定义**位移凸性**（沿位移插值的凸性），成为 W₂ 几何的曲率工具。【S1】

### 1.3 Benamou–Brenier 动力学与 Otto 度量

**Benamou–Brenier 公式**（2000 [6]）：

$$W_2^2(\mu_0,\mu_1) = \inf_{(\mu_t,v_t)} \int_0^1\!\!\int_X |v_t|^2\,d\mu_t\,dt,\qquad \partial_t\mu_t + \nabla\cdot(\mu_t v_t) = 0$$

W₂ 是"动能最小化"的作用量距离。【S1】

**Otto 形式黎曼结构**（2001 [7]）：切向量表示为 s = −∇·(ρ∇φ)，度量

$$g^{W_2}_\rho(s_1,s_2) = \int_X \rho\,\langle\nabla\varphi_1,\nabla\varphi_2\rangle\,dx$$

泛函 E 的 W₂ 梯度为 grad E = −∇·(ρ∇(δE/δρ))，故梯度流方程为

$$\partial_t\rho = \nabla\cdot\big(\rho\,\nabla\tfrac{\delta E}{\delta \rho}\big)$$

取 E = ∫ρlogρ（Boltzmann 熵，negative）得热方程；E = ∫(ρlogρ + ρV) 得 Fokker–Planck；E = (m−1)⁻¹∫ρᵐ 得多孔介质方程。【S1，逐条为 [7][8][9]】

## 2 梯度流结构的分类定理

### 2.1 变分三元组与问题形式化

**定义 2.1.1**（耗散动力学的变分结构）𝒫(M) 上的密度动力学由连续性方程给出：

$$\partial_t\rho_t + \nabla\cdot(\rho_t\, v[\rho_t]) = 0$$

其中 v[·] 是本构律（density ↦ vector field）。称该动力学承认 **Wasserstein 梯度流结构**，若存在泛函 E : 𝒫(M) → ℝ 使 v[ρ] = −∇(δE/δρ)。称三元组 (E, W₂, v) 为一个**变分实现**。

**问题（分类）**：给定本构律 v[·]，判定变分实现是否存在；存在时给出 E；不存在时给出结构性障碍。

该问题有两层：**几何层**（v 是否是势场）与**泛函层**（标量场 ψ[ρ] 是否是某泛函的一阶变分）。两层各有障碍，分别对应物理上的"非梯度力"与"非互反响应"。

### 2.2 Wasserstein 切空间的加权 Helmholtz 分解

**引理 2.1**（加权 Helmholtz 分解）【S2 本文自证】。设 M 紧致无边（或 ℝ^d 且诸场满足衰减），ρ 光滑严格正。则任意光滑向量场 v 唯一分解为

$$v = \nabla\varphi + w,\qquad \nabla\cdot(\rho\, w) = 0$$

且 ∫_M ρ⟨∇φ, w⟩dx = 0；即 L²(ρ; TM) = ∇C^∞ 的 L²(ρ)-闭包 ⊕ {w : ∇·(ρw)=0} 为正交直和。

**证明**：存在性：解椭圆方程 ∇·(ρ∇φ) = ∇·(ρv)。右端在紧致无边 M 上积分为零（散度定理），满足 Neumann 可解条件；加权 Laplacian Δ_ρ := ρ⁻¹∇·(ρ∇·) 在 ∫φ dρ = 0 的补空间上自伴且谱隙严格正（ρ ≥ c > 0，标准椭圆理论），解存在。置 w := v − ∇φ，即得 ∇·(ρw) = 0。正交性：∫ρ⟨∇φ, w⟩ = −∫φ∇·(ρw) = 0（分部积分，无边）。唯一性：两分解之差给出 ∇φ' 同时满足 ∇·(ρ∇φ') = 0，乘以 φ' 积分得 ∫ρ|∇φ'|² = 0，故 φ' 常值。∎

**注**：该分解正是 Otto 切空间构造的线性代数内核——Tan_ρ 𝒫₂ = ∇C^∞ 的 L²(ρ)-闭包（[11] Ch. 8 的严格版本即取此闭包）。w 分量是"不搬质量"的无穷小环流：它满足连续性方程的齐次部分，对应的密度变率为零。

### 2.3 分类主定理（光滑情形）

**定义 2.1.2**（泛函可积条件 / 泛函级 Onsager 对称）标量场映射 ψ : ρ ↦ ψ[ρ] 称为**可积的**，若存在 E 使 ψ[ρ] = −δE/δρ + const。可积的必要条件（亦将证其充分）是 Gâteaux 导数的对称性：对一切零均值变分 σ₁, σ₂，

$$\int_M \sigma_1\, D\psi[\rho](\sigma_2)\,dx = \int_M \sigma_2\, D\psi[\rho](\sigma_1)\,dx$$

**定理 2.2**（梯度流结构判据）【S2 光滑情形自证；非光滑推广 S3】。设 M 紧致无边，本构律 ρ ↦ v[ρ] 光滑且局部（v[ρ](x) 只依赖 ρ 在 x 的 jet）。则下列等价：

(i) 存在变分实现 (E, W₂, v)；
(ii) v[ρ] 逐点（对 ρ）为势场——即引理 2.1 分解中 w[ρ] ≡ 0——且标量映射 ψ[ρ]（v = ∇ψ）满足泛函可积条件（定义 2.1.2）；
(iii) 线性化陈述：在任意背景 ρ 处，线性化流算子 L_ρ : σ ↦ −∇·(ρ ∇(Dψ[ρ]·σ)) 关于加权内积 ⟨σ₁,σ₂⟩_ρ = ∫σ₁σ₂ρ⁻¹dx 自伴。

**证明**：(i)⇒(ii)：v = −∇(δE/δρ) 直接给出 w ≡ 0 与 ψ = −δE/δρ；E 的二阶 Gâteaux 导数对称（光滑泛函的 Schwarz 定理）给出可积条件。(ii)⇒(i)：用路径积分构造原泛函。固定参考密度 ρ₀，对任意 ρ₁ 取线性插值 ρ_t = (1−t)ρ₀ + tρ₁（t ∈ [0,1]，全程严格正），定义

$$E(\rho_1) := -\int_0^1\!\!\int_M \psi[\rho_t]\,\partial_t\rho_t\,dx\,dt$$

对称性条件保证该积分与路径无关：两条路径 ρ_t, ρ̃_t 张成二维参数族 ρ_{t,s}，围道差为 ∮⟨ψ, dρ⟩，由 Green 公式化为曲面积分 ∫∫ [Dψ(σ₁)·σ₂ − Dψ(σ₂)·σ₁] dsdt = 0（被积式恰为对称条件之差）。于是 E 良定，且直接求导得 δE/δρ = −ψ（差一个由 ∫ρ=1 约束吸收的常数），故 v = ∇ψ = −∇(δE/δρ)，(i) 成立。(ii)⇔(iii)：把加权内积展开成分部积分形式 ⟨σ₁,L_ρσ₂⟩_ρ = −∫σ₁ρ⁻¹∇·(ρ∇(Dψ·σ₂)) = ∫ρ⟨∇(σ₁/ρ), ∇(Dψ·σ₂)⟩。交换 σ₁↔σ₂ 后再分部积分回写，差式归结为 ∫σ₁Dψ(σ₂) − ∫σ₂Dψ(σ₁)，故 L_ρ 关于 ⟨·,·⟩_ρ 自伴 ⟺ Dψ 对称（标准变分计算的严格展开属初等演算，此处从略一行）。∎

**缺口标注（S3 部分）**：非光滑推广（ρ 仅可测、E 仅下半连续）需要以 AGS 的 AC 曲线与 metric slope 语言重述 (i)，此时 (ii) 的"逐点势场"应替换为"速度场属于切空间闭包"（这在 [11] Ch. 8 中恰是 AC 曲线的刻画，故真正的非平凡内容只剩泛函层的对称条件如何下放到度量情形——本文不解决，登记为开放问题 6.2 的一部分）。

**物理释读**：条件 (ii) 的两部分正是热力学两支柱的泛函化——w ≡ 0 对应"无稳态环流"（平衡态/细致平衡的几何形式）；Dψ 对称对应 **Onsager 互反关系**（[22]：流 = L·力 中矩阵 L 对称）。命题 2.5 把这个对应钉死。

### 2.5 反例 I：非平衡稳态扩散（细致平衡破缺）

**定理 2.3**（Markov 扩散版本：纯梯度 ⟺ 细致平衡）【S2 本文自证（计算）】。考虑 ℝ^d 上扩散的 Kolmogorov 前方程

$$\partial_t\rho = \Delta\rho - \nabla\cdot(\rho\, b)$$

漂移 b 光滑，存在光滑严格正不变测度 ρ_∞。对 b 作关于 ρ_∞ 的引理 2.1 分解：b = −∇V + ℓ，其中 ρ_∞ = Z⁻¹e^{−V} 且 ∇·(ρ_∞ ℓ) = 0。则：

(i) ∂ₜρ = ∇·(ρ∇(δH/δρ)) − ∇·(ρℓ)，其中 H(ρ) := KL(ρ‖ρ_∞) = ∫ρlog(ρ/ρ_∞) 是相对熵；
(ii) 方程是 H 的 W₂ 梯度流 ⟺ ℓ ≡ 0 ⟺ 扩散关于 ρ_∞ 可逆（细致平衡）。

**证明**：(i) 逐行展开：Δρ − ∇·(ρb) = ∇·(ρ∇logρ) − ∇·(ρ(−∇V+ℓ)) = ∇·(ρ∇(logρ+V)) − ∇·(ρℓ)。而 δH/δρ = logρ − logρ_∞ + 1 = logρ + V + (1+logZ)，常数不进入梯度。得 (i)。(ii) ⟸方向：ℓ≡0 即 (i) 中只剩梯度项。⟹方向：若方程同时是某 E 的梯度流与 (i) 的和式，则在稳态 ρ_∞ 处梯度项为零（δH/δρ|_{ρ_∞} = const），但 −∇·(ρ_∞ℓ) = 0 虽成立，对非稳态 ρ 一般而言 −∇·(ρℓ) ≠ 0 且该项不能写成任何泛函的 W₂ 梯度——因为它沿 ρ_∞ 加权正交于一切梯度场：对任意 φ，∫ρ⟨∇φ, ℓ⟩ 在 ρ=ρ_∞ 处为零但 ℓ 自身非梯度（引理 2.1 分解的唯一性，ℓ 的 w 分量即 ℓ 自身非零）。由定理 2.2 (ii) 的 w≡0 条件被破坏，梯度结构不存在。可逆性等价是扩散过程的标准事实（漂移为 −∇V 型 ⟺ 生成元在 L²(ρ_∞) 自伴 ⟺ 细致平衡）。∎

**物理含义**：ℓ ≠ 0 的系统有**非平衡稳态流** J_st = ρ_∞ℓ（概率流环），稳态持续产熵。这类方程的动力学 = 梯度流（弛豫部分）+ 正交输运（环流部分），**恰是 GENERIC/亚稳框架中"耗散括号 + Poisson 括号"分解在 W₂ 上的化身**；其 Markov 链版本即 [21] 的正则结构/正交分解。定理 2.3 给出的是：该分解在 W₂ 几何下是**正交直和分解**，两项的地位不对称——梯度项耗散 H，环流项保持 H 的一级变分加权正交。

### 2.6 反例 II：Navier–Stokes 与惯性

**定理 2.4**（Navier–Stokes/Euler 的非梯度性）【S3 论证＋S1 部件】。不可压 Navier–Stokes 方程组不是 (𝒫₂, W₂) 上任何泛函的梯度流；其无黏极限（Euler）恰是 W₂ 上的 **Hamilton 流**而非梯度流。

**论证**：三层障碍。(a) **时间阶数**：梯度流是一阶过阻尼动力学（力 = 速度的线性函数）；NS 含惯性 ∂ₜu + (u·∇)u，是二阶/加速度型关系，不存在 (E, W₂) 使其第一变分给出加速度——梯度流的轨迹能量单调，而惯性系统能量可在动能与内能间往返。(b) **对流项的正交性**：对流加速度 (u·∇)u 对应密度—动量系统上的环流型分量；在不可压约束下它保持动能的梯度投影结构而与熵产生无关（黏性项 −νΔu 才是耗散，且它作用于速度场而非密度场，不在 (𝒫₂, W₂) 的对象层级上）。(c) **正面刻画**（S1 部件）：Ambrosio–Gangbo 2008 [15] 证明 Euler 类方程是 W₂ 几何上的 Hamilton ODE（辛形式由质量流的旋转部分给出）——同一几何、相反的结构类型：Hamilton 流保辛、梯度流产熵。∎（缺口：(b) 的严格直和表述需要密度—动量双变量的几何，超出本文 𝒫(M) 单变量框架，登记至 §6 开放问题。）

**分类表（终版）**：

| 类型 | 判据 | 实例 |
|------|------|------|
| I 型：W₂ 梯度流 | 定理 2.2 (ii) 成立，耗散二次 | 热/FP/PME/聚集 |
| II 型：其他迁移率/广义结构 | 耗散二次但 m(ρ)≠ρ，或耗散非二次 | Cahn–Hilliard、Maas 链、cosh 反应扩散 |
| III 型：无梯度结构 | w≢0（环流）或时间二阶（惯性） | 非平衡稳态扩散、NS/Euler |

### 2.7 Onsager 互反 ⟺ 度规对称性

**命题 2.5**【S2 线性情形；S3 一般表述】。近平衡线性化：流 J = −L(ρ_∞)∇(δE/δρ 的线性化)，响应算子 L(ρ_∞)ξ = −∇·(ρ_∞ξ)。则 L 关于 L² 内积自伴且半正定，其对称性正是 Onsager 互反关系；反之，任何"流 = 对称正定响应算子 × 热力学力"的线性不可逆热力学都定义一个（形式）黎曼度规——**Onsager 矩阵的逆就是度规张量**。

**证明**：自伴性：∫ξ₁·(−∇·(ρ_∞ξ₂)) = ∫ρ_∞⟨ξ₁,ξ₂⟩（分部积分）对称；半正定：∫ξ·Lξ = ∫ρ_∞|ξ|² ≥ 0。逆命题：给定对称正定算子 L，定义切空间内积 g(σ₁,σ₂) := ⟨σ₁, L⁻¹σ₂⟩ 即得度规，梯度流 ∂ₜρ = −L∇δE/δρ 恰为"流=L·力"。∎（S3 注：远离平衡时 L 依赖 ρ，"Onsager 矩阵 = 度规逆"仍形式成立——W₂ 的 L(ρ)ξ = −∇·(ρξ) 正是 ρ-依赖的迁移率算子；严格性依赖椭圆正则，与定理 2.2 的 S3 缺口同源。）

## 3 能量耗散等式与熵产生

### 3.1 De Giorgi 框架：斜率与 EDE

度量空间 (𝒳, d) 上泛函 E 的**局部斜率**与 AC 曲线的**度量导数**：

$$|\partial E|(\mu) := \limsup_{\nu\to\mu}\frac{(E(\mu)-E(\nu))^+}{d(\mu,\nu)},\qquad |\dot\mu_t| := \lim_{h\to0}\frac{d(\mu_{t+h},\mu_t)}{|h|}$$

**定义 3.1.1**（能量耗散等式，EDE）AC 曲线 μ_t 满足 EDE，若

$$E(\mu_T) + \frac12\int_0^T\Big(|\dot\mu_t|^2 + |\partial E|^2(\mu_t)\Big)dt = E(\mu_0)$$

**定理 3.1**（EDE ⟺ 梯度流）【S1，Ambrosio–Gigli–Savaré [11]】。设 E 在 (𝒳, d) 上 λ-测地凸（EVI 意义）。则 AC 曲线 μ_t 是 E 的（EVI）梯度流 ⟺ 它满足 EDE；此时 t ↦ E(μ_t) 绝对连续且

$$-\frac{d}{dt}E(\mu_t) = |\dot\mu_t|^2 = |\partial E|^2(\mu_t)\quad \text{a.e. } t$$

链条是：Young 不等式给出 d/dt E ≥ −|μ̇||∂E| ≥ −½(|μ̇|²+|∂E|²)（恒成立）；EDE 要求等号，等号 ⟺ |μ̇| = |∂E| 且同向。（[11] Thm 11.1.3 及 Ch. 11 的 W₂ 特化；Daneri–Savaré 2008 [14] 给出 EVI 与位移凸性的欧氏演算。）

### 3.2 定理 B：熵产生率 = W₂ 斜率平方

设定：Fokker–Planck 方程 ∂ₜρ = Δρ + ∇·(ρ∇V)，V 光滑且 e^{−V} 可积，ρ_∞ = Z⁻¹e^{−V}。相对熵 H(ρ) := KL(ρ‖ρ_∞)，相对 Fisher 信息

$$I(\rho) := \int \rho\,\big|\nabla\log\tfrac{\rho}{\rho_\infty}\big|^2 dx$$

**定理 3.2**（熵产生 = 斜率平方）【S2 自证（组装 S1 部件）】。沿 Fokker–Planck 解 ρ_t（光滑、衰减充分），三个量恒等：

$$\underbrace{-\frac{d}{dt}H(\rho_t)}_{\text{熵产生/自由能耗散率}} = \underbrace{I(\rho_t)}_{\text{Fisher 信息}} = \underbrace{|\partial H|_{W_2}^2(\rho_t)}_{W_2\text{ 度量斜率平方}} = \underbrace{|\dot\rho_t|_{W_2}^2}_{\text{度量速度平方}}$$

**证明**：第一等号（直接计算）：d/dt H = ∫(log(ρ/ρ_∞)+1)∂ₜρ = ∫(log(ρ/ρ_∞)) ∇·(ρ∇log(ρ/ρ_∞)) = −∫ρ|∇log(ρ/ρ_∞)|² = −I（分部积分；用 δH/δρ = log(ρ/ρ_∞)+1 与方程 ∂ₜρ = ∇·(ρ∇δH/δρ)）。第二等号：W₂ 斜率恒等式 |∂H|²_{W₂} = I 是 Otto 演算的标准内容（Otto–Villani 2000 [10]；严格版本 [11] Lemma 10.4.1：相对熵的斜率平方等于其 Fisher 信息，含"斜率 ≤ √I 一般成立、对数凹参考测度下相等"的精确条件）。第三等号：速度场 v_t = ∇log(ρ_t/ρ_∞)（由方程直接读出），度量速度平方 = ∫ρ|v|² = I。∎

**注**：-dH/dt = I 在非平衡统计力学中正是总熵产生率的定义（k_B = 1 单位；Seifert 2012 [39] 的系综层定义）。故定理 3.2 的字面内容是：**物理熵产生率是纯粹的几何对象——相对熵这个泛函在 Otto 度规下的斜率平方**。38 号文 §2.4 在参数流形上定义了另一个"几何熵产生"（Σ̇ = g_ij θ̇ⁱ(η₀ʲ−η_tʲ)），二者的关系由命题 3.4 给出。

### 3.3 EDE 作为第二定律的等式化；OU 显式验证

**命题 3.3**（Ornstein–Uhlenbeck 流显式验证）【S2 逐行计算】。取 V(x) = |x|²/2（d=1），ρ_∞ = N(0,1)，初值 ρ_0 = N(m₀, σ₀²)。OU 流的解为 ρ_t = N(m_t, σ_t²)，m_t = m₀e^{−t}，σ_t² = 1 + (σ₀²−1)e^{−2t}。则

$$H(t) = \tfrac12\big(m_t^2 + \sigma_t^2 - 1 - \log\sigma_t^2\big),\qquad I(t) = m_t^2 + \frac{(\sigma_t^2-1)^2}{\sigma_t^2}$$

且 −Ḣ(t) = I(t) 逐点成立。

**验证**：Ḣ = m_tṁ_t + σ̇_t(σ_t − 1/σ_t)；ṁ_t = −m_t；d(σ_t²)/dt = −2(σ_t²−1) ⇒ σ_tσ̇_t = −(σ_t²−1)。代入：Ḣ = −m_t² − (σ_t²−1)²/σ_t² = −I(t)。另一边 I 的直接计算：∂_x log(ρ/ρ_∞) = −(x−m_t)/σ_t² + x，以 x = m_t + σ_tξ（ξ 标准正态）代入得期望 m_t² + σ_t²(1−σ_t^{−2})² = m_t² + (σ_t²−1)²/σ_t²。两者相等。∎

EDE 读法：定理 3.1 的等式 −Ḣ = |∂H|² 不是"耗散 ≥ 0"的不等式，而是**耗散恰为斜率平方的等式**——第二定律在这条轨道上被完全定量化：每一单位自由能的下降都登记为 Otto 度规下速度的平方。38 号文的 Jarzynski 等式（其定理 2.9，⟨e^{−βW}⟩ = e^{−βΔF} [37]）则是同一内容的**路径测度层**版本：EDE 是其系综平均后的确定性骨架。

### 3.4 与 38 号文涨落定理的对接

**命题 3.4**（两种熵产生定义的线性层同一性）【S2 线性计算；S3 一般层论证】。(i) 在 Onsager 线性律 J = LX（X = 热力学力 = −∇δE/δρ 的坐标写法）下，38 号文 §2.4 的流-力双线性熵产生 Σ̇ = ⟨X, J⟩ = ⟨X, LX⟩ 与本文的斜率平方是**同一个二次型的两种坐标写法**：命题 2.5 已证 L = 度规逆，故 ⟨X, LX⟩ = ‖X‖²_{L} = |∂E|²。(ii) 一般（非线性）层：涨落定理（Jarzynski [37]、Crooks [38]）控制的是功/熵产生的**全部分布**（指数矩、正反路径比），EDE 只控制其系综平均的一阶矩结构；二者经大偏差理论衔接——Mielke–Peletier–Renger 2014 [20] 证明 Markov 过程的大偏差率函数在近平衡二次化后 Legendre 对偶出广义梯度结构（Onsager–Machlup [23] 纲领的严格化）。

**缺口标注**：(i) 的一般化（任意时刻、任意状态，而非近平衡）需要 38 号文定义中 KL 时间导数与本文斜率的显式换算公式，本文未给出——38 号的 Σ̇ 定义依赖参数化族的选取（其附录 E.5.1 已自标"非稳态自然参数化"为开放），换算公式依赖该选取，诚实标注为未闭合。(ii) 的"EDE = 涨落定理的期望层"目前是经 [20] 的**结构性对应**，不是定理；严格化路径见开放问题 6.3。

## 4 Sinkhorn 的几何：从交替投影到测地线极限

### 4.1 熵正则化与 Schrödinger 问题

熵正则化 OT（Sinkhorn 1964 [24] 的矩阵缩放原型；Cuturi 2013 [25] 使其成为计算主力；综述 [26]）：

$$\mathrm{OT}_\varepsilon(\mu,\nu) := \min_{\pi\in\Pi(\mu,\nu)} \int c\,d\pi + \varepsilon\,\mathrm{KL}(\pi\|\mu\otimes\nu)$$

其动力学化身是 **Schrödinger 问题**：以方差 ε 的 Brownian 参考测度 R_ε 为参照，在两端边际固定为 μ, ν 的路径测度中最小化 ε·KL(·‖R_ε)；最优路径测度的时-t 边际给出**熵插值** μ_t^ε（Sinkhorn 路径）。07 号 §3.3 已整理：Sinkhorn 迭代 = 两个边际约束流形间的交替 Bregman/I-投影（[27] 的迭代 Bregman 投影口径），熵正则化把 OT 接进对偶平坦信息几何。本文的问题是：**ε→0 时这条"被熵抹平的路径"以什么几何方式退回 McCann 测地线？**

### 4.2 熵 Benamou–Brenier 公式：动能 + Fisher 长度

**定理 4.1**（熵作用量分解；Gigli–Tamanini 2020 [31]）【S1 引用；常数约定见附录 A 注记】。在 RCD*(K,N) 度量测度空间（含 ℝ^d 与紧致流形）上，Schrödinger 问题的值（经边际熵中心化后）具有 Benamou–Brenier 型动力学表示：存在常数 c(ε) ≍ ε²（按参考热核约定，本文取 c(ε) = ε²/4）使

$$\mathrm{Sch}_\varepsilon(\mu,\nu) = \inf_{(\mu_t,v_t)} \int_0^1\!\!\int \Big(|v_t|^2 + \frac{\varepsilon^2}{4}\,|\nabla\log\mu_t|^2\Big)d\mu_t\,dt,\qquad \partial_t\mu_t + \nabla\cdot(\mu_t v_t)=0$$

即熵正则化在 Benamou–Brenier 作用量上**加了一项 Fisher 信息的时间积分**。同结果的对偶与 RCD 推广见 [31]；Mikami 2004 [30] 与 Léonard 2012 [28] 给出零噪声极限与大偏差源头。

**几何释读（本文的表述贡献）**：定义路径 γ = (μ_t) 的 **Fisher 长度**

$$\mathrm{FL}(\gamma) := \int_0^1 I(\mu_t)\,dt,\qquad I(\mu) = \int \mu\,|\nabla\log\mu|^2 dx$$

则定理 4.1 说：熵作用量 = Otto 动能 + (ε²/4)·Fisher 长度。**注意第二项不含 v_t——它不是度规项，而是路径上的"势能项/张力项"**：熵插值 μ_t^ε 不是某个 ε-度规的测地线，而是 Newton 型变分问题 δ∫(½‖γ̇‖²_Otto + (ε²/4)I(γ_t))dt = 0 的临界路径，所受"力"为 −(ε²/4)grad I（Fisher 信息作为密度路径的弯曲罚）。这个"动能+势能"图像是 Schrödinger 桥的正确几何化，比"ε-度规的测地线"图像更诚实——后者在文献口语中常见但严格说不成立（势能项不可吸收进切向量范数）。

### 4.3 定理 C：显式定量夹逼与值收敛

**定理 4.2**（值的两-sided 夹逼）【S2 自证（在 [31] 恒等式基础上的推论组装）】。设 μ, ν 间存在常速 W₂ 测地线 γ⁰ 满足 FL(γ⁰) < ∞（例如 μ, ν 光滑、严格正、紧支撑——McCann 插值保持这些性质）。则对一切 ε > 0，

$$\frac12 W_2^2(\mu,\nu) \;\le\; \mathrm{Sch}_\varepsilon(\mu,\nu) \;\le\; \frac12 W_2^2(\mu,\nu) + \frac{\varepsilon^2}{4}\,\mathrm{FL}(\gamma^0)$$

**证明**：下界：Fisher 项非负 ⇒ 熵作用量 ≥ 纯动能项，对所有候选路径取下确界 ⇒ Sch_ε ≥ inf 动能 = ½W₂²（约定因子依定理 4.1 的 ½ 口径）。上界：取特定候选路径 γ = γ⁰（与其最优速度场，McCann 测地线满足连续性方程），其动能 = ½W₂²，故 Sch_ε ≤ ½W₂² + (ε²/4)FL(γ⁰)。∎

**评注**：该夹逼把"ε→0 时 Sch_ε → ½W₂²"（Léonard 2012 [28] 的 Γ-收敛结论）**量化**为 O(ε²) 速率，常数显式（极限测地线的 Fisher 长度）。下界平凡但上界非常trivial——它要求测地线的 Fisher 长度有限，这正是端点奇异性的藏身之处（t→0,1 时 I(μ_t) 可能爆破）；FL(γ⁰) < ∞ 假设的弱化（截断逼近）是标准技术，本文不展开。

### 4.4 猜想 D：路径收敛的几何形式

**猜想 4.4**（Sinkhorn 路径 → W₂ 测地线，Γ/Mosco 口径）【S4 诚实猜想】。设 μ 绝对连续（Brenier 定理适用，极限测地线唯一）。则 ε→0 时：(D1) 熵插值 γ^ε 在 AC² 拓扑中收敛（无需子列）到 γ⁰；(D2) 更强地，作用量泛函族 𝒜^ε(γ) := ½·Otto动能(γ) + (ε²/4)·FL(γ) 在路径空间上 Γ-收敛到 𝒜⁰（Fisher 长度有限的路径类上），且该 Γ-收敛提升为梯度流层面的 Mosco/EDP 收敛。

**证据与缺口分列**：
- **已证部件（S1）**：(a) 值的 Γ-收敛（Léonard 2012 [28]；2014 综述 [29] 含熵插值 → 位移插值的收敛陈述）；(b) 作用量恒等式（定理 4.1 [31]）；(c) 极限测地线唯一性（Brenier–McCann [3][4]）。
- **本文部件（S2/S3）**：(d) 定理 4.2 的夹逼给出 𝒜^ε(γ^ε) 的一致界 ⇒ 动能一致有界 ⇒ AC² 紧性，故任意子列有弱极限，且极限为 W₂ 测地线（动能下界迫使极限达到 ½W₂²）；(e) 由 (c) 极限唯一 ⇒ 全列收敛。**缺口**：(d) 中"紧性 ⟹ 极限路径动能 ≤ ½W₂²"用了动能的弱下半连续与 FL 项符号控制，严格书写需 RCD 框架的全部测度论机器；(D2) 的 Γ-收敛上界（recovery sequence）在一般目标点上要求"任意有限动能路径可被有限 Fisher 长度路径逼近"——密度正则化论证在端点奇异处失效，这是真缺口。
- **类比证据（S1）**：有限维 LP 中指数罚轨迹（Sinkhorn 的静态骨架）ε→0 收敛到最优面的解析中心（Cominetti–San Martín 1994 [33]）——"正则化路径收敛到极限问题解"在有限维严格成立；(D2) 是其无穷维测地线版本。
- **显式证据（S3）**：高斯族内熵插值有闭式解（Mallasto–Gerolin–Minh 2021 [34]），逐项检验 ε→0 收敛到 Bures–Wasserstein 测地线（07 号 §3.4 的度量）——逐行代数检验本文未展开，标待补全。

**猜想 4.4 的意义**：若成立，则 Sinkhorn 不只是"快速近似 W₂ 的算法"（[25] 的计算观点），而是**一族以 Fisher 长度为张力、连续变形到 Wasserstein 几何的变分结构**——熵正则化的真正几何内容是路径空间上的势能变形，这与 §3 的"熵产生 = 斜率平方"呼应：Fisher 信息在 ε>0 世界是约束路径的罚，在 ε=0 世界是驱动耗散的斜率。

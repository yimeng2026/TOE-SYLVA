## 1 从 19 号诊断出发：Fisher 度量为什么不能恒零

### 1.1 诊断回顾（19 号 §2–§3）

19 号逐行核对确认（行号见附录 A1）：`FisherInformationMatrix := 0`（FisherMetric.lean:42）；公理 `FisherInformationPSD`（:47）与 `FisherMetric`（:53）断言零矩阵的性质，"当前即可证"；`KLDivergence` 是全模块唯一真实积分定义，`KLDivergenceNonNegative`（Gibbs 不等式）是唯一有内容的公理；`NaturalGradient := 0` 配一条平凡 theorem；`StatMech.lean` 两条公理陈述体均为字面量 `True`。另有类型脱节：`parameterSpace` 是任意 Type，与返回 `Matrix (Fin n) (Fin n)` 的 FIM 在类型层面毫无关联。19 号的定性是"语义空洞（semantic void）"——本节给出该空洞的定量刻画。

### 1.2 恒零度量的三重代价

设参数化族 p(x;θ)，θ ∈ Θ ⊆ ℝⁿ，ℓ := log p，score s_i := ∂ℓ/∂θ_i。Fisher 信息矩阵 g_ij(θ) = E_θ[s_i s_j] = ∫ p ∂ᵢℓ ∂ⱼℓ dx（正则条件下亦等于 −E[∂ᵢ∂ⱼℓ]）。

**代价一：Cramér–Rao 下界失效。** 对无偏估计 θ̂（N 个 iid 样本），Cov_θ(θ̂) ⪰ g(θ)⁻¹/N（PSD 序；标量情形 Var ≥ 1/(N·g)）（Rao 1945；Cramér 1946）。该界要求 g ≻ 0 可逆；g ≡ 0 时下界形式发散——含义不是"估计极好"，而是**不存在有限方差的无偏估计**。

**代价二：参数不可识别。** g(θ) ≡ 0 ⟺ s_i = 0 a.s.（因 g_ii = E[s_i²]）⟺ ℓ 对 θ 局部常值 ⟺ 分布在参数扰动下不变。**恒零 Fisher 度量 = 模型对参数完全无敏感性**——这是"语义空洞"的精确数学形式。

**代价三：公理平凡化传染。** 两条公理在零定义下由 simp/rfl 可证（§5.1 已机器验证），"锁定的是一个名字而非内容"（19 号 §3）；FIM 一旦真实化，二者立刻转为真债务。占位定义使公理账本失真——这是 01 篇"占位公理"分类在信息几何模块的实例。

### 1.3 正确的起点：指数族 Fisher = Bregman 散度 Hessian / 对偶势

修复不是把 `0` 换成手写矩阵，而是让 Fisher 度量从**对数似然的结构**中长出来。典范情形是指数族：

$$p(x;\theta) = \exp\big(\langle \theta, T(x)\rangle - \psi(\theta)\big)\,h(x),\qquad \psi(\theta) = \log\int e^{\langle\theta,T(x)\rangle}\,h(x)\,dx$$

- **score**：s(x;θ) = T(x) − ∇ψ(θ)，从而 E[s] = 0、E[T] = ∇ψ(θ)；
- **Fisher = Hessian**：g_ij = ∂²ψ/∂θ_i∂θ_j = Cov(T)_ij。ψ 在自然参数空间上凸；极小表示时严格凸，**g 非退化**——恒零病态在定义层面被排除；
- **Bregman 结构**：D_ψ(θ, θ′) := ψ(θ) − ψ(θ′) − ⟨∇ψ(θ′), θ−θ′⟩，直接计算得 KL(p_θ‖p_θ′) = D_ψ(θ′, θ)；
- **Legendre 对偶**：η := ∇ψ(θ)（期望/混合坐标），ψ*(η) := sup_θ(⟨θ,η⟩ − ψ(θ))，∇ψ* = (∇ψ)⁻¹，且 Hess ψ*|_{η(θ)} = (Hess ψ|_θ)⁻¹——同一度量在两套对偶坐标下互为逆矩阵。

KL 的二阶展开 KL(p_θ‖p_{θ+dθ}) = ½ g_ij dθⁱdθʲ + O(‖dθ‖³) 把"Hessian = 度量"与"散度的局部二阶结构"钉在一起。这就是"恒零占位"的正确替代起点：**Fisher 度量是散度（Bregman/KL）的二阶导，指数族给出第一类非平凡实例**。§5.1 的玩具探针（ψ(μ) = μ²/2）把这条链端到端机器验证了一遍。

## 2 对偶结构：α-联络、Amari–Chentsov 张量与统计流形的平坦性

### 2.1 前世今生：从 Fisher 到 Amari

| 年份 | 人物 | 贡献 |
|------|------|------|
| 1922 | Fisher | Fisher 信息量与极大似然效率 |
| 1945 / 1946 | Rao / Jeffreys | 信息矩阵作为黎曼度量 + Cramér–Rao 界；不变先验 ∝ √det g |
| 1972 | Chentsov | 不变性定理：Fisher 度量与一族联络（今称 α-联络）是充分统计量下唯一不变的几何结构（至多差尺度） |
| 1985 / 2000 | Amari / Amari–Nagaoka | 对偶联络与对偶平坦的系统理论及其英文化集大成 |
| 2016 / 2022 | Amari / Nielsen | 应用卷；Notices 综述 *The Many Faces of Information Geometry* |

知乎 Proof-Trivial《信息几何（对偶结构）的前世今生》即按 Nielsen 综述脉络整理（附录 A3）。Chentsov 定理的意义：**这些结构不是人为选择，而是统计不变性唯一确定的**——这是信息几何作为"数学基础"而非"统计技巧"的根据。

### 2.2 α-联络与 Amari–Chentsov 张量

记 ℓ = log p。三阶对称张量（Amari–Chentsov 张量）与 α-联络（θ 坐标下的 Christoffel 符号）：

$$T_{ijk}(\theta) = \mathbb{E}_\theta[\partial_i\ell\,\partial_j\ell\,\partial_k\ell],\qquad \Gamma^{(\alpha)}_{ij,k} = \mathbb{E}_\theta[\partial_i\partial_j\ell\,\partial_k\ell] + \frac{1-\alpha}{2}\,T_{ijk}$$

α = 0 时 Γ⁽⁰⁾ 恰为 Fisher 度量的 Levi-Civita 联络，通式 Γ⁽ᵅ⁾ = Γ⁽⁰⁾ − (α/2)·T；全部 Γ⁽ᵅ⁾ 无挠（T 的全对称性保证）；α = 1 称 e-联络（指数联络），α = −1 称 m-联络（混合联络）。

### 2.3 对偶联络对与曲率

联络 ∇ 与 ∇* 关于 g **对偶**，若 X g(Y,Z) = g(∇_X Y, Z) + g(Y, ∇*_X Z) 对一切向量场成立。基本事实（Amari–Nagaoka 2000）：

1. ∇⁽ᵅ⁾ 与 ∇⁽⁻ᵅ⁾ 关于 Fisher 度量互为对偶；
2. 无挠对偶对的曲率 (0,4)-张量相等：R⁽ᵅ⁾ = R⁽⁻ᵅ⁾；故 ∇⁽ᵅ⁾ 平坦 ⟺ ∇⁽⁻ᵅ⁾ 平坦——**平坦性沿对偶对转移**；
3. R⁽ᵅ⁾ 与 Levi-Civita 曲率 R⁽⁰⁾ 相差 T 的二次项（系数量级 α²/4；指标式依赖符号约定，本文不展开）。

### 2.4 何时平坦：指数族与混合族互为对偶

- **指数族 e-平坦**：自然坐标下 ∂ᵢ∂ⱼℓ = −∂ᵢ∂ⱼψ = −g_ij 与 x 无关，故 Γ⁽¹⁾_{ij,k} = E[∂ᵢ∂ⱼℓ·∂ₖℓ] = −g_ij·E[∂ₖℓ] = 0（score 均值为零）；θ 是 e-仿射坐标。
- **混合族 m-平坦**：对 p(x;θ) = Σᵢ θᵢ qᵢ(x) + (1−Σᵢθᵢ)q₀(x)，由恒等式 ∂ᵢ∂ⱼℓ + ∂ᵢℓ∂ⱼℓ = (∂ᵢ∂ⱼp)/p 与 p 对 θ 的仿射性，Γ⁽⁻¹⁾_{ij,k} = E[(∂ᵢ∂ⱼp/p)·∂ₖℓ] = 0；混合坐标是 m-仿射坐标。
- **对偶平坦结构**：两族经 Legendre 对偶 η = ∇ψ(θ) 互为对偶坐标系；(g, ∇⁽¹⁾, ∇⁽⁻¹⁾) 构成对偶平坦空间，存在对偶势 ψ, ψ*，典范散度即 §1.3 的 Bregman 散度；并有**广义勾股定理**：若 m-测地线 qr 与 e-测地线 qp 在 q 处正交，则 D(p,r) = D(p,q) + D(q,r)。

统计推论：e-投影/m-投影的勾股分解是 I-投影与 EM 算法几何的骨架；§3.3 将看到它也是 Sinkhorn 迭代的几何本质。

## 3 最优传输与信息几何的交叉

### 3.1 Wasserstein 几何纲要

对 ℝ^d 上概率测度，W₂²(μ,ν) = inf_{π∈Π(μ,ν)} ∫‖x−y‖²dπ（Π 为耦合集）。三个支柱：**Brenier–McCann**（μ 绝对连续时最优映射唯一且为凸函数梯度 T = ∇φ，McCann 插值给出 W2 测地线）；**Benamou–Brenier 2000**（W₂² = inf ∫₀¹∫|v_t|²dμ_t dt，约束连续性方程——W2 是作用量最小化）；**Otto 2001 形式黎曼结构**（切向量 −∇·(ρ∇φ)，度量 ∫ρ⟨∇φ₁,∇φ₂⟩；JKO 1998：Fokker–Planck 方程是熵泛函的 W2 梯度流；Villani 2009 系统总结）。

### 3.2 Fisher 几何与 W2 几何的分工

| | Fisher–Rao / 信息几何 | Otto–Wasserstein |
|---|---|---|
| 几何对象 | 参数化族上的"垂直"几何 | 测度空间上的"水平"几何 |
| 局部结构 | KL/Bregman 的二阶展开 | 位移插值的动能 |
| 对质量的处理 | 重加权（生灭型） | 搬运（传输型） |
| 典型不变性 | 充分统计量（Chentsov） | 底空间等距 |

Fisher–Rao 度量 g^FR_ρ(σ,σ) = ∫σ²/ρ 对应球面 Hellinger 几何（d_FR(p,q) = 2 arccos ∫√(pq)，至多差常数因子）——对底空间几何完全无感；W2 反之。二者互补而非竞争。**桥梁**：非平衡最优传输（Hellinger–Kantorovich / Wasserstein–Fisher–Rao 距离，Liero–Mielke–Savaré 2018）把生灭项与传输项插值进同一框架，是目前最成熟的统一。

### 3.3 熵正则化与 Sinkhorn：KL 投影作为桥梁

熵正则化传输 min_{π∈Π(μ,ν)} ⟨C,π⟩ + ε·KL(π‖μ⊗ν)：ε → 0 回 W2；ε → ∞ 退化为 ⟨C, μ⊗ν⟩（独立耦合）；去偏 Sinkhorn 散度 S_ε 修正自相似项（Genevay–Peyré–Cuturi 2018）。**Sinkhorn 迭代 = 交替 Bregman（I-）投影**：离散情形即矩阵缩放（Sinkhorn 1964；Cuturi 2013 使其成为计算主力；Peyré–Cuturi 2019 综述，含 Schrödinger 桥视角）。交替投影落在两个边际约束仿射流形之间——正是 §2.4 m-投影勾股结构的化身：**熵正则化把最优传输接进了对偶平坦信息几何的地盘**。

### 3.4 参数化 W2：高斯族上的 Fisher 型度量

W2 限制到高斯族 N(m,Σ) 给出有限维黎曼几何（Takatsu 2011；Malagò–Montrucchio–Pistone 2018）：

$$W_2^2\big(N(m_0,\Sigma_0),\,N(m_1,\Sigma_1)\big) = \|m_0-m_1\|^2 + \operatorname{tr}\Big(\Sigma_0+\Sigma_1-2\big(\Sigma_1^{1/2}\Sigma_0\Sigma_1^{1/2}\big)^{1/2}\Big)$$

协方差部分即 **Bures–Wasserstein 度量**，其在 SPD 锥上的黎曼张量可由 Sylvester 方程显式写出（Bhatia–Jain–Lim 2019）。对照：同一高斯族的 Fisher–Rao 度量在均值块给 Σ⁻¹、协方差块给 ½·tr(Σ⁻¹dΣ Σ⁻¹dΣ)——恰为 §4 的 SPD 仿射不变度量（Bhatia 2007）。**同一参数流形上的两套典范几何**（W2-Bures vs Fisher-仿射不变）并存，为测地凸优化提供两类舞台。

## 4 测地凸优化

### 4.1 黎曼流形上的凸性

(M, g) 完备黎曼流形，f : M → ℝ 测地凸，若对任意测地线 γ(t) 有 f(γ(t)) ≤ (1−t)f(γ(0)) + t f(γ(1))（右端减 (λ/2)t(1−t)d² 即 λ-强测地凸）。非正截面曲率（NPC/Hadamard）流形上，CAT(0) 不等式给出 x ↦ d²(x,p) 强测地凸，Karcher 均值唯一存在（Bhatia 2007）。测地凸把"局部极小 = 全局极小"搬到弯曲空间，使凸分析工具全套可用（Zhang–Sra 2016；Bonnabel 2013）。

### 4.2 SPD 流形上的测地凸函数类

SPD_n 配仿射不变度量 g_Σ(X,Y) = tr(Σ⁻¹X Σ⁻¹Y)：测地线 Σ(t) = P #_t Q := P^{1/2}(P^{-1/2}QP^{-1/2})^t P^{1/2}，完备 NPC（Bhatia 2007；Moakher 2005）。标准测地凸函数类：

1. **log det**：测地线性（既凸且凹）——det Σ(t) = (det P)^{1−t}(det Q)^t，故 t ↦ log det Σ(t) 是仿射函数；
2. **线性泛函** X ↦ tr(AX)（A ⪰ 0）：由 Ando 不等式 P#Q ⪯ (P+Q)/2 得中点凸，进而测地凸；
3. **距离平方** d²(·,P)：NPC 上强测地凸；
4. **Karcher 泛函** Σᵢ wᵢ d²(·,Pᵢ)：凸且极小点唯一 = 加权 Karcher 均值（Moakher 2005；Bhatia–Holbrook 2006）。

### 4.3 det = c 超曲面（Proof-Trivial 例子的精确化）

log det 测地线性 ⇒ 水平集 {Σ : det Σ = c} 是测地约束的天然舞台；det = 1 叶 ≅ SL(n,ℝ)/SO(n)，全测地、继承 NPC。两个分离现象（欧氏视角会误判）：log det 在 SPD 上**欧氏凹**（−log det 欧氏凸）却**测地线性**；tr(AX) 欧氏线性却仅**测地凸**。应用落点：定行列式约束下的协方差估计（Tyler M-估计及推广）之适定性恰由该叶上的测地凸性保证（Wiesel 2012）。

### 4.4 应用：从自然梯度到 Bures 重心

- **自然梯度**（Amari 1998）：θ⁺ = θ − η·g(θ)⁻¹∇L，Fisher 几何下的最速下降，参数化不变；损失测地凸时黎曼 SGD 有全局收敛理论（Bonnabel 2013）；
- **SPD 上的估计与学习**：Karcher 均值（扩散张量成像、协方差描述子汇聚）、协方差估计（Wiesel 2012）；**Bures–Wasserstein 重心**（Agueh–Carlier 2011）连通高斯族平均与熵正则化重心计算；**矩阵缩放/Sinkhorn** 亦可表述为相应几何下的凸优化——§3.3 的桥在此合拢。

## 目录主题简介

**高阶拓扑相（Higher-Order Topological Phase, HOTP）** 是 2017 年由 Benalcazar-Bernevig-Hughes（BBH）等引入的一类新型对称性保护拓扑相，将常规 bulk-boundary 对应（$d$ 维体→ $d-1$ 维边界）推广为层级结构：$d$ 维体的拓扑可编码于 $d-2$ 维、$d-3$ 维乃至更深的"边界之边界"中。

其最具代表性的实现是 BBH 的**量化四极矩绝缘体**（Quantized Quadrupole Insulator）：二维方格子上由手性对称（$\{H,\Gamma_5\}=0$）保护的四个零能角态（corner modes），其拓扑不变量为**嵌套 Wilson 环**（Nested Wilson Loop）给出的 Wannier-sector 极化 $p_x^{\rm sec} = q_{xy} \bmod 1$——在拓扑相取 $1/2$、平庸相取 $0$。一般 $n$ 阶拓扑相在 codimension-$n$ 子流形上承载受对称保护的零模，而 $d-1$ 维表面可被完全 gap 掉。实验上，高阶拓扑相已在光子晶体、声学晶体、电路网络、冷原子和凝聚态体系中得到多样化实现，并与 Floquet 驱动、非厄米性、分形子（Fracton）等前沿方向产生了丰富的交叉。

## TOE-SYLVA 关联

- **(M1) 层级体-边界对应与层级涌现**：$d$ 维→ $d-1$→ $d-2$ 维的逐步降低是 SYLVA 层级涌现的直接展示——每个边界维度承载的是上一层"连接律"的剩余拓扑信息。
- **(M2) 嵌套 Wilson 环与对偶递归**：`Wilson($k_x$, $k_y$) → Wannier-sector 极化` 的递归计算过程体现了 SYLVA 中"对偶结构在更低维度上的再现"——每一层边界的拓扑不变量由更内层边界的几何决定。
- **(M3) 角态与对偶极的局域化**：四个角态两两互为对偶极——空间反射 $\mathcal{P}$ 与反演对称交换对角角态，体现了 SYLVA 对偶原理在实空间的局域实现。

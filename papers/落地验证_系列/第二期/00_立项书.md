## 一、背景：从"引用纪律审计"到"框架自己出数"

第一期千界花园评审（C3，暗物质/宇宙学专家）指出：T3/T4 实质是"文献引用纪律审计"而非"理论落地验证"——框架在这两个领域没有给出自己的定量预言（具体截面、具体 w(z)），因此无假设可检验；"真正行刑须待框架给出具体截面与 w(z)"。评审 C1（精密测量专家）另留悬案：T1 判据 |α⁻¹−137|<0.04 的 0.04 冻结界来源待档案审计——是否存在更早更强版本被事后弱化。

第二期的设计前提由此确定：

1. **T5**：从框架真实形式化（`FourForcesUnification.lean` 的直接赋值参数，行号见 PARAMETER_DISCIPLINE.md）与框架自有截面公式（`framework/18_dark_matter_spectrum.md` §二.1）推导 CNF WIMP 的 SI 截面量级估计，与 LZ 2024 上限（2.2×10⁻⁴⁸ cm² @40 GeV，第一期已核验）对照判定。
2. **T6**：检查框架是否有任何暗能量状态方程 w(z) 的可计算结构，按成色分级（定义选择/后验/推导）逐结构对照公开数据；无法导出唯一 w(z) 者如实登记 `[OPEN-DERIVATION]` 并给出缺口分析。
3. **T9**：0.04 判据档案审计——用 `git log -S` / `git log -G` / `--follow` / reflog 检索仓库全部历史，追查 0.04 界的最早出现版本、是否存在更强版本被弱化的时间线与原因，含提交哈希与引文。
4. **T7/T8**：按评审 C1 意见把 T1 升级为三级判据体系（0.04 存活线 + 0.001 强判据 + 精确读法死刑线），对框架内全部 α⁻¹ 主张（整数 137 与 doc101 三链 137.036）分级裁决。

**诚实成色声明（本期方法论核心）**：T5 的截面估计**不是第一性预言**——它由"定义选择（T_{2,3}、m_χ 的文档级赋值）+ 后验拟合参数（κ、G_F 推导链）"驱动，属唯象估计。本期的一切判定都区分三种成色：**框架死**（结构性矛盾，无参数退避）、**参数死**（当前参数化被排除，结构可退避）、**文档死**（文档数值/声称错误，不影响结构）。每条轨道必须显式回答"死的是哪一层"。

**判定词汇表**（沿用第一期，三条互斥）：

| 判定 | 含义 |
|---|---|
| **存活** | 按冻结/预登记判据检验通过；声明维持原治理级别 |
| **降级** | 声明在较强读法下被数据排除，仅能在较弱读法下存活 |
| **排除** | 证伪条件被满足；声明死亡，登记勘误 |

本期新增一个**裁决状态**（非判定词）：**裁决悬置**——证伪条件被字面触及，但因数据侧保留（第一期 T4 四点谨慎评估）或适用范围限定而不构成干净触发；如实登记，不宣告存活也不宣告排除。

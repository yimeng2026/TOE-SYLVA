## 一、背景与目的

TOE-SYLVA 框架在长期发展中积累了大量理论声明（CLAIM/CONJECTURE），其中部分带有定量预言。读者王斌的公开建议指出了一个朴素但根本的方法论要求：**理论必须走出自洽性叙事，接受公开实验数据的逐条检验**。

本项目将此建议升格为正式大型项目「理论落地验证」的第一期，对框架的四条可证伪主张/关联观测领域逐格行刑：

- 能定量的，用公开权威数据（CODATA、LEP）实算偏差与 σ 水平；
- 有冻结预言的（BP-1），严格按预登记判据裁决，禁止事后移动门柱；
- 属外部观测领域的（暗物质直接探测、暗能量状态方程），评估框架关联叙事与公开数据的真实相容程度，如实登记张力；
- 全部关键文献编号经 SylvaEngine 调用 arXiv 官方 Atom API 逐条核验，核验记录入库。

**第一期的判定词汇表**（三条，互斥）：

| 判定 | 含义 |
|---|---|
| **存活** | 按冻结/预登记判据检验通过；声明维持原治理级别 |
| **降级** | 声明在较强读法下被数据排除，仅能在较弱读法下存活；治理级别或措辞须下调 |
| **排除** | 证伪条件被满足；声明死亡，登记勘误 |

## 二、验证哲学：预登记死刑条款与盲登记联动

本项目的方法论骨架是仓库已有的两块治理基石的联动执行：

1. **盲登记（BLIND_PREDICTIONS.md）**：BP-1~4 已于 2026-08-10 冻结，含预言内容、数值与不确定度、证伪条件（原文照录 proof_status.md）、裁决时间窗、版本哈希。冻结规则：任何事后修改自动降级为后验拟合（POST-HOC）。本期 T1 轨道的判据 A（|α⁻¹−137| < 0.04）即 BP-1 冻结条目的原样执行——**判据先于数据审视而存在**。
2. **死刑条款预登记（热点议题 01 的方法论 CLAIM）**：对外部观测领域（T3/T4），框架不拥有这些实验，但框架对它们的引用方式必须接受审计——引用是否忠实、是否夸大显著性、是否把"暗示"说成"发现"。本期的行刑对象因此有两类：**框架自己的定量预言**（T1、T2）与**框架对外部数据的引用纪律**（T3、T4）。

诚实原则（VERIFICATION_PROTOCOL §四 真数据红线，本项目全部继承）：

- 禁止合成数据回退伪装；获取失败必须 `[DATA-MISSING]` 标注；
- 禁止编造引用；文献编号必须可核验；
- 断言阈值只许收紧、不许放宽；
- "数值验证通过" ≠ "定理证明"；
- 负结果必须登记，不得删除或隐藏。

## 三、四轨道设计

| 轨道 | 行刑对象 | 数据 | 判据性质 | 对应冻结条目 |
|---|---|---|---|---|
| **T1** | α⁻¹ ≈ n_CS = 137（CLAIM） | CODATA 2018：α⁻¹=137.035999084(21)；LEP：α⁻¹(M_Z)≈127.955±0.010（对照） | 双判据：A 有界近似（冻结界 0.04）；B 精确整数读法 σ 水平 | BP-1 |
| **T2** | FifteenConstants 定理中冯·克利青常数一致性（已修复项复核） | CODATA 2018 / SI-2019：h、e、c 精确值；ε₀=8.8541878128(13)×10⁻¹² F/m；α⁻¹ 独立测量值；R_K 标称 25812.80745 Ω | 1/(2ε₀cα) 与 h/e² 的合成不确定度内一致性；**α 用测量值，禁止公式回代（防循环）** | —（工程复核） |
| **T3** | WIMP 行刑进度（框架暗物质叙事的引用忠实度与参数空间封闭进度） | LZ 2024（arXiv:2410.17036）、LZ 2022（arXiv:2207.03764）、XENONnT（arXiv:2502.18005）、PandaX-4T（arXiv:2407.10892）、XENONnT-B8（arXiv:2408.02877）、DARWIN/XLZD（arXiv:2404.19524） | 上限收紧进度量化；距中微子雾差距；引用忠实度 | —（引用纪律审计） |
| **T4** | 暗能量 w(z) 观测现状（框架暗能量桥接叙事的边界） | DESI DR1（arXiv:2404.03002）、DR2（arXiv:2503.14738、2503.14739） | 显著性区间如实引用；四点谨慎评估；未达 5σ 红线 | —（引用纪律审计） |

### T4 四点谨慎评估（预登记，报告内逐项展开）

1. **显著性未达发现门槛**：全部数据组合 2.5–4.2σ，最高约 4σ 量级，低于 5σ；
2. **超新星样本依赖**：显著性区间几乎完全由选用哪套超新星汇编决定（Pantheon+ 2.5σ → DES-SN5YR 3.9σ/4.2σ 端），命中标准化系统误差要害；
3. **参数化先验**：CPL 形式在 z≳1 强制 w→w₀+wₐ，"演化偏好"可能部分为参数化响应而非逐点测量；
4. **共享系统误差不能排除**：多组合同向加强不等于独立确认；Euclid/Rubin 的独立系统误差谱复核到位前，w=−1 仍是基准假设。

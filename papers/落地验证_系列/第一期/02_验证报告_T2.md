**防循环纪律（立项书 §三）**：α 采用 CODATA 2018 独立测量值（α⁻¹=137.035999084）。**绝不**使用 α = 1/(2ε₀cR_K) 从 R_K 回代——否则一致性检验退化为恒等式自证，验证无效。

**物理背景**：恒等式 R_K = h/e² = 1/(2ε₀cα) 两端分别挂在 (h, e) 与 (ε₀, α) 两组常数上。SI-2019 之后 h、e 精确，因此该恒等式把 ε₀ 与 α 的不确定性锁在一起；本检验实为 **CODATA 2018 调整内部自洽性 + 框架引用该自洽性是否正确** 的双重复核。

## 四、判定

### **T2 判定：存活**

1. 恒等式 1/(2ε₀cα) = h/e² 在 CODATA 2018 独立输入下以 **0.004σ** 的精度成立——这不是框架的物理成就（恒等式本身是电磁学定义关系），但它证明了：
2. **框架的引用链无循环**：用独立测量的 α 而非回代 α 完成检验，修复后的 FifteenConstants 定理在常数引用层面是自洽的、诚实的；
3. **历史修复有效**：该项此前因循环引用风险被修复（α 改为独立输入），本期复核确认修复达到了其声称的目的；
4. **边界声明**：本判定不触及 FifteenConstants 定理的其余十四项常数关系；每一项都须在未来各期以同样的"独立输入、防循环"纪律单独复核。

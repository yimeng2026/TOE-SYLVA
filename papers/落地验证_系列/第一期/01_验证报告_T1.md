## 四、判定

### **T1 判定：降级（存活于有界近似读法；精确整数读法排除）**

1. **有界近似存活**：按 BP-1 冻结判据，|α⁻¹−137| = 0.036 < 0.04，预言在其冻结形式下通过，**不标记 FALSIFIED**。
2. **精确整数读法死亡**：任何人若以"α⁻¹ 精确等于整数 137"解读框架，该读法在 1.71×10⁶σ 水平上被 CODATA 排除。此读法自始不在 BP-1 冻结文本内，本报告显式登记以防外部误读。
3. **措辞降级要求**：框架一切涉及"α⁻¹ ≈ 137"的表述，**只允许**以"有界近似（|Δ|<0.04，实测 0.036）"形式出现；禁止任何暗示精确相等的修辞（如"自然给出 137"之类）。偏差已达冻结界 90%，CLAIM 级别维持但须附加"余量仅 10%"的承压注记。
4. **方向性观察（事实，不作拟合）**：LEP run 值 α⁻¹(M_Z)≈127.955 远离 137（9.045，约 904σ）——137 只在低能极限附近有数值邻近性，这强化了"n_CS=137 与 α⁻¹ 的对应若存在，其机制必须是低能定点性质"的约束。

## 目录主题简介

**等离子体（Plasma）**——由自由运动的正负带电粒子组成的准中性电离气体——是物质在固体、液体、气体之外的"第四态"，构成了宇宙中超过 99% 的可见物质。等离子体物理研究带电粒子与电磁场的自洽耦合行为，其核心方程是 Vlasov-Maxwell 系统（动力学理论）或磁流体力学（MHD）方程组（流体近似）。

等离子体的基本过程包括：Langmuir 波（电子密度振荡，$\omega_p^2 = n_e e^2 / \varepsilon_0 m_e$）、Debye 屏蔽（电势$\sim e^{-r/\lambda_D}$）、Alfvén 波（沿磁力线的横波，$v_A = B/\sqrt{\mu_0\rho}$）以及各种不稳定性（Kink、Sausage、Rayleigh-Taylor 等）。在**磁约束核聚变**中，TOKAMAK 装置的等离子体平衡、输运与 MHD 稳定性是核心研究课题；而在**惯性约束聚变**（ICF）中，等离子体的 Rayleigh-Taylor 不稳定性与激光-等离子体耦合决定了压缩均匀性。

本综述还涉及天体物理等离子体——太阳风、吸积盘（磁转动不稳定性 MRI）、Kerr 黑洞附近的 Blandford-Znajek 过程等。

- **(M1) 集体模式作为涌现现象**：等离子体的 Langmuir 波和 Alfvén 波是从大量粒子-场耦合中涌现的集体激发态——是 SYLVA"连接律产生新模式"的典型多体实例。

- **(M3) 磁重联与对偶拓扑变化**：磁重联是磁力线拓扑在电流片处发生断裂与重连的过程，对应于 SYLVA 对偶结构的"相变"——重联效率由连接律的局部失效与重建决定。

## Formal Theories of Consciousness: From Integrated Information to Global Workspace

## 1. 引言：意识的困难问题

### 1.1 Chalmers的区分

**简单问题**：意识的神经相关物（NCC）、注意、报告等机制。

**困难问题**：为什么物理过程伴随主观体验（qualia）？

### 1.2 形式化的动机

意识需要形式化处理，因为：
1. **精确性**：模糊的"体验"需要数学化

3. **可计算性**：意识度量需要算法
4. **可扩展性**：理论需要适用于非生物系统

## 2. 整合信息论（IIT）

### 2.1 核心公理

**IIT 3.0**（Tononi et al.）的五个公理：

1. **存在性**：意识存在
2. **组合性**：意识有结构
3. **信息性**：意识有内容
4. **整合性**：意识是统一的
5. **排除性**：意识有边界

### 2.2 数学形式化

**整合信息 $\Phi$**：
$$\Phi = \text{MI}(X; X) - \sum_{k} \text{MI}(X_k; X_k | \text{partition})$$

其中 $\text{MI}$ 是互信息，partition是最小信息分区。

**核心直觉**：$\Phi$ 衡量系统"不可还原"的程度——高 $\Phi$ 系统不能被分解为独立部分。

### 2.3 意识的度量

**$\Phi^{Max}$**：系统在所有可能分区下的最大 $\Phi$。

**预测**：
- 大脑皮层：高 $\Phi$（有意识）
- 小脑：低 $\Phi$（无意识，尽管神经元多）
- 麻醉状态：$\Phi$ 降低
- 睡眠：$\Phi$ 变化

### 2.4 IIT的局限

1. **计算困难**：$\Phi$ 的精确计算是NP-hard
2. **网络依赖**：$\Phi$ 依赖于系统的因果结构
3. **泛化困难**：从简单系统到大脑的推广
4. **$\Phi$ 与意识的关系**：相关性还是因果性？

## 3. 全局工作空间理论（GWT）

### 3.1 核心思想

**GWT**（Baars, 1988; Dehaene, 2014）：
- 意识 = 全局工作空间中的信息广播
- 局部处理 → 无意识
- 全局广播 → 有意识

### 3.2 神经基础

**全局神经元工作空间**：
- 长程皮层连接形成"工作空间"
- 信息从局部模块"点燃"全局网络
- "点燃" = 意识

**预测**：
- 无意识处理：$<50$ ms，局部
- 有意识处理：$>300$ ms，全局
- P3b波：意识访问的标志

### 3.3 形式化

**工作空间模型**：
$$\text{Conscious}(x) \iff \text{Broadcast}(x, \text{GlobalWorkspace})$$

**广播条件**：
$$\text{Activation}(x) > \theta_{global}$$

### 3.4 GWT的局限

1. **阈值问题**：$\theta_{global}$ 如何确定？
2. **广播 vs 体验**：广播是意识的充分条件吗？
3. **非广播意识**：边缘意识、盲视
4. **计算模型**：缺乏精确的计算理论

## 4. 高阶理论（HOT）

### 4.1 核心思想

**HOT**（Rosenthal, 1986）：
- 意识 = 对自身心理状态的高阶表征
- 一阶状态（感知）→ 无意识
- 高阶状态（对一阶的表征）→ 有意识

### 4.2 形式化

$$\text{Conscious}(M_1) \iff \exists M_2: M_2 \text{ represents } M_1$$

其中 $M_1$ 是一阶心理状态，$M_2$ 是高阶状态。

### 4.3 神经基础

**前额叶皮层**：高阶表征的候选区域。

**证据**：前额叶损伤影响元认知但不影响感知。

### 4.4 HOT的局限

1. **无穷回归**：是否需要 $M_3$ 表征 $M_2$？
2. **高阶 vs 一阶**：高阶状态本身是否需要意识？
3. **动物意识**：动物是否有高阶状态？
4. **机器意识**：AI能否有高阶状态？

## 5. 预测处理框架

### 5.1 自由能原理

**Friston的自由能原理**：
$$F = -\mathbb{E}_q[\ln p(o,s)] + \mathbb{E}_q[\ln q(s)]$$

**核心**：生物系统最小化变分自由能。

### 5.2 预测编码

**层次预测编码**：
- 每层预测下一层输入
- 误差向上传播
- 感知 = 最小化预测误差

### 5.3 意识与预测

**假说**：意识与预测精度调节相关。

**证据**：
- 注意力 = 精度调节
- 意识 = 高精度预测
- 幻觉 = 过度自信的预测

### 5.4 形式化

**意识条件**：
$$\text{Conscious}(x) \iff \text{Precision}(x) > \theta \text{ and } \text{GlobalBroadcast}(x)$$

## 6. 注意力图式理论（AST）

### 6.1 核心思想

**AST**（Graziano, 2013）：
- 意识 = 对注意力的简化模型（"图式"）
- 大脑构建注意力模型来控制注意力
- 这个模型的主观体验 = 意识

### 6.2 形式化

$$\text{Consciousness} = \text{Model}(\text{Attention})$$

**关键**：意识是对注意力的模型，不是注意力本身。

### 6.3 优势

- 解释意识的主观性
- 解释意识的非物理感
- 连接意识与控制理论

## 目录主题简介

**大气物理学**是运用流体力学、热力学和辐射传输等经典物理工具研究地球大气层中各种物理过程的学科。核心议题包括：大气垂直结构（对流层、平流层、中间层、热层）、大尺度环流（Hadley 环流、Ferrel 环流、极地环流）、辐射平衡与温室效应、大气边界层中的 Ekman 螺旋、云微物理学与降水机制等。

**气候科学**则在更长时间尺度和更大空间尺度上研究气候系统的行为与演变，涵盖辐射强迫（radiative forcing）、气候反馈（如冰-反照率反馈、水汽反馈）、以及气候敏感度（$\Delta T_{2\times\text{CO}_2}$）等核心概念。本综述从辐射-对流平衡的基本能量平衡模型（EBM）出发，推导温室气体浓度变化对全球平均地表温度的影响，并讨论极端气候事件（如台风强度、热浪频率）与气候变暖的统计关联。TOE-SYLVA 视角下，气候系统是大气-海洋-冰冻圈-生物圈子系统之间"连接律"的宏观展示——各层之间通过能量、动量和水汽交换构成耦合系统。

## TOE-SYLVA 关联

- **(M1) 多圈层耦合与连接律**：大气-海洋-冰冻圈耦合是 SYLVA 连接律的地球实例——能量和物质在子系统之间通过"连接通道"传递，驱动涌现现象（如 ENSO 振荡）。
- **(M2) 层级涌现**：从云微物理（微米级）→ 对流系统（千米级）→ 全球环流（万千米级），多尺度现象通过 SYLVA 的涌现机制逐级组织。
- **(M3) 非线性反馈与对偶**：正反馈（水汽、冰-反照率）与负反馈（Planck 辐射）的竞争对应 SYLVA 中正/负对偶通道的动力学平衡。

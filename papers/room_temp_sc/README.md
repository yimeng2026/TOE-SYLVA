## 主题简介

室温超导是凝聚态物理的"圣杯"——在环境温度和常压下实现电阻为零的超导态。本目录从 TOE-SYLVA 框架出发，系统跟踪室温超导的最新研究进展，涵盖：BCS 理论的超导能隙公式与 Allen-Dynes 修正、Floquet 工程诱导的非平衡超导性（Floquet 超导）、氢基超导体的高压相图（H₃S、LaH₁₀）、以及 "LK-99" 类材料的结构-物性争议分析。

核心视角：将超导临界温度 T_c 诠释为因果网络上信息-能量耦合的**相变成核阈值**——BCS 能隙方程对应于因果网络配对态的信息自由能最小化，Floquet 超导对应于周期性驱动下的非平衡信息重整化，而高压氢化物中的高 T_c 对应于压缩相空间中信息密度的急剧变化。

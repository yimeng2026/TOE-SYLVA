## 目录主题简介

**Floquet 物理**研究的是受周期性驱动（Periodically Driven）的量子系统在时间维度上的"能带"结构。Floquet 定理——时间域上的 Bloch 定理——将一个含时周期哈密顿量 $H(t+T)=H(t)$ 映射为静态的 Floquet 哈密顿量，其特征值（准能量）形成一个周期结构，称为 Floquet 布里渊区。这为量子材料的动态调控提供了一个极其丰富的工具箱，催生了 Floquet 拓扑绝缘体、Floquet 外尔半金属、Floquet 超导等众多"周期驱动工程"相。

**离散时间晶体（Discrete Time Crystal, DTC）** 是 Floquet 物理中最为惊艳的发现之一。它打破了连续时间平移对称性的常规自发破缺范式，在一个周期驱动的多体系统中自发形成比驱动力周期长整数倍的子谐波响应（如周期倍增）。这种"时间自组织秩序"最初被认为是热力学不可能成立的，直到 2016-2017 年才在理论上被严格构建（以多体局域化为保护机制），并很快在离子阱、NV 色心、超导量子比特等实验平台上得到验证。

- **(M1) 时间维度上的对偶结构**：Floquet 系统的频域/时域双重视角体现了 SYLVA 对偶原理在时间维度的应用：驱动频率（$2\pi/T$）与准能量折叠构成了频-时对偶。

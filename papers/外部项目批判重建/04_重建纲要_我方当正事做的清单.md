## 二、逐项展开

### T1 白矮星观测裁决方法论对我方盲预言的移植（★★★）

**为什么值得**：paper48 的六轮迭代（v5–v11）+ 四类显性证伪（多元回归控制混杂、匹配对照、单调性检验、缺口补全）是独立研究者圈层中罕见的完整观测裁决样本（01 号 §2.1 核验：P48:16/547/552/554）。它同时示范了**后验探索如何留痕**与**选择效应如何主动攻击**——这恰是我方盲登记体系目前最薄的一环：我方有前置冻结，但对"数据已在手、诠释刚生成"的后验场景缺留痕规格。

**我方切入点**：
1. 把 paper48 的四类证伪抽象为**后验裁决四件套**：混杂变量回归控制 / 匹配子样本 / 全场单调性 / 梯度缺口补全，写入我方 VERIFICATION_PROTOCOL 附录（新增"后验分析留痕"节，与既有前置盲登记并列）。
2. 升级我方盲登记模板：吸收 REG 的四要素（公式/数值/证伪条件/裁决时间窗，REG:11）+ paper48 的证伪设计字段，形成"前置登记 + 后验留痕"双层格式。
3. 对照登记 REG 的覆盖缺口教训（01 号 §7.4：治理密度与内容风险反向分布），我方盲登记优先覆盖**裁决快**的方向。

**预期产出**：`framework/VERIFICATION_PROTOCOL.md` 附录修订（含模板）；一篇方法学短记《后验裁决四件套：从白矮星案例到我方协议》。

**验收**：模板能逐字段复刻 paper48 案例与我方一个真实案例（建议用 CNF 光子线的 κ_Δ 冻结）。

### T2 谱丛反演算法的独立复现与真实基线对照（★★★）

**为什么值得**：这是 MUFPF 48 篇中唯一有明确工程转让价值的单项（01 号 §2.3）：弛豫谱反演是流变学真实病态问题，其 T3/T4/T5 验收数据（P6:632–634）具体可复核，算法栈公开（Prony-NNLS + Trust-Region + LACI，P6:623）。同时它的现有基线（手工 Tikhonov）不充分，**真实的竞技场（CONTIN、最大熵、贝叶斯反演）还没上过**——谁先把它放进真实竞技场，谁就拥有对该算法的 definitive 评价。

**我方切入点**：
1. 按 P6 §9.3.6 与镜像脚本（`_rheo_sheaf_inversion.py`）独立复现三对角谱丛反演；先过其五项验收（确认 9.2×10⁻³² / 0.06% / 0.3% 三数可复现——复现本身即是对 V3 口径问题的裁决）。
2. 上真实基线：CONTIN（Provencher 1982）、最大熵法、贝叶斯反演，用**公开流变实验数据**（非合成数据）做对照。
3. 补做对方未做的**模型失配测试**（01 号 §2.3 批评 1：用非广义 Maxwell 模型生成数据，看谱丛反演的谱恢复鲁棒性）。

**预期产出**：开源复现代码（注明 CC-BY 归属王斌原始算法）+ 一篇基准对照报告（投稿规格：J. Rheol. 或 arXiv）；若结果正面，这是对王斌最实质的学术致意，并自然开启 T3 共建。

**验收**：三数复现登记 + 至少 2 个外部基线 + 1 组模型失配测试。

### T4 筛法"顺序不可交换性"的 Lean 形式化（★★）

**为什么值得**：01 号 §6.2 已判定：王斌定理 3.5（顺序不可交换）按现有转述证据大概率是平凡事实的重述，但其**非平凡化的唯一出路是定量化**。Lean 形式化是迫使该命题"显形"的最便宜工具：把 Eratosthenes 筛定义为状态机，把"不可交换性"精确陈述为轨道函数的差异，机器证明会立刻显示它是定理还是重言式。无论结果如何都有产出：平凡→登记判定，了结一桩公案；非平凡→对方工作升格，我方获得一个新引理库。

**我方切入点**：
1. 在 Lean 4 中形式化筛状态机（有限集 + 移除映射族），证明两个基定理：(i) 终态顺序无关（布尔标记的交换性）；(ii) 轨道顺序相关（构造反例对）。
2. 把 (i)(ii) 的合取与"定理 3.5"的精确陈述比对（需先取得原文——知乎 2026-08-27 文，本轮未定位，建议通过共建渠道索取）。
3. 若对方命题含定量部分（如轨道差异的下界），一并形式化。

**预期产出**：Lean 工程（可并入我方形式化支线）+ 一页判定短文（"重言式 / 非平凡定理"二元结论 + 证据）。

**验收**：`lake build` 通过 + 判定短文经我方评审流程。

### T5 湍流谱的机器验证（★★★）

**为什么值得**：02 号 §五已判定方向选择：做 TurbRec 一侧（有即时考官、与我方技术栈同构），并把 paper6/paper45 的谱语言残片变成**可在公开数据上被杀死的预言**。这是把"批判"转化为"物理"的一步：λ_k∝k^{2/3}（P6:135）与 λ_π 类谱隙接口（P45:996）都是具体、可提取、可证伪的量——但迄今为止没有任何一方在公开湍流数据上真做过。

**我方切入点**（三步，同 02 号 §5.3）：
1. S1：复现 TurbRec 核心管线（频率感知傅里叶嵌入 + 重叠窗口分段学习）于 2D 衰减湍流公开数据（JHU Turbulence Database 或自生成 DNS），验收能谱 −5/3 区间恢复度。
2. S2：同数据上跑 DMD/EDMD，提取 Koopman 特征值谱，检验 λ_k 的 k^{2/3} 标度窗口——**事前按 T1 升级后的盲登记模板冻结预言**（标度区间、拟合优度阈值、证伪条件），使本任务同时成为 T1 模板的首个实战。
3. S3：把 S2 的提取管线对接 paper45 的 λ_π 类预言格式（剪切道谱隙），出对照报告。

**预期产出**：复现管线（开源）+ 盲登记预言 + 裁决报告（无论正负均发表）；若 λ_k∝k^{2/3} 窗口成立，王斌的谱几何诠释获得第一个独立证据；若失败，01 号 §6.1 的批判从文本层升级为数据层。

**验收**：盲登记时间戳早于首次提取；裁决报告含阴性结果预案。

### T6 K41 常数 1.59 事件的勘误与严肃性检验（★★，时效性）

**为什么值得**：V1（01 号 §6.1 点 3）是本轮核验抓到的最严重单项：paper6 旗舰声称"Kolmogorov 常数的谱确定 C=(2π)⁻¹(3/2)^{2/3}≈1.59 与实验 1.5–1.6 一致"（P6:157–161），而公式实算 = 0.2086，差 7.62 倍，且"证明"无计算（P6:163）。这件事有两个独立价值：①学术卫生——该公式若不修正，会被后续文本（含 AI 检索）持续引用放大；②治理测试——它是检验对方勘误纪律的最佳试纸（T3），也是检验我方"核验-通报-留痕"流程的标准案例。

**我方切入点**：
1. 起草勘误建议函（中性措辞，附实算过程与三种可能修复路径：归一化约定因子 / 公式笔误 / 数值笔误；注明我们未找到使 1.59 成立的自然归一化）。
2. 同时做一份**常数文献核算综述**（内部）：Kolmogorov 常数在实验（1.5–1.6，Sreenivasan 1995 汇编）、RG（Yakhot-Orszag）、closure（EDQNM）各线的估值与不确定度——把"1.59 是否本就特殊"这个问题先在我方内部钉死，避免对方修复时换个同样无据的数字。
3. 对方响应后更新 01 号文件（留痕纪律，不改原文、加 ERRATA 行）。

**预期产出**：勘误建议函（经共建渠道送达）+ 内部综述备忘录 + 01 号 ERRATA 留痕。

**验收**：函件送达有记录；综述覆盖至少三条独立估值路线。

## 四、不做清单（同样重要的判定）

以下方向经评审**不值得我方投入**，如实登记理由：

1. **MUFPF 主框架（P1–P7 粒子预言）的再验证**：对方盲登记最严处即裁决最远处（以年计），我方投入无法加速裁决，重复验证只能复读其脚本。
2. **晶脉哲学/谐振理论的 LLM 工具链**：与我方物理目标无关，且其工程迭代速度快、评价会迅速过时。
3. **paper47 仿形感应的哲学辩论**：诠释层争议无裁判（01 号 §5.2），投入产出比为零。
4. **稳定岛热力学极限的 ED 扩展**（N>16）：指数成本墙，且 P-CM-5 已直接验证到 N=16；若要推进应走 MPS/DMRG 路线，但那是对方与 EDRN 的自然下一步，我方不必代劳。
5. **对 paper6 K41"第一性"的持续论战**：T6 勘误送达后，此事转入对方响应流程；我方不再追加文本火力——把同样的精力投入 T5，用数据说话。

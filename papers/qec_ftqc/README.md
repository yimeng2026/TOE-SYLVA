## 主题简介

量子纠错（Quantum Error Correction, QEC）与容错量子计算（Fault-Tolerant Quantum Computation, FTQC）是实现大规模通用量子计算机的核心挑战。本目录收录了 TOE-SYLVA 框架下关于 QEC/FTQC 的综合性研究。

主题涵盖：表面码（Surface Code）的稳定子形式化与阈值定理、Steane 码的症候提取与解码算法、拓扑量子纠错码与非阿贝尔任意子编织的对应关系、以及 TOE-SYLVA 框架下"几何纠缠熵 ↔ 纠错阈值"的深层对偶。核心发现：量子纠错阈值可被诠释为纠缠熵相变点，表面码的逻辑错误率与 RT 极小曲面面积具有相同的标度行为。

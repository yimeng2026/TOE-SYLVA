## ⚠️ 重要说明

本目录包含 TOE-SYLVA 框架下的各类论文、综述、回应与审计文档。这些文档的**可信度分级**如下：

- **CANONICAL**: 经诚实审计的规范版本，可独立验证
- **DRAFT**: 工作草稿，部分内容可能未经完全审查
- **DEPRECATED**: 已被后续版本取代，仅保留供历史参考
- **REFERENCE**: 审计/元文档，用于透明性与质量控制

> **读者须知**: 本仓库中的论文旨在组织已知结果、提供阐述性框架、并提出可验证的推测。文中所有数学定理的原始归属均标注在对应的引用文献中。最终判断请以原始期刊/预印本论文为准。

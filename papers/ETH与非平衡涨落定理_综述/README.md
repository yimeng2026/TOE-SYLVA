## 目录主题简介

**本征态热化假说（Eigenstate Thermalization Hypothesis, ETH）** 是解释孤立量子多体系统如何实现热化的核心理论框架。ETH 由 Deutsch（1991）和 Srednicki（1994）独立提出，其核心断言是：对于满足 ETH 的量子系统，单个能量本征态的局域观测期望值就等于微正则系综平均值，从而在"本征态"层面而非"系综"层面解释了量子统计力学的微观基础。

与之互补的**非平衡涨落定理**（Fluctuation Theorems）——包括 Jarzynski 等式（$\langle e^{-\beta W}\rangle = e^{-\beta \Delta F}$）与 Crooks 涨落定理——则从非平衡热力学角度精确量化了不可逆过程中功与自由能之间的关系，将热力学第二定律从不等式提升为等式。这两大支柱共同构成了现代非平衡统计物理的数学骨架。

本综述深入分析了 ETH 的热化机制与涨落定理的数学结构，并在 TOE-SYLVA 框架下探讨了热化与信息编码之间的本体论联系：ETH 中的"本征态→热系综"涌现与涨落定理中的"微观可逆↔宏观方向性"对偶。

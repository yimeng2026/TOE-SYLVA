## 1. 引言：弦理论作为量子引力的候选

弦理论是目前最成熟的量子引力候选方案之一。其核心思想是：**基本客体不是点粒子，而是一维弦**。弦的不同振动模式对应不同的粒子，包括引力子。

## 2. 微扰弦理论

### 2.1 玻色弦与超弦

**玻色弦**（26维）：
- 作用量：$S = -\frac{T}{2}\int d^2\sigma \sqrt{-h} h^{ab} \partial_a X^\mu \partial_b X_\mu$
- 振动模式包括：引力子、膨胀子、反对称张量
- 缺陷：包含快子，无费米子

**超弦**（10维）：
- 五种一致理论：Type I, Type IIA, Type IIB, SO(32)杂化, $E_8 \times E_8$杂化
- 包含时空费米子，无快子
- 需要N=1世界面超对称

### 2.2 弦的量子化

弦的量子化有三种主要方法：
1. **Old covariant quantization**：Gupta-Bleuler条件
2. **Light-cone quantization**：消除约束但失去明显Lorentz不变性
3. **BRST quantization**：现代标准方法

物理态条件：$L_n|\psi\rangle = 0$ ($n > 0$), $(L_0 - a)|\psi\rangle = 0$

## 3. 五种超弦理论的对偶

### 3.1 T对偶

T对偶将紧致化半径 $R$ 与 $1/R$ 的理论等价：
$$R \leftrightarrow \frac{\alpha'}{R}$$

Type IIA 与 Type IIB 在T对偶下相关。

### 3.2 S对偶

S对偶交换强耦合与弱耦合：
$$g_s \leftrightarrow \frac{1}{g_s}$$

Type IIB 弦理论具有 $SL(2, \mathbb{Z})$ S对偶对称性。

## 4. D膜物理

### 4.1 D膜的定义

Dp膜是Dirichlet边界条件在p个空间方向上施加的开弦端点。其性质包括：
- 携带RR荷
- 张力 $T_p \sim 1/g_s$
- 非微扰对象（$g_s \to 0$ 时重）

### 4.2 D膜与规范理论

D膜的世界体积理论是规范理论：
- N个D3膜 → $U(N)$ $\mathcal{N}=4$ 超对称Yang-Mills
- D3/反D3系统 → 流形上的规范对称破缺

## 5. Calabi-Yau紧化

### 5.1 从10维到4维

将10维超弦理论在6维Calabi-Yau流形 $X$ 上紧化：
- 保持 $\mathcal{N}=1$ 超对称
- Hodge数 $(h^{1,1}, h^{2,1})$ 决定4维物理
  - $h^{1,1}$：Kähler模数（矢量多重态）
  - $h^{2,1}$：复结构模数（超多重态）

### 5.2 镜像对称

镜像对称预测：对Calabi-Yau三流形 $X$，存在镜像 $X^\vee$ 使得：
$$h^{1,1}(X) = h^{2,1}(X^\vee), \quad h^{2,1}(X) = h^{1,1}(X^\vee)$$

## 6. M理论

### 6.1 11维图景

M理论是11维理论，其低能有效作用量是11维超引力：
$$S = \frac{1}{2\kappa_{11}^2}\int d^{11}x \sqrt{-g}\left(R - \frac{1}{2}|F_4|^2\right) - \frac{1}{6}\int C_3 \wedge F_4 \wedge F_4$$

M理论的基本扩展对象：

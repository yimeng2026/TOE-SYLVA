## 2. 量子纠缠

### 2.1 纠缠的定义与度量

**纠缠态**：不能分解为纯态直积的量子态。

对于二分系统 $\rho_{AB}$，纠缠度量包括：
- **纠缠熵**：$S(\rho_A) = -\text{Tr}(\rho_A \ln \rho_A)$
- **concurrence**：$C(\rho) = \max(0, \lambda_1 - \lambda_2 - \lambda_3 - \lambda_4)$
- **负度（negativity）**：$N(\rho) = \frac{\|\rho^{T_A}\|_1 - 1}{2}$

### 2.2 Bell不等式与纠缠检验

Bell不等式提供了纠缠的实验检验：
$$|S| = |E(a,b) - E(a,b') + E(a',b) + E(a',b')| \leq 2$$

量子力学预测最大值 $2\sqrt{2}$，已被实验多次验证。

### 2.3 多体纠缠

多体纠缠比二体复杂得多：
- **GHZ态**：$\frac{1}{\sqrt{2}}(|000\rangle + |111\rangle)$
- **W态**：$\frac{1}{\sqrt{3}}(|001\rangle + |010\rangle + |100\rangle)$
- GHZ与W在局域操作下不等价

## 3. 量子信道与量子熵

### 3.1 量子信道

量子信道是完全正定保迹（CPTP）映射：
$$\Phi(\rho) = \sum_k E_k \rho E_k^\dagger, \quad \sum_k E_k^\dagger E_k = I$$

### 3.2 量子熵

**von Neumann熵**：$S(\rho) = -\text{Tr}(\rho \ln \rho)$

**量子互信息**：$I(A:B) = S(\rho_A) + S(\rho_B) - S(\rho_{AB})$

**量子条件熵**：$S(A|B) = S(\rho_{AB}) - S(\rho_B)$（可为负！）

### 3.3 量子Holevo界

通过量子信道传输的经典信息上界：
$$\chi = S\left(\sum_i p_i \rho_i\right) - \sum_i p_i S(\rho_i)$$

## 4. 量子纠错

### 4.1 量子纠错的必要性

量子计算面临三类错误：
1. **比特翻转**：$|0\rangle \leftrightarrow |1\rangle$
2. **相位翻转**：$|0\rangle \to |0\rangle, |1\rangle \to -|1\rangle$
3. **振幅阻尼**：能量耗散

### 4.2 量子纠错码

**3比特码**（仅纠正比特翻转）：
$$|0\rangle_L = |000\rangle, \quad |1\rangle_L = |111\rangle$$

**Shor码**（9比特，纠正任意单比特错误）：
$$|0\rangle_L = \frac{1}{2\sqrt{2}}(|000\rangle + |111\rangle)^{\otimes 3}$$

### 4.3 稳定子码

稳定子码由其稳定子群 $S \subset \mathcal{P}_n$ 定义：
- 编码空间：$V_S = \{|\psi\rangle : M|\psi\rangle = |\psi\rangle, \forall M \in S\}$
- **表面码**：$[[d^2, 1, d]]$ 码，目前最有前景的方案
- **颜色码**：三角格点上的拓扑码

### 4.4 容错量子计算

容错阈值定理：若物理错误率 $p < p_{th}$，则可任意长时间计算。

表面码阈值：$p_{th} \approx 1\%$

## 5. 量子算法

### 5.1 Shor算法

**问题**：大整数分解
**复杂度**：
- 经典：$O(e^{n^{1/3}})$（数域筛）
- 量子：$O(n^3)$

**核心步骤**：
1. 量子傅里叶变换找周期
2. 经典连分数恢复因子

### 5.2 Grover算法

**问题**：无结构搜索
**复杂度**：
- 经典：$O(N)$
- 量子：$O(\sqrt{N})$

**核心**：振幅放大

### 5.3 变分量子算法（VQA）

近期量子设备的算法：
- **VQE**（变分量子本征求解器）：量子化学
- **QAOA**（量子近似优化算法）：组合优化

## 6. 量子复杂度理论

### 6.1 量子复杂度类

| 复杂度类 | 定义 | 经典对应 |
|---------|------|---------|
| **BQP** | 量子多项式时间 | BPP |
| **QMA** | 量子Merlin-Arthur | NP |
| **QIP** | 量子交互证明 | IP |

### 6.2 关键结果

- **BQP ⊆ QMA**：显然
- **QMA完备问题**：局部哈密顿量问题
- **BQP vs NP**：未知是否BQP ⊆ NP或NP ⊆ BQP

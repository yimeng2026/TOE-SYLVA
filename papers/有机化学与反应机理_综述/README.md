## 目录主题简介

**有机化学**是研究含碳化合物的结构、性质、合成与反应的学科。其核心包括：官能团化学（醇、醛、酮、酸、胺、芳烃等）、反应机理（亲核取代、消除、加成、重排、周环反应）、立体化学（手性、对映异构、非对映异构、CIP 规则）、波谱解析（¹H/¹³C NMR、IR、MS、UV-Vis）。

**反应机理**研究化学反应中电子重排与化学键断裂/形成的具体路径——从基元反应（单步电子流）到多步串联反应（催化循环）。Hammett 方程（σ-ρ 线性自由能关系）将取代基效应定量化，是物理有机化学的核心工具。本综述从官能团化学与电子效应（诱导、共轭、超共轭）出发，系统阐述亲核/亲电反应（SN1/SN2、E1/E2、亲电加成）、周环反应（Diels-Alder、[1,5]-H 迁移、Cope/Claisen 重排）的 Woodward-Hoffmann 规则、立体化学（手性中心计数、CIP 优先级、对映/非对映选择性）、波谱解析（化学位移、偶合常数、质谱碎片）。在 SYLVA CNF 视角下，有机分子是因果网络节点，电子流是因果网络的边，反应机理 = 因果网络的有向路径，立体化学 = 因果节点的几何对称性破缺。

**关键词**：有机化学、反应机理、Hammett 方程、Woodward-Hoffmann、立体化学、CIP 规则、周环反应、波谱解析、CNF

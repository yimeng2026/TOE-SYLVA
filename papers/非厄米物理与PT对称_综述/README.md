## 目录主题简介

**非厄米物理**是对传统量子力学厄米性（$H = H^\dagger$）公理的激进拓展。1998 年，Bender 与 Boettcher 证明，一类非厄米哈密顿量——若满足 $\mathcal{PT}$ 对称（空间反射 $\mathcal{P}$ 与时间反演 $\mathcal{T}$ 联合不变性）——可以具有全实、下有界的能谱，从而将"实谱"的充分条件从厄米性推广到 $\mathcal{PT}$ 对称性。典型例子 $H = p^2 + ix^3$ 的能级全部为正实数。

本综述系统梳理了（i）$\mathcal{PT}$ 对称的数学构造（$\mathcal{C}$ 算子、正定内积与重构的幺正演化）；（ii）**例外点**（Exceptional Point, EP）——非厄米系统特有的谱简并点，在此点不仅本征值合并，本征向量也合并为一个"自缩简态"（self-orthogonal），导致的平方根灵敏度使 EP 成为超灵敏传感器的物理基础；（iii）**非厄米趋肤效应**（Non-Hermitian Skin Effect）——所有本征态局域在开放边界，导致常规体-边界对应（BBC）的破缺，需要引入非布洛赫 BBC；（iv）在光学、声学、电子电路中 $\mathcal{PT}$ 对称的实验实现。在 TOE-SYLVA 框架下，$\mathcal{PT}$ 对称是"阴阳对偶"的微观物理实例，而 EP 附近的拓扑结构则是对偶结构发生相变的关键节点。

## 主题简介

粒子物理标准模型（Standard Model）是人类迄今为止最精确的物理理论——它用 SU(3)×SU(2)×U(1) 规范对称性统一描述了强相互作用（QCD）、弱相互作用和电磁相互作用，其预言在 LHC 上被精确验证至千分之一量级。

本目录从 TOE-SYLVA 框架出发，系统回顾标准模型的数学结构（纤维丛、联络、曲率 = 场强）、粒子谱系（三代费米子、Higgs 机制）、以及标准模型的未解之谜（中微子质量、强 CP 问题、层级问题、暗物质候选者）。核心视角：标准模型的规范对称性可被诠释为因果网络上信息守恒的局部gauge约束——SU(3) 对应于颜色信息的不可区分性，SU(2)×U(1) 对应于弱同位旋与超荷信息的混合。

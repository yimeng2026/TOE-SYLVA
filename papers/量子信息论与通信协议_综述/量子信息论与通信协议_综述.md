## 2. 量子信息度量

### 2.1 冯·诺依曼熵

$$S(\rho) = -\text{Tr}[\rho \ln \rho]$$

**性质**：
- $S(\rho) = 0 \iff \rho$ 是纯态
- $S(\rho) \leq \log d$（等号当且仅当 $\rho = I/d$）
- 在幺正演化下不变：$S(U\rho U^\dagger) = S(\rho)$

### 2.2 量子相对熵

$$S(\rho\|\sigma) = \text{Tr}[\rho(\ln\rho - \ln\sigma)] \geq 0 \quad \text{(Klein's inequality)}$$

### 2.3 条件熵与互信息

$$S(A|B)_\rho = S(AB)_\rho - S(B)_\rho \quad \text{(可为负数！)}$$
$$I(A:B)_\rho = S(A) + S(B) - S(AB) \quad \text{(量子互信息)}$$

**负条件熵** $S(A|B) < 0$ 是纯粹的量子效应，意味着存在**量子纠缠**。

## 3. Holevo 界与信道容量

### 3.1 Holevo 定理

**定理 3.1**（Holevo）。Alice 用 $n$ 个量子比特编码经典信息发送给 Bob，Bob 最多能提取：
$$I_{\max} = S\left(\sum_i p_i \rho_i\right) - \sum_i p_i S(\rho_i) \leq n \text{ bits}$$

**证明思路**：利用量子 Fisher 信息的单调性和 Holevo 界的上界构造。□

### 3.2 量子信道容量

**定义 3.1**（量子信道）。一个量子信道 $\mathcal{N}: \mathcal{D}(\mathcal{H}_{in}) \to \mathcal{D}(\mathcal{H}_{out})$ 是 CPTP 映射。

**量子容量定理**（LSD 公式）：
$$Q(\mathcal{N}) = \lim_{n\to\infty} \frac{1}{n} Q^{(1)}(\mathcal{N}^{\otimes n})$$
其中 $Q^{(1)}(\mathcal{N}) = \max_\rho [S(\mathcal{N}(\rho)) - S((\mathcal{N}\otimes I)(\Phi_\rho))]$ 是**单字母下界**（coherent information）。

### 3.3 加性 vs 非加性

- **经典容量** $C(\mathcal{N})$：已知非加性（superactivation 现象）
- **量子容量** $Q(\mathcal{N})$：存在 superactivation——两个零容量信道组合后容量 > 0
- **私有权容量** $P(\mathcal{N})$：类似非加性

## 4. 量子密钥分发（QKD）

### 4.1 BB84 协议

**步骤**：
1. Alice 随机选基 $\{|0\rangle,|1\rangle\}$ 或 $\{|+\rangle,|-\rangle\}$ 发送 qubit
2. Bob 随机选基测量
3. 公开讨论基选择，保留基匹配的比特
4. **错误估计**：取部分比特公开比较，估计 Eve 的信息量
5. **隐私放大**：通过哈希函数压缩到安全密钥

**安全性证明**（Shor-Preskill, 2000）：
- 基于 CSS 码的纠错 + 隐私放大
- 即使 Eve 有无限量子算力也安全
- 密钥率：$R = 1 - h_2(e) - h_2(e)$（其中 $e$ 是误码率，$h_2$ 是二进制熵函数）

### 4.2 E91 协议（纠缠基）

1. 共享纠缠对 $(|00\rangle+|11\rangle)/\sqrt{2}$
2. Alice 和 Bob 各自随机选测量基
3. 用 CHSH 不等式违反 $S > 2$ 检测 eavesdropping
4. 从满足 Bell 不等式的数据中提取密钥

**优势**：安全性直接来自量子力学原理（Bell 定理），不依赖具体设备 → **DI-QKD**（设备无关 QKD）

## 5. 量子中继器与量子网络

### 5.1 纠缠交换

$$|\Phi^+\rangle_{12} \otimes |\Phi^+\rangle_{34} \xrightarrow{\text{Bell meas on }2,3} |\Phi^+\rangle_{14}$$

通过测量中间两粒子，使两端粒子建立纠缠——无需直接交互。

### 5.2 量子中继器架构

```
[A]---[QR1]---[QR2]---[QR3]---[B]
  <-d-><-d-><-d-><-d->
```

- 每段长度 $d$，总距离 $L = 4d$
- 每段建立纠缠，然后逐段交换
- 纠缠纯化提高 fidelity
- 最终 A-B 距离 $L$ 的纠缠建立时间 $\sim (\text{segment time}) \times \log(L/d)$

### 5.3 量子存储要求

| NV 色心 | 毫秒-秒 | 90% | 中 |
| 稀土离子晶体 | 小时级 | 60% | 中 |

黑洞的 Hawking 辐射可以视为一种**量子信道**——信息通过纠缠被"传输"到辐射场中。量子岛公式 $S(R) = \min[\text{Area}/4G_N + S_{\text{bulk}}]$ 与信道容量公式共享同一个数学结构。

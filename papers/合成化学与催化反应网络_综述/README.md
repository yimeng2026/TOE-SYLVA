## 目录主题简介

**合成化学**是研究如何通过化学反应构建目标分子的学科，其核心包括：逆合成分析（Retrosynthesis）、官能团转化、保护基策略、偶联反应（Suzuki、Heck、Sonogashira 等）、不对称合成等。现代合成化学已从"试错法"进入"理性设计"阶段，密度泛函理论（DFT）+ 微观动力学模型（MKM）+ 机器学习正成为新催化剂发现的三件套。

**催化反应网络**研究催化剂在反应网络中的拓扑角色——催化循环对应闭环的有向反应图，催化剂的活性中心是因果网络中的"高扇出枢纽节点"，反应选择性由催化剂改变网络局部能量景观而非热力学终态决定。本综述从催化动力学的两大经典模型（Michaelis-Menten 酶催化、Langmuir-Hinshelwood 多相催化）出发，系统阐述反应网络图论性质（度分布、连通性、Feinberg 亏格、Deficiency Zero 定理），并探讨绿色化学十二原则下的可持续催化设计。在 SYLVA CNF 视角下，化学系统是一个多层耦合因果网络场——化学键 = 因果节点内部态、反应通道 = 因果网络边、催化剂 = 因果网络度集中枢纽、热力学 = 因果网络全局约束势函数。

**关键词**：合成化学、催化动力学、Michaelis-Menten、Langmuir-Hinshelwood、反应网络拓扑、Feinberg 亏格、绿色化学、CNF 分子因果网络

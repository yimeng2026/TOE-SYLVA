## 一、背景：王斌之问

王斌（UFPF，通用不动点分形谱范畴框架，gitee.com/dpsnet/universal_fixed_point_framework，CC-BY 4.0 + MIT）于 2026-08-10 起陆续发布光子拓扑理论系列（母笔记 Note-PHOTON-TOPO-v1.0 + Addendum 01–04，研究笔记 v2.7，第一性起源笔记 v0.6，Lean 模块 `PhotonTopology.lean`/`PhotonTopologyFunctor.lean`/`PhotonTopologyCurvature.lean` 与 Agda 镜像 `PhotonTopology.agda`），其核心主张为：

1. **光子 = 紧致驻波拓扑 → 开放行波拓扑的离散拓扑转变**（公理 A1/A2）；
2. **方向性阶跃公理 A4**：以 Heaviside 阶跃 χ_Φ(t)=Θ(t−t\*) 编码转变的过程性与不可逆性；
3. **双层正交结构**：光子是正交于三维空间（纤维 vs 基空间）且正交于引力 Δ（法向 vs 水平）的法向拓扑自由度，与 KK 额外维的区分判据为**可被物质拦截**（命题 1.3）；
4. **拦截共振条件**：吸收 = R 右伴随折叠，必要条件 hν=ΔE（命题 1.4），概率由 σ_abs=(hν/c)B₁₂g(ν) 描述（定义 1.4）。

他向 SYLVA（TOE-SYLVA / CNF 因果网络框架）提出的问题是一个公平的学术挑战：**你们的框架如何解释光子的行为？** 本项目是对该问题的正式、完整、可复核的回答。

## 二、目标

1. **给出 CNF 光子理论**（`01_CNF光子理论.md`）：光子 = 因果网络 L1 电磁层（U(1) 规范层）的集体激发/拓扑模；映射波粒二象性、Maxwell 方程涌现、E=pc 与无质量性、两种螺旋度、hν 量子化；姿态为**结构对应 + 可证伪关系**，不假装推出真实光子数值。
2. **正式评价 UFPF 光子拓扑 v0.9**（`02_对UFPF光子拓扑v0.9的评价.md`）：基于其真实文本（含行号引用），逐构件评审四构件（拓扑转变图景/A4 阶跃公理/双层正交/拦截共振），优点与批评并举，按 VERIFICATION_PROTOCOL §8.1 置信度四级逐条定级，并给出两方案优劣互换表。
3. **双理论综合批判**（`03_双理论综合批判.md`）：千界花园 research/panels **两轮**正式批判——第一轮对 CNF 光子理论自我批判，第二轮对 UFPF 光子拓扑批判（同配置：chair + 数学物理 reviewer + 统计物理委员）；两轮全部实质批评原文摘录（含对我们自己的不利意见），记录存 `_panel_records/`；若为 fallback/模拟内容，如实标注不采用。
4. **重构优化理论 v2.0**（`04_重构优化理论_v2.0.md`）：基于两轮批判重构——汲取 UFPF 的可拦截性判据与阶跃过程性表述，保留 CNF 的规范激发连续性与 Lean 实证路线，消除双方被批评点；给出统一框架 v2.0（核心公理集、概念对照表、升级版可证伪预言挂证伪条件与裁决时间窗、与王斌原理论的形式差异声明）。
5. **数据验证**（`05_数据验证报告.md` + `code/`）：≥2 个 check() 范式脚本，做经典一致性检验（Maxwell 涌现一致性、黑体辐射 Planck 谱与光子气体热力学、Compton 关系、hν=ΔE 拦截条件量纲一致性），全部真实计算、无 mock、附输出。
6. **总结与公开回应**（`06_两则理论的评价和比较.md` + `README.md`）：三方对照表（UFPF vs CNF v1.0 vs 重构 v2.0）+ 给王斌的知乎回复摘要（可直接发布）+ 项目索引与状态。

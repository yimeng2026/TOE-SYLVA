## 勘误 E1：paper6 推论 3.2 Kolmogorov 常数公式数值错误（V1，严重）

**位置**：paper6（湍流谱流篇）推论 3.2，P6:157–163；其"证明"见 P6:163。

**现状**：文中给出 Kolmogorov 常数公式

  C = (2π)⁻¹ · (3/2)^{2/3}

并标注数值 "≈ 1.59"，声称"与实验值 1.5–1.6 一致"。其证明仅一句："由归一化条件唯一确定，具体计算涉及不变测度"，无实际计算过程。

**问题**：按双精度实算，(2π)⁻¹·(3/2)^{2/3} = **0.20855**（Python float64），与文中所标 1.59 相差 **7.62 倍**。数字 1.59 疑为 (2π)⁻¹ = 0.15915 的移位误读（小数点右移一位）。此外，即使公式数值修好，"具体计算涉及不变测度"一句也不构成推导——归一化常数的确定需要展示不变测度的显式构造或至少一个可执行的归一化积分，当前文本是"声称"而非"展示"。附带说明：Kolmogorov 常数在主流理论中本就不由 K41 唯一确定（Yakhot-Orszag RG、EDQNM 闭合、间歇性修正各有估值，无公认第一原理值），"谱确定 C"的声称强度超出文本交付。

**修正建议**：
1. 数值重算：将 1.59 更正为 0.2086（或修正公式本身——若目标确为复现 1.5 附近的实验值，则公式结构需要重新审视，例如核查 (3/2) 的指数归属与 2π 因子的来源）；
2. 为该公式注册一个 `check_kolmogorov_C.py` 数值脚本，纳入贵方 RAP 检测矩阵——这正是贵方自己确立的纪律（"每个数值声称配 check 脚本"），paper6 目前不在 proof_status / 盲登记 / 证伪条款的任何一张网里，此脚本可补上该覆盖缺口；
3. 若归一化计算暂不能完成，建议按贵方措辞规范将该条降级为"常数公式候选，归一化计算待完成"。

**核验方式**：
- 我方出处：`papers/外部项目批判重建/01_MUFPF四十八篇批判性总评.md` V1 节（§6.1 点 3 及专节结论，行 120、183、189、223）。
- 复核命令：`python -c "print((2*3.141592653589793)**-1 * (1.5)**(2/3))"` → 0.20855…
- 镜像定位：paper6 v2.8，推论 3.2 及证明段。

## 勘误 E2：paper6:457 Tc 偏差口径不符（V2）

**位置**：paper6:457，关于临界温度 Tc 的数值比较。

**现状**：文中标注 Tc 两值（153 MeV vs 155 MeV）的相对偏差为 "1.1%"。

**问题**：按常规定义（以 155 为基准），|153−155|/155 = **1.29%**，非所标 1.1%。若取另一方向基准（|153−155|/153 = 1.31%）或对称口径（2/154 = 1.30%），同样得不到 1.1%。属轻度口径偏差，不影响定性结论，但在以口径严谨著称的文稿中应当修正。

**修正建议**：更正为 "≈1.3%"（或写明所用口径及其定义式）。建议在检测矩阵中为所有百分比声称统一注册口径定义，避免不同章节使用不同基准。

**核验方式**：
- 我方出处：`papers/外部项目批判重建/01_MUFPF四十八篇批判性总评.md` V1 节相关条目。
- 复核命令：`python -c "print(abs(153-155)/155)"` → 0.012903…
- 镜像定位：paper6:457。

## 勘误 E3：paper44 v0.37 定理 2.4 波阻抗公式 α 倒置（严重）

**位置**：paper44 v0.37 定理 2.4（波阻抗）；另涉其证明步 3 与上下文表述共三处。

**现状**：定理 2.4 印刷形式为

  Z₀ = (4π/α) · (ℏ/e²)

并标注数值核验通过（✓）。

**问题**：按印刷公式实算：(4π/α)·(ℏ/e²) = 4π × 137.036 × 4108.9 ≈ **7.08×10⁶ Ω**，偏离真实自由空间阻抗 Z₀ = μ₀c ≈ **376.730 Ω** 达 **18779 倍（≈ α⁻²，精确比值 18786）**。正确恒等式为 **Z₀ = 2αR_K = 4πα·(ℏ/e²)**——α 在**分子**而非分母；实算 4π × 4108.9 / 137.036 = 376.73 Ω ✓。更严重的是内部矛盾：该定理**证明步 3 中暗中使用了正确形式** Z₀ = 4πα·ℏ/e² = 2αR_K，而定理表述为倒置形式，加上 ✓ 标注声称核验通过，三处表述互相矛盾，且无任何 check 脚本覆盖该数值——✓ 标注不成立。这是"α 倒置"型错误：量纲正确、结构形似，但精细结构常数位置颠倒，偏差因子恰为 α⁻²，纯人工审读极易漏过。

**修正建议**：
1. 定理表述统一修正为 Z₀ = 4πα·(ℏ/e²) = 2αR_K（≈ 376.73 Ω）；
2. 注册数值脚本 `check_Z0.py`：断言 `abs(4*pi*alpha*hbar/e**2 - 376.730313) < 1e-3`，纳入检测矩阵；
3. 全文检索 `4π/α` 与 `alpha` 在阻抗、电导、耦合类公式中的位置，排查同类倒置（我们建议至少覆盖定理 2.3 麦克斯韦拓扑推导章节的全部含 α 表达式）。

**核验方式**：
- 我方出处：`papers/光子行为_CNF解释/07_MUFPF更名与v0.40追踪评价.md` §3.6 专项（2026-09-05 实测，行 112、123、147、273），数值为我方独立实算，非贵方报告值。
- 复核命令：`python -c "import math; a=1/137.036; Rk=25812.807/6.283185307; print(4*math.pi/a*Rk/6.283185307, 2*a*25812.807)"`（或直接以 CODATA 值代入两种形式对比 376.730313 Ω）。
- 镜像定位：paper44 v0.37 定理 2.4 及证明步 3。

## 勘误 E5：ISLE "临界绝缘相"概念错误

**位置**：贵方稳定岛同域谱解释（ISLE，基于 paper14 v1.5 §5.8，ISLE:743–796）中"星形硬 = 能隙全区间关闭（gap≡0）"所对应相的命名。

**现状**：原文表述为"**临界绝缘相**"。

**问题**：绝缘相的定义性特征是非零激发能隙；gap ≡ 0（全区间无能隙）与"绝缘"在物理上互斥。该命名属概念错误，且位于 ISLE 三重签名（A 分支点密度尺寸持续 / B δ≈0 高比例 / C 发散度量级分离）的核心表述位置，容易误导后续读者对签名 A 物理含义的理解。

**修正建议**：更名为"**临界无能隙相**"（或"临界无隙金属相"，视贵方对该相输运性质的具体判定而定）。我方在转述贵方该理论时已先行修正并加注登记（深筛勘误 2026-09-06），本条为对等告知，便于贵方在源文稿同步更正。

**核验方式**：
- 我方出处：`papers/外部项目批判重建/03_稳定岛与EDRN项目簇批判.md` 行 17–18（含我方加注原文）。
- 复核方式：对照绝缘相标准定义（非零电荷激发能隙，参见 Mott/Anderson 绝缘教科书定义）与 ISLE:743–796 的 gap≡0 表述。

## 勘误 E6：P-CM-5 裁决口径与自家赝像档案矛盾

**位置**：P-CM-5（谱丛分支点相关裁决条目）中"分支点密度跨 N=6..16 恒定 ≈0.079–0.082"的表述。

**现状**：裁决口径称分支点密度在 N=6..16 区间恒定（≈0.079–0.082），并以此支持尺寸持续性签名。

**问题**：贵方自家 float64 赝像档案已将 N=6 的 107 个分支点**全部处决为舍入噪声**。若 N=6 的分支点集合整体属浮点赝像，则 N=6 处不存在可计入密度统计的真实分支点，"跨 N=6..16 恒定"的下端点不成立——裁决口径与赝像档案自相矛盾。

**修正建议**：将恒定区间修正为 **N=8..16**（并复核 N=8 处是否同样受赝像档案影响）；或在 P-CM-5 条目中显式注明"N=6 数据点依赝像档案剔除，恒定声称的实际支撑为 N=8..16"。后者更符合贵方"处决留痕"的治理风格。

**核验方式**：
- 我方出处：`papers/外部项目批判重建/03_稳定岛与EDRN项目簇批判.md` 相关节（P-CM-5 裁决与赝像档案交叉对照）。
- 复核方式：调阅贵方 float64 赝像档案 N=6 条目（107 个分支点全部处决记录）与 P-CM-5 原文区间表述对照。

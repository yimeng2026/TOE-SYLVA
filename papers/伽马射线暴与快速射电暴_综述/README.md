## 目录主题简介

**伽马射线暴（Gamma-Ray Burst, GRB）** 是宇宙中最猛烈的电磁爆发现象之一——在几秒到几分钟内释放的能量超过太阳一生（100 亿年）的总辐射。GRB 分为短暴（$<2$ 秒，双中子星并合）和长暴（$>2$ 秒，大质量星坍缩/超新星成协），其核心物理模型为**火球-内激波-外激波**模型：极端相对论喷流（Lorentz 因子 $\Gamma \gtrsim 100$）中的内激波产生瞬态 $\gamma$ 辐射，而喷流与星际介质碰撞产生的外激波则产生持续更久的余辉（X 射线、光学、射电波段）。

**快速射电暴（Fast Radio Burst, FRB）** 是 2007 年发现的毫秒级射电闪耀，其瞬时亮度（$\sim$ Jy·ms）使 GRB 相形见绌。FRB 的最重要物理信息编码在其色散量（Dispersion Measure）中：$\mathrm{DM} = \int n_e\,dl$。高 DM 值（远超银河系贡献）证明 FRB 源在宇宙学距离，使 FRB 成为探测宇宙"失踪重子物质"、暗物质与暗能量分布以及星际介质的新探针。磁陀星（magnetar）是目前 FRB 最有力的候选引擎。GRB 与 FRB 共同构成了 TOE-SYLVA 在天体物理观测端的"极端对偶探针"。

## TOE-SYLVA 关联

- **(M1) 极端对偶变换**：GRB/FRB 将引力能/磁能转换为电磁辐射的效率远超恒星核聚变（$\lesssim 1\%$），是 SYLVA 对偶变换在极端天体物理中的体现——一种"本体论形式"的能量转化为另一种。
- **(M2) DM 作为积分连接律**：FRB 的 DM 值将沿视线方向的所有自由电子积分编码为一个单一数值——是 SYLVA 中"信息通过连接律穿透多层系统"的宇宙学实例。
- **(M3) 喷流准直与对偶方向性**：GRB 喷流的极端准直（半张角数度）将能量沿对偶极化方向集中——体现了 SYLVA 连接律的方向选择性。

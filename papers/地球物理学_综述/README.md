## 目录主题简介

**地球物理学**是运用物理学原理与方法研究地球内部结构、动力学过程及其演化的学科。核心领域包括：**地震学**——通过地震波（P 波、S 波、面波）的传播反演地球内部速度结构（如 PREM 参考模型揭示了从地壳到内核的径向分层）；**地磁学**——研究地球磁场的起源（地核发电机理论）与长期变化（地磁倒转、西向漂移）；**重力与大地测量学**——通过重力异常和卫星轨道扰动探测地壳均衡与地幔对流；**地热学**——地球内部热源（放射性衰变、原始吸积热）与热传导-对流机制。

本综述还涵盖了地震震级标度（如矩震级 $M_w = \frac{2}{3} \log M_0 - 10.7$）、Gutenberg-Richter 定律（$ \log N = a - bM$）等定量描述工具，以及板块构造的物理驱动力（地幔对流、板块拉力）和地震预测的基本物理挑战。TOE-SYLVA 框架下，地球内部的圈层结构是"连接律"在行星尺度的体现——各圈层（地壳、地幔、外核、内核）通过物质与能量交换构成层级的耦合系统。

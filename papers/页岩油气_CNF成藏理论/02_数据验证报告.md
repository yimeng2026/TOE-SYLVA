## 二、Rock-Eval 验证（预言 P1/P2）

**脚本输出原文**（`python code/verify_cnf_shale_rockeval.py`，exit 0）：

```
[数据] 长7段 10 样品；青山口 8 样品（全部真实 csv 读入）
[T1] 长7段 S1 = 0.570*TOC -0.238  (R2=0.9937, t_b=-1.87)
  [PASS] P1a 渗流阈值：S1~TOC 截距 b < -0.05 mg/g（负截距=低端死区）
[T2] 低半区 S1 均值 1.430 / 高半区 5.640 = 0.254
  [PASS] P1b 低端趋零：低/高半区 S1 均值比 < 0.35
[T3] 上包络线 S1+S2 = 4.892*TOC -1.634  (R2=0.9998, 包络点 n=6)
  [PASS] P2 连通容量上包络：|b_env| <= 2.0 且 R2_env >= 0.90（楔形过原点）
[T4] 长7段 S1+S2 = 4.898*TOC -1.482  (R2=0.9990)
  [PASS] 健全性：长7段 S1+S2~TOC OLS R2 > 0.95
[T5] HI 中位：长7段 409.7 vs 青山口 349.0
  [PASS] 健全性：青山口 HI 中位 < 长7段 HI 中位
5/5 检查通过
```

### 判定 P1：存活

- **P1a**：长7段 OLS 截距 b = −0.238 mg/g < −0.05（t_b = −1.87，n=10）。渗流阈值（零注入死区）方向成立：TOC* = 0.238/0.570 ≈ 0.42 wt% 以下游离烃趋零；
- **P1b**：低/高半区 S1 均值比 = 0.254 < 0.35，低端趋零成立；
- **与 UFPF 的关系**：UFPF P4 在同一数据上同向（其报告 b = −0.238，与本项目独立重算逐值一致——管线互证）。两理论在该数据点**共同存活**，不分胜负；UFPF 已做跨盆地检验并部分证伪（Permian 正截距），CNF-P1 本期未做跨盆地——**预登记降级风险**（`01_CNF成藏理论.md` §5）：若跨盆地失效，CNF-P1 同样须降级为"成熟度均匀、无运移注入的原地生烃体系"特例。

### 判定 P2：存活（CNF 独有预言）

- 合并 n=18（长7段 10 + 青山口 8），按预登记方法（TOC 升序 6 等箱、箱内 S1+S2 最大值点为包络点）得上包络线 **S1+S2 = 4.892·TOC − 1.634**，R²_env = 0.9998；
- |b_env| = 1.634 ≤ 2.0 且 R²_env ≥ 0.90 → **连通容量上包络过原点成立**：散点呈楔形——上界为容量线（斜率 ≈ 4.9 mg/g 每 wt% TOC，与均值回归斜率 4.898 几乎一致），下界由夹层（CY-04/CY-07 低 TOC 低潜量点）与成熟度差异向下弥散；
- **差异化意义**：UFPF 谱流理论无此预言形式（其主线为均值线性 R²=0.9990）；楔形上包络是 CNF"连通度饱和 → 容量上限"映射（§3.3）的独有可检验形式，本期存活。

## 三、MICP 验证（预言 P3：两理论形式对决）

**脚本输出原文**（`python code/verify_cnf_shale_micp.py`，exit 1，负结果如实保留）：

```
[数据] 样品数 31，压力点数 85（全部真实 csv 读入）
[逐样品] D 中位 3.448（范围 2.69-4.25）；ln P_t 中位 8.28
  [FAIL] 健全性：分形维数 D 中位数 ∈ [2,3]: D 中位=3.448，范围 [2.69,4.25]
[定义域] D > 2.05 的样品 31/31
  [PASS] 健全性：双曲形式定义域样品占比 >= 80%
[形式A·CNF 线性] ln P_t = 1.921*D +1.641  (R2=0.8330)
[形式B·UFPF 双曲] ln P_t = -2.771/(D-2) +10.300  (R2=0.8720)
[P3] n=31，RSS_线性=2.8149，RSS_双曲=2.1574，ΔAIC = -8.247
  [FAIL] P3 封堵标度形式竞争：ΔAIC > -2: ΔAIC=-8.247
1/3 检查通过
```

### 判定 P3：排除（负结果登记，UFPF 得分点）

- 预登记判据：ΔAIC = AIC_双曲 − AIC_线性 > −2 则 CNF 线性形式存活。实测 **ΔAIC = −8.247 ≤ −2** → **CNF-P3 排除**；
- 在同一套 D 与 P_t（预登记透明操作定义）上，UFPF 双曲形式 ln P_t = −2.771/(D−2) + 10.300（R² = 0.8720）显著优于 CNF 线性形式 ln P_t = 1.921·D + 1.641（R² = 0.8330）；
- **与 UFPF 自身结果的对照（独立重算后比对，非引用）**：UFPF M10/M11 报告线性 R² = 0.450 / 双曲 R² = 0.578，方向一致（双曲优于线性）；本项目 R² 整体更高源于 D 操作定义差异（见 §四根因），但"双曲胜线性"的方向在两套独立定义下一致 → P3 判定对定义差异稳健；
- **理论后果**（按 `01_CNF成藏理论.md` §5.1 降级规则）：隧穿抑制 exp(−κΔz) 的双对数线性形式**不能**作为全段 MICP 封堵标度的全局形式；§3.2 映射须修订为窗口局部近似（见 §五 POST-HOC）。

## 四、负结果登记（2 项，E 编号永不移除）

### E-SHALE-01：分形维数健全性未通过（D 中位 3.448 ∉ [2,3]）

- **现象**：全段 log(1−S_wet)–log P 幂律拟合给出 D 中位 3.448（范围 2.69–4.25），超出压汞分形文献物理范围 [2,3]；UFPF M1 报告其口径下单段 D 中位 2.862；
- **根因诊断**（2026-08-10，逐样品窗口扫描）：S1 样品在 S_hg > 0 / >0.01 / >0.05 窗口下 D = 3.352 / 3.278 / 3.123，P > 5000 psia 窗口 D = 3.054——**全段单一幂律把高压小孔段（模型失效区）混入拟合，系统性抬高 D**；UFPF M1 自身亦报告小孔段 D = 3.626"不物理"并改行多段分形——本负结果与 UFPF 的内部观察**方向一致**，属"单幂律应用于多段数据"的已知方法学假象，非数据错误；
- **处置**：登记负结果；本项目不改为多段拟合再判（那将构成 POST-HOC 口径变更）；P3 判定在预登记口径下已完成，不受影响（两种形式在同一 D 口径下竞争，内部公平）。

### E-SHALE-02：CNF-P3 排除（线性封堵标度被双曲击败）

- 内容见 §三。作为两理论同数据对决的负结果永久登记：**在 Tuscaloosa MICP 数据点（预登记全段口径）上，UFPF 谱隙双曲形式占优**。

## 五、POST-HOC 敏感性分析（明确标注，不进入预登记判定）

预登记判定完成后补做的高压窗口（P > 5000 psia）重赛（明确 POST-HOC 标签，**不用于推翻 §三判定**）：

```
n=31, D中位=3.246（范围 2.31-4.25）
线性: lnPt=1.579·D+3.055, R2=0.9034；双曲: lnPt=-1.066/(D-2)+9.201, R2=0.7846
ΔAIC = +24.859（线性显著占优）
```

- 形式竞争结果**窗口依赖**：全段口径双曲胜（ΔAIC = −8.2），高压窗口线性胜（ΔAIC = +24.9）；
- 科学解读：两种函数形式均非全局正确——数据的本征特征是**多段结构**（与 UFPF M1 多段分形、M7 双孔隙两段分形一致）；双曲形式在全段口径胜出是因为其曲率吸收了段间过渡，线性形式在单一孔隙族窗口内才是隧穿抑制的正确局部表现；
- 对 CNF 的修正指引（POST-HOC，待下期正式立项）：§3.2 映射改为"窗口局部线性 + 段间过渡由多孔隙族结构解释"；对 UFPF 的对等质疑：双曲形式同样只是全段口径的经验最优，其 D→2 发散预言在多段数据上无定义域。

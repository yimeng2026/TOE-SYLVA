## 一、背景：王斌挑战书与应战方式

知乎读者王斌公开建议双方"用各自的理论进行落地测试"，并率先完成其侧工作：以 UFPF（通用不动点分形谱范畴框架）重构页岩油气成藏机理，提出"递归生烃 → 谱流注入 → 毛细管谱隙封堵 → 谱隙闭合突破"的谱流机制，声称完成 20 项实证检验（19 通过 + 1 负结果登记），数据源包括 USGS Tuscaloosa MICP（31 样品）、长7段/青山口 Rock-Eval 等，其仓库与数据集已全部公开。

本项目的应战方式（三条铁律）：

1. **同数据竞争**：只使用 UFPF 已公开入库的真实数据（其仓库 `scripts/data/` 下的公开数据集 csv，来源均可追溯至 USGS data release 与 OA 论文）与公开文献值；**判定必须基于同一数据的独立重算，不得照抄其 19/20 结论**；
2. **诚实姿态**：CNF 是分层因果网络的数学框架，本项目**不假装** CNF 能推出真实地质数值（κ、Δz 的地质对应需要标定而非推导）；我们承诺的是"**结构对应 + 可证伪关系**"——映射必须自洽，预言必须带死刑条款；
3. **判据先登**：本立项书 §四 的判据矩阵与 §五 的盲登记**先于任何数据实算写成**，行刑顺序：先写判据 → 后看数据 → 最后下判定（沿用第一期透明度声明模式）。

## 三、主流理论基线（调研结论，2026-08-10，zhihu-cli 实搜）

**李传亮运移聚集模型**（`UFPF/docs/页岩油藏气机理.md` 收录原文 + 知乎专栏核验）：

1. 页岩 = 泥岩基质（生油层+盖层）+ 薄层砂条（储集层）的非均质体；成藏 = 无数微型岩性圈闭的集合（离散型油气藏）；
2. 基质生烃 → 油气在浮力作用下**向上**运移入砂条 → 砂条灌满憋压形成**油气超压**（水仍常压，油水压差被毛管压力抵消）→ **不向下倒灌**；
3. 油水压差超过基质毛管压力 → **从油柱顶部突破**；砂条全部灌满后突破上覆地层 → 源外成藏；
4. 封堵为毛管压力"它封闭"，非"自封闭"；超压 vs 常压取决于基质致密程度（毛管压力公式判据）。

**全油气系统三动力场**（贾承造/庞雄奇学派，知乎检索核验）：自由达西流动力场 / 局限达西流动力场 / 束缚动力场，对应常规浮力成藏与非常规非浮力（自封闭/滞留）成藏。李传亮对此持批评立场，主张统一的浮力-毛管力-水动力定量描述。本项目取**三动力场作为现象学分区的描述语言**（自由/局限/束缚），与李传亮的统一力学描述并行不悖——CNF 将为三分区给出网络结构对应。

**UFPF 谱流理论（竞争对手）**：机制四段论"递归生烃 → 谱流注入 → 毛细管谱隙封堵 → 谱隙闭合突破"；独有预言 P1（封堵双曲标度 log P_t = C/(D−2)+B）、P2（超压临界 ν≈1/2）、P3（突破通道 D_b=ln2/ln3）、P4（零注入阈值，跨盆地部分证伪后修正）、P5（HI-Tmax 窗内符号反转）；S1 三因素机制 S1 = a·TOC + f(M) + c；声称 20 项检查 19 通过（M0–M14 + B1–B3 + P 系列）。

## 四、判据矩阵（预登记，先于数据实算）

CNF 理论三条可证伪预言的判定标准（详见 `01_CNF成藏理论.md` §5 盲登记）：

| 编号 | 预言（一句话） | 数据 | 通过条件 | 证伪条件（死刑条款） |
|---|---|---|---|---|
| **CNF-P1** | 渗流阈值：游离烃 S1 对 TOC 呈"过原点线性 + 低端死区"（负截距 + 低端趋零） | 长7段 n=10 | OLS 截距 b < −0.05 mg/g 且低端（TOC 下半区）S1 均值/高端（TOC 上半区）S1 均值 < 0.35 | b ≥ −0.05（截距不显著为负）**或** 低/高比 ≥ 0.35 → P1 死亡 |
| **CNF-P2** | 连通容量上包络：生烃潜量 S1+S2 对 TOC 呈楔形包络，上包络为过原点直线 | 长7段+青山口合并 n=18 | 上分位包络线（分箱 90% 分位点 OLS）截距 \|b_env\| ≤ 2.0 mg/g 且 R²_env ≥ 0.90 | \|b_env\| > 2.0 **或** R²_env < 0.90 → P2 死亡 |
| **CNF-P3** | 封堵标度形式竞争：CNF 线性形式 log P_t = α·D + β 对 UFPF 双曲形式 log P_t = C/(D−2)+B，在同一 Tuscaloosa 31 样品上 CNF 形式不劣于双曲 | Tuscaloosa MICP n=31 | ΔAIC = AIC_双曲 − AIC_线性 > −2（即线性不被双曲显著击败；同参数量下以 R² 复核） | ΔAIC ≤ −2（双曲显著更优）→ P3 死亡，UFPF 形式获胜并如实登记 |

**公平性附注**（预登记）：P3 的门限压力 P_t 采用透明操作定义（伪润湿饱和度首次降至 <0.99 对应的压力，即 1% 汞侵入点），分形维数 D 采用全段 log S–log P 回归（S=a·P_c^{−(2−D)} 模型，D = 斜率+2）；该定义与 UFPF M1/M10 的内部定义未必逐字相同，函数形式竞争的结论对操作定义的敏感性将在报告中如实讨论。判定词汇表沿用第一期：**存活 / 降级 / 排除**。

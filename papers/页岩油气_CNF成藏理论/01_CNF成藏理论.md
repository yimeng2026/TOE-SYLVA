## 摘要

本文将页岩油气成藏过程映射为 TOE-SYLVA 因果网络框架（Causal Network Framework, CNF）上的结构动力学：**烃源岩基质-砂条垂向序列映射为分层因果网络的层（Level）；生烃增压映射为层内节点激活与连通度增长；排烃运移映射为占据网络上有向渗流；毛管封堵与保存映射为层间隧穿抑制 ℱ = exp(−κΔz)；突破散失映射为势垒塌缩导致的层间连通重开**。与李传亮运移聚集模型及全油气系统三动力场（自由/局限/束缚）给出逐项结构对应；与 UFPF 谱流理论给出逐项机制对照。提出三条可证伪定量预言（渗流阈值、连通容量上包络、封堵标度形式竞争），均以盲登记格式冻结判据。本文持"结构对应 + 可证伪关系"的诚实姿态：CNF 不提供地质数值的第一性推导，κ、Δz、渗流阈值等参数须由真实数据标定；理论的价值在于给出**可检验的关系形式与方向性约束**。其中运移方向性以"边方向 = 浮力/重力势梯度"对应规则显式登记——**v1.1 诚实修订：该对应规则是独立假设，与 UFPF 谱静默设定认识论地位同等**（v1.0 的"无环公理内禀推论、无需外加假设"宣称经千界花园评审被判定为循环论证，已撤回，见 §3.4）。

## 1 引言

### 1.1 问题

页岩油气藏成藏机理存在两类竞争图景（李传亮《页岩油气藏的成藏机理》；王斌 UFPF 谱流重构）：

- **运移聚集模型**（李传亮）：页岩为泥岩基质 + 薄层砂条的非均质体；基质生烃 → 浮力驱动向上运移入砂条 → 灌满憋压成超压 → 油水压差超毛管压力后从油柱顶部突破；封堵为毛管"它封闭"；
- **原位滞留/自封闭模型**（主流非常规叙事）：油气以吸附态/游离态滞留于烃源岩内，分子间作用力主导，无需外部圈闭。

王斌已用 UFPF 框架对运移聚集模型给出谱流机制重构（递归生烃 → 谱流注入 → 谱隙封堵 → 谱隙闭合突破），并完成同批公开数据的实证检验（声称 20 项检查 19 通过）。本文的任务：以 TOE-SYLVA 的因果网络框架给出**同一地质图景的第二种理论重构**，与 UFPF 谱流理论在机制表述力、可证伪性与同数据表现三个维度正面竞争。

### 1.2 姿态声明（诚实边界）

CNF 是关于分层因果结构的数学框架，其原生对象是普朗克尺度事件网络（FourForcesUnification.lean 的 `CausalNode`/`CausalEdge`/`noCycles`）。把它用到页岩成藏，是**跨尺度的结构映射**，不是微观推导。因此：

1. 我们**不声称** CNF 能推出 κ、Δz、渗流阈值的真实地质数值——这些参数由 Rock-Eval/MICP 真实数据标定；
2. 我们**声称** CNF 给出自洽的结构对应（§3）、方向性约束（§3.4，以独立对应规则显式登记，v1.1）、以及可证伪的关系形式（§5）；
3. 一切数值结论以 `02_数据验证报告.md` 的 csv 实算为准，本论文只做理论建构与预言登记；
4. 本文不裁决"运移聚集 vs 原位滞留"的地质学争论——与 UFPF 谱流理论保持同一方法论姿态。

## 3 成藏过程的 CNF 映射（核心）

### 3.0 映射总图

```
地质对象（李传亮图景）                CNF 对象（FourForcesUnification.lean）
─────────────────────────────────────────────────────────────────────────
干酪根（有机质储备）        ──→     待激活节点储备（源层内，规模上限 = TOC）
基质生烃（S2 → S1 转化）    ──→     节点激活 + 边生长（连通度 C_total 增长）
孔隙单元（基质孔/砂条孔）   ──→     CausalNode（id, layer, chirality）
孔喉（可流动通道）          ──→     CausalEdge（有向，weight = 导流能力）
砂条/基质垂向序列           ──→     Level 层序列 + 层距 Δz = |i − j|
毛管压力封堵                ──→     层间隧穿抑制 ℱ = exp(−κΔz)
砂条灌满憋压（超压）        ──→     连通度饱和 → 边权积累（C→C_max）
浮力驱动向上运移            ──→     有向渗流（沿因果前序 ≺，J⁺ 方向）
不向下倒灌                  ──→     noCycles 公理（可达性反对称）+ 边方向=重力势梯度对应规则（独立假设，v1.1）
油柱顶部突破                ──→     顶部 Δz_eff 塌缩，层间渗流相变
源内/源外分界               ──→     J⁺ 被高 Δz 边界截断 / 穿越
```

### 3.1 对应规则 R1：烃源岩层 = CNF 层，孔隙单元 = 因果节点

页岩垂向序列（基质—砂条—基质…）映射为分层因果网络的层序列：

- 每个**孔隙单元**（基质孔、砂条孔）映射为一个 `CausalNode`，其 `layer` 字段取该单元所属地质层位；
- 相邻层位索引差给出**层距** Δz = |layer_i − layer_j|（对应 `layerDistance`，L194–195）；地质上 Δz 综合了垂向距离与介质差异（基质小孔→砂条大孔的有效距离大，砂条→砂条有效距离小）；
- 孔喉（两孔隙单元间的可流动通道）映射为 `CausalEdge`，边权 w 对应喉道导流能力；
- 干酪根（有机质）映射为源层内**待激活节点储备**：TOC（总有机碳）= 源层可激活节点的规模上限。Rock-Eval 指标对应：TOC ↔ 储备规模；S2（裂解烃潜力）↔ 剩余可激活储备；S1（游离烃）↔ 已激活并已建立连通的节点-边；S1+S2 ↔ 总预算。

### 3.2 对应规则 R2：封堵/保存 = 层间隧穿抑制 ℱ = exp(−κΔz)

跨层流动（基质→砂条、砂条→上覆地层）必须经过层间跃迁，其通过率为隧穿因子（`tunnelingFactorFormula`，L190–191）：

$$\mathcal{F}(\Delta z) = \exp(-\kappa\,\Delta z), \qquad \kappa = \ln 10$$

- **毛管封堵**：基质小孔与砂条大孔之间的毛管压力差在 CNF 中对应**有效层距**——孔喉越小、封堵越强，等效 Δz 越大，跨层通过率指数抑制。致密基质（强封堵）⇔ Δz 大 ⇔ ℱ→0：油气被局域在砂条内，超压得以保存；欠致密基质 ⇔ Δz 小 ⇔ 持续泄漏：常压藏。这给出李传亮"超压 vs 常压取决于基质致密程度"判据的 CNF 形式；
- **突破**：当驱动压差（油水压差）超过封堵阈值，物理上等效于 Δz_eff 塌缩（势垒被克服），ℱ 从 ~0 跳到 O(1)，层间连通重开——突破是**层间渗流的相变**，而非渐变。突破发生在油柱顶部（压差最大处）⇔ 顶部等效 Δz 最先塌缩；
- **与 MICP 可测量量的桥**：压汞实验中门限压力 P_t 是非润湿相突破孔喉封堵的临界压力；CNF 给出 ℱ–Δz 指数形式，经 Washburn 关系（P ∝ 1/r）转化为 P_t 与孔喉结构标度参量（分形维数 D）的可检验关系（§5 预言 P3）。

### 3.3 对应规则 R3：生烃增压 = 连通度增长；含烃饱和度 = 连通度度量

生烃过程在 CNF 中是**节点激活与边生长**：干酪根降解把待激活节点转为流体占据节点，并在孔隙单元间建立新边。连通度（`ConnectivityMeasure`，L271–329）随激活单调增长：

$$C_{\text{total}}(t) = C_{\text{spatial}}(t) + C_{\text{temporal}}(t) \;\uparrow \;\Longleftrightarrow\; \text{生烃增压}$$

- 连通度的物理对应是**含烃饱和度**：被激活节点占层内节点比例即含油/气饱和度 S_o；
- 砂条灌满憋压（李传亮图景第 3 步）⇔ 砂条层内连通度逼近容量上限 C_max：继续注入只能在固定节点集上增加边权（压力升高）而非增加节点数——**超压 = 连通度饱和后的边权积累**；
- "油气超压、水常压"⇔ 油相占据的子网络与水相子网络是两个连通分量，压力（边权）不共享——分量间无有效边，压差被分量边界（封堵边，§3.2）承受。

### 3.4 对应规则 R4：排烃运移 = 有向渗流；方向对应规则 = 独立假设（v1.1 修订）

油气沿压力梯度的运移映射为占据节点/边在有向网络上的**渗流（percolation）**：

- **渗流阈值**：当激活节点密度（⇔ 生烃强度 × TOC）低于阈值 p_c，激活节点形成有限孤岛（finite clusters），无贯穿路径——无游离烃排出；超过 p_c 后出现巨连通分量（giant component），游离烃获得贯穿通道。这给出"有效烃源岩 TOC 下限"现象的网络机制（§5 预言 P1）；
- **方向对应规则（独立假设，v1.1 修订版）**：CNF 的 `noCycles` 公理（L87–90）规定可达关系反对称——u 可达 v 且 v 可达 u 则 u = v；因果前序 `precedes`（L111）给出运移路径的严格时序（A ≺ B 则不存在 B→A 反向路径）。**v1.1 诚实修订**（采纳千界花园评审判定，见 `03_与UFPF谱流理论对比评审.md` 议题 1）：v1.0 宣称运移单向性"是无环公理的内禀推论、无需外加假设"，该宣称被判定为**循环论证**——无环性只排除环路，不"推导出"向上性；"边方向 = 浮力/重力势梯度方向"本身是一条**对应规则**，即独立假设。v1.1 明确登记：
  - **认识论地位声明**：方向对应规则与 UFPF 的"谱静默（S3 型）"设定处于**同等认识论地位**——两者都是方向性设定，差别仅在表述位置（CNF 以一条对应规则一次性登记于映射层，UFPF 以谱静默逐方向设定于动力学层）；"一次性登记"是表述经济性的有限优点，**不是**假设的免除；
  - **独立论证义务**：该对应规则的独立地质理由是浮力分异（油气-水密度差 × 重力场）——这是李传亮模型与盆地模拟工业软件共用的力学基线，并非 CNF 独有推导；
  - **可检验的失效条件**（对应规则可判失效的观测形式）：(i) 封闭体系内观测到净向下运移（倒灌）事件，且不能用后期构造改造、水力压裂等"边反向"机制解释 → 对应规则失效；(ii) 突破散失点位不在含油柱顶部而在底部 → 失效（联动结构性预言 CNF-S1，[DATA-MISSING]）；(iii) 数值敏感性检验（评审建议 R6）：若允许少量边反向（~1%，模拟构造改造）后 P1/P2 预言不再稳健 → 对应规则的经验稳健性不足，须降级；
- **源内/源外分界**：源层（生烃层）的 `futureLightCone`（J⁺，L106–107）= 该层生烃可影响的所有层位集合；J⁺ 被高 Δz 边界截断的范围即"源内成藏"域，穿越边界即"源外成藏"。

### 3.5 对应规则 R5：孔喉-连通标度 = 度分布幂律

CNF 的度分布幂律 P(k) ~ k^(−γ)（L160，`sylvaGamma = 2.2`）映射为孔喉系统的标度结构：孔隙单元的连通数（度 k）分布若为幂律，则网络存在跨越尺度的连通枢纽（大孔+裂缝），这与压汞分形（孔喉分布的多尺度自相似，文献分形维数 D∈[2,3]）是同一非均质性的两种度量语言。CNF 不预言 γ 必须取 Sylva 值 2.2（该值为基本相互作用网络的标定）；本期仅要求标度对应自洽：实测孔喉标度参量（分形维数 D）应落在幂律网络可实现的范围，且与封堵压力有可检验关系（§5 P3）。

### 3.6 成藏四阶段：CNF 叙事总装

| 阶段 | 李传亮图景 | CNF 表述 |
|---|---|---|
| ① 常压期 | 生烃少，油水压力接近 | 激活节点密度 < p_c：有限孤岛，无贯穿分量；层内连通度低 |
| ② 充注期 | 砂条聚集油气渐增 | 激活密度越过 p_c：巨分量出现，游离烃沿 J⁺ 方向充注砂条层 |
| ③ 超压期 | 砂条灌满憋压，水仍常压 | 砂条层连通度饱和（C→C_max），转为边权积累；油/水两分量不连通，压差由封堵边承受（ℱ≈0） |
| ④ 突破期 | 压差超毛管压力，顶部突破 | 顶部等效 Δz_eff 塌缩，ℱ 跳升至 O(1)：层间渗流相变，向 J⁺ 更外层位重开通道；全部砂条饱和后突破至源外 |

|---|---|---|
| 自由（达西流）动力场 | 浮力驱动、达西渗流自由进行，常规圈闭成藏 | **层内连通主导区**：激活密度远超 p_c，巨分量贯穿，层内渗流无阻 |
| 局限（局限达西流）动力场 | 渗流受孔喉结构部分抑制，非常规连续聚集 | **层间弱隧穿区**：层内连通但跨层 ℱ = exp(−κΔz) 指数压制非零，运移缓慢且受结构控制 |
| 束缚动力场 | 分子间作用力主导，流体被束缚（吸附/滞留） | **隧穿封闭区 + 孤岛区**：ℱ→0 跨层切断，或激活密度 < p_c 的有限孤岛，流体局域不可动 |

对应的意义：三动力场在 CNF 中不是三种物理机制，而是**同一网络在不同连通度/层距参数区的三个相**——这为李传亮"统一力学描述"立场提供了网络化的实现路径（三分区是涌现的现象学分区，不是三种算法切换）。

## 5 可证伪定量预言（盲登记）

以下三条预言已于 `00_立项书.md` §五 冻结（登记日期 2026-08-10，版本哈希 `1101630d0eb289239f02c4d3ac98865e346e2b67`），判据先于数据实算。判定词汇：存活/降级/排除。

**预言类型区分（v1.1 增补，采纳评审意见 R2）**：P1、P2 为 **Type-I（禁止性声明型）**预言——证伪条件命中即对应映射环节被排除，适用存活/降级/排除词汇；P3 为 **Type-II（比较统计型）**预言——其判据（ΔAIC）度量的是**两候选模型形式在同一数据窗口的相对适配度**（Burnham & Anderson 意义的模型选择支持度），命中不利判据的含义是"本模型形式在该窗口的相对适配度劣化登记"，**不是**理论整体的 Popper 式证伪。两类预言的认识论地位不同，报告中分别措辞。

### 预言 CNF-P1：渗流阈值（零注入死区）

**内容**：游离烃 S1 = 已建立有效连通的节点-边度量；渗流理论要求激活密度低于阈值 p_c 时巨分量不存在、S1 ≈ 0。故 S1 对 TOC 的关系应为"低端死区 + 过阈值近线性"：S1 = a·TOC − b，**截距 b 显著为负**（死区 TOC* = b/a > 0），且低 TOC 半区 S1 均值 / 高 TOC 半区 S1 均值显著小于 1（低端趋零）。
**证伪条件**：长7段（n=10）OLS 截距 b ≥ −0.05 mg/g（不显著为负），**或** 低/高半区 S1 均值比 ≥ 0.35 → P1 排除。
**与 UFPF 的关系**：UFPF P4（零注入阈值）在长7段上同向（b=−0.238），但其跨盆地检验部分证伪后修正为"原地生烃体系特例"。CNF-P1 的差异化在于机制归因（渗流阈值 vs 线性注入外推）且本期只在长7段就地判定；若 P1 存活而跨盆地失效，CNF 同样须降级为体系特例——如实预登记这一风险。

### 预言 CNF-P2：连通容量上包络（楔形包络）

**内容**：单位有机质可建立的连通总量存在容量上限（C_max 对应）⇒ 生烃潜量 S1+S2 对 TOC 的散点应呈**楔形**：上包络为容量线（近似过原点——无有机质则无容量），下界因成熟度/保存/夹层差异向下弥散。上包络线（分箱 90% 分位点 OLS）应满足：截距 |b_env| ≤ 2.0 mg/g，R²_env ≥ 0.90。
**证伪条件**：长7段+青山口合并（n=18）上包络截距 |b_env| > 2.0 mg/g，**或** R²_env < 0.90 → P2 排除。
**差异化**：UFPF 谱流理论无此预言形式（其主线为均值回归 R²=0.999）；楔形包络是 CNF 容量饱和机制的独有可检验形式。

### 预言 CNF-P3：封堵标度的函数形式比较（同数据模型选择，Type-II）

**内容**：CNF 的 ℱ = exp(−κΔz) 指数抑制 + Washburn 关系 ⇒ 门限压力对数与孔喉结构标度参量（分形维数 D）呈**线性形式** log P_t = α·D + β（指数律的双对数表现）；UFPF 谱流理论主张**双曲形式** log P_t = C/(D−2) + B（其 M11，声称 R²=0.578 优于线性 0.450）。两者在同一 Tuscaloosa MICP 数据（n=31）上以 AIC 比较：CNF 预言线性形式**不显著劣于**双曲（ΔAIC = AIC_双曲 − AIC_线性 > −2，同参数量下以 R² 复核）。
**不利判据（v1.1 措辞修订）**：ΔAIC ≤ −2（双曲显著更优）→ **相对适配度劣化登记**：被排除的是"CNF 线性形式"这一**模型形式在当前数据窗口的相对适配度**，UFPF 双曲形式在该窗口占优并如实登记；**这不是** CNF 理论整体的证伪——Type-II 判据度量相对支持度而非逻辑否证（Burnham & Anderson, 2002；评审意见 R2）。
**操作定义（预登记）**：P_t = 伪润湿饱和度首次 < 0.99 对应的压力（1% 汞侵入点）；D = 全段 log(1−S_wet)–log P 回归斜率 + 2（压汞分形模型 S = a·P^{−(2−D)}）；结论对操作定义的敏感性在报告中如实讨论。
**差异化说明**：这是两个理论在同一批真实数据上的函数形式**模型选择比较**——判定不引用 UFPF 的 R² 数字，全部由本项目脚本独立重算。

### 结构性预言（[DATA-MISSING] 预标注）

- **CNF-S1（突破顶部性）**：突破散失应发生在含油柱顶部（压差最大 ⇔ Δz_eff 最先塌缩）——需突破点位的井下观测数据，当前无公开数据，标注 **[DATA-MISSING]**，不计入本期判定；
- **CNF-S2（度分布标度）**：孔喉连通度分布若为幂律，标度指数应在幂律网络可实现范围（γ_eff ∈ [2,3]）——需孔喉-连通联合成像数据，标注 **[DATA-MISSING]**。

### 5.1 判定与降级规则（预登记 + v1.1 措辞修订）

1. Type-I 预言（P1/P2）判定：判据满足 = **存活**；证伪条件命中 = **排除**；介于其间（如截距为负但幅度不足）= **降级**并在报告中显式给出弱化读法。Type-II 预言（P3）判定（v1.1）：判据满足 = **存活**；不利判据命中 = **相对适配度劣化登记**（模型选择框架，非理论证伪）；
2. P3 为两理论同数据模型选择比较项：若双曲形式占优，除登记相对劣化外，须在 `02_数据验证报告.md` 与 `03_与UFPF谱流理论对比评审.md` 中明确写出"该数据窗口上 UFPF 形式占优"——不得含糊（v1.1 措辞）；
3. Type-I 预言排除不导致理论整体死亡，但须在理论篇修订版中删除或修正对应映射环节（如 P2 排除 ⇒ §3.3 容量饱和对应须重写）；Type-II 相对劣化仅要求该模型形式的适用范围说明（如 P3 ⇒ §3.2 线性形式限窗口局部，见 `02` §五）；
4. 判定只依据 `code/` 脚本实算输出；脚本未覆盖的论断不得使用"验证"措辞。

|---|---|---|---|
| 生烃 | 递归演化映射 Φ_kerogen（Tmax=进度，S2=剩余，S1=注入） | 节点激活 + 边生长（TOC=储备上限，S2=剩余储备，S1=已连通量） | 平行重构，同 Rock-Eval 对应 |

## 7 理论边界与诚实声明

1. **非推导声明**：CNF 不推导 κ、Δz、p_c、C_max 的地质数值；本期全部定量结论为"结构形式 + 数据标定"。凡出现数值（如 TOC*、α、β、D），均来自 `02_数据验证报告.md` 的 csv 实算；
2. **映射唯一性不主张**：同一地质图景可有多种理论重构（UFPF 谱流、CNF 网络、传统渗流力学）；本文只主张 CNF 重构自洽且可证伪，不主张其为唯一正确映射；
3. **地质学争论不裁决**：运移聚集 vs 原位滞留的争论由地质证据裁决，两个理论重构方均不越界；
4. **方向性主张的范围（v1.1 修订）**：无环公理只排除环路，不推导向上性；运移方向性依赖"边方向 = 浮力/重力势梯度"这一**独立对应规则**（与 UFPF 谱静默设定认识论地位同等），其独立地质理由为浮力分异力学基线；该规则的可判失效观测条件已在 §3.4 显式登记——方向性因此是**可检验的假设**而非免费的内禀性质；
5. **置信度**：本理论建构为 L1（开放，带证伪条款）；P1–P3 的数据检验为 L3（数值验证）；无 L4（Lean 形式化）主张。

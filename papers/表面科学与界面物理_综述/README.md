## 目录主题简介

**表面科学**研究的是材料最外层 1-10 个原子层区域的独特物理化学性质。表面原子的配位环境、电子态密度和化学活性均与体材料显著不同——表面态（Surface States）的形成、表面重构（Surface Reconstruction）、以及吸附（Adsorption）和脱附（Desorption）动力学构成了表面物理的核心议题。关键实验技术包括扫描隧道显微镜（STM）、原子力显微镜（AFM）、X 射线光电子能谱（XPS）和低能电子衍射（LEED）。

**界面物理**则将视野从"真空/表面"扩展到两种不同材料的交界面，涵盖金属-半导体肖特基势垒（Schottky Barrier）、氧化物异质界面二维电子气（如 LaAlO$_3$/SrTiO$_3$）、表面等离激元（Surface Plasmon Polariton, SPP）、以及表面增强拉曼散射（SERS）等丰富现象。在 TOE-SYLVA 框架下，表面与界面是连接律最直观的物理舞台——两种物质相的边界处涌现出全新的集体激发与对称性模式，是"层级涌现"的标准模板。

## TOE-SYLVA 关联

- **(M1) 界面作为连接律的实现**：每种界面都是两种"体相"的连接层，界面态是连接律产生的涌现自由度——连接处产生新的"物种"而非简单叠加。
- **(M2) 维度涌现**：表面态从 3D 体态中涌现出 2D 行为（如拓扑绝缘体表面 Dirac 锥），是 SYLVA 维度层级涌现的范例。
- **(M3) SPP 与光子-电荷对偶**：表面等离激元是光子与电荷密度的混合激发，体现了 SYLVA 中不同本体论层的耦合机制。

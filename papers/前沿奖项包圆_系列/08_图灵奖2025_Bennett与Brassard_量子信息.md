## 二、机制解剖

### 2.1 BB84：共轭编码 + 测量扰动 = 窃听检测【F0 + 推导】

- **编码**：Alice 对每一比特随机选两个共轭基之一——Z 基 {|0⟩, |1⟩} 或 X 基 {|+⟩, |−⟩}（|±⟩ = (|0⟩ ± |1⟩)/√2），发送相应偏振光子。
- **测量**：Bob 对每一光子独立随机选基测量。
- **筛基（sifting）**：双方在公开经典信道比对基（不比对比特值），丢弃基不符的一半，剩余为筛后密钥。
- **窃听检测**：抽样比对一部分筛后比特，估计量子比特误码率 QBER；QBER 低则纠错 + 隐私放大产出最终密钥，QBER 高则弃轮。
- **窃听必留痕的定量演示**【推导】：Eve 采用最简单的拦截-重发策略——随机选基测 Alice 的光子，再把测得态重发给 Bob。
  - 对每一个比特：Eve 选错基的概率 1/2；此时她重发的态在 Bob（选对基时）给出错误比特的概率 1/2。
  - 筛后比特上 Eve 引入的误码率 = 1/2 × 1/2 = **25%**。
  - 因此 intercept-resend 攻击在采样中必以 25% QBER 暴露；更一般攻击由不可克隆定理与纠缠单配性约束（§2.5 证明史把这一直觉变成无条件定理）。
- **三支柱**【判断】：不可克隆（不能复制未知量子态，Wootters–Zurek 1982【F0】）+ 测量扰动（共轭基不可同时对角化）+ 无信号（§3.3）——三者皆为物理定律，不是计算假设。

### 2.2 信息论安全 vs 计算安全【F0 + 判断】

| 维度 | 计算安全（RSA/ECC 传统） | 信息论安全（BB84 传统） |
|---|---|---|
| 安全根基 | 数学难题假设（大数分解、离散对数） | 物理定律（量子力学） |
| 对手模型 | 算力受限 | 算力无限、仅受物理定律约束 |
| 失效模式 | 算法突破或量子计算机（Shor 1994【F0】） | 物理定律被推翻（=可证伪的科学命题本身） |
| 长期性 | "现在收割、以后解密"威胁为真 | 密钥分发完成即永久安全 |
| 审计方式 | 跟踪复杂度理论进展 | 物理实验 + 统计检验（QBER） |

- Shannon 1949（*Bell Syst. Tech. J.* 28, 656–715【F0】）证明：完美保密要求密钥不短于明文——一次一密（OTP）。公钥密码绕开了密钥分发难题但引入计算假设；**QKD 恰好补上 OTP 的短板：用物理定律完成密钥分发**。ACM 新闻稿明确采用此叙事线【实录·已核】。
- 【判断】这不是"量子密码取代公钥密码"的零和故事——NIST 后量子密码标准（FIPS 203/204/205，2024-08 定稿【F0】）走的是"换计算假设"路线，QKD 走的是"换担保类型"路线；二者并行，但**担保类型不同这一事实本身是认识论事件**（§3.2 展开）。

### 2.3 量子隐形传态（1993）【F0 + 推导】

协议（BBCJPW 六人，PRL 70, 1895）：

1. Alice 与 Bob 共享一对 Bell 态 |Φ⁻⟩_{AB} = (|00⟩ − |11⟩)/√2；
2. Alice 对待传态 |ψ⟩_C = α|0⟩ + β|1⟩ 与自己那一半 A 做 Bell 基联合测量；
3. 关键恒等式（可逐行展开验证）：

$$
|\psi\rangle_C \otimes |\Phi^-\rangle_{AB} = \tfrac{1}{2}\sum_{k=0}^{3} |\mathcal{B}_k\rangle_{CA} \otimes \big(\sigma_k\,|\psi\rangle\big)_B
$$

其中 |𝓑_k⟩ 为四 Bell 态，σ_k ∈ {I, X, Z, XZ}。测量使 Bob 的粒子坍缩到 σ_k|ψ⟩——**α, β 两个连续参数完好地出现在 Bob 侧**，而 Alice 的测量结果 k（2 比特）不含任何关于 α, β 的信息；
4. Alice 经经典信道发送 2 比特 k；Bob 施以 σ_k† 修正，重建 |ψ⟩。

- **三条"没有违反"**【F0】：不超光速（必须等经典比特到达）；不违反不可克隆（Alice 侧原态已被测量破坏）；不传输物质（传的是态）。
- **意义**【判断】：纠缠从 EPR 佯论的"哲学奇物"变成可消耗的**工程资源**；ACM 原文即以此定性【实录·已核】。

### 2.4 纠缠蒸馏（1996）【F0】

- 问题：真实信道退相干使共享纠缠退化为混合态 ρ，保真度 F = ⟨Φ⁻|ρ|Φ⁻⟩ < 1，直接隐形传态质量不可控。
- BBPSSW 协议（PRL 76, 722）：两方对**两份**劣质纠缠对做局部双侧 XOR（BXOR）操作 + 测量比对，以消耗一份为代价提升另一份的保真度；递归迭代可把 F > 1/2 的 Werner 型态提纯到任意接近 1（产率上界由 hashing 不等式给出： distillable entanglement ≥ 1 − S(ρ)【F0】）。
- 【判断】蒸馏是"纠缠的纠错码"：它把量子通信从"演示物理"推向"可扩展网络"——量子中继（Briegel–Dür–Cirac–Zoller 1998【F0】）与 ACM 原文展望的量子互联网都建立在此之上。

### 3.1 信息几何轴（★★★★★）

- **"信息即物理量"的极端案例**【判断】：香农熵是抽象计数，von Neumann 熵 S(ρ) = −Tr ρ log ρ 却同时是热力学量、纠缠度量与信道容量的构筑砖块——在量子信息里，信息概念第一次获得**算子值的几何载体**（密度算子）。
- **Holevo 界**【F0】：对系综 {p_i, ρ_i}，可获取经典信息不超过

$$
\chi = S\!\left(\sum_i p_i \rho_i\right) - \sum_i p_i\, S(\rho_i)
$$

（Holevo 1973, *Probl. Peredachi Inf.* 9(3), 3–11【F0，页码待核】）。χ 是"平均态的熵 − 平均的熵"，即**分布的二阶差**——这正是信息几何中 Jensen 间隙/Bregman 散度家族的量子化身【判断】。
- **量子 Fisher 信息与 Bures 度量**【F0】：密度算子流形上的单调度量由量子 Fisher 信息给出（Bures 度量是其最小代表）；估计理论与几何在此合一（Helstrom/Holevo 谱系；Amari–Nagaoka *Methods of Information Geometry* 2000【F0】）。
- **直接接口**【判断】：我方 38 号文《信息几何与统计力学》（内部文献，确切编号与路径待核对【待核】）的对偶联络与熵几何框架，可与 Holevo 量、量子 Fisher 度量直接对接——BB84 的安全率公式 R = 1 − 2h(QBER) 就是二进制熵的几何对象，纠缠蒸馏的 hashing 界 1 − S(ρ) 亦然。**本篇是 38 号文最自然的应用场。**

### 3.2 形式化治理轴（★★★★☆）

- **信任基础设施的换锚**【判断】：现代密码把信任锚在"某数学难题很难"这一**经验性计算假设**上；BB84 把信任锚在"量子力学是对的"这一**物理定律**上。两者的认识论地位不同：计算假设随算法进展单调折旧（Shor 1994 已演示一次崩塌【F0】），物理定律则服从可证伪性纪律——它可能错，但错的方式是公开、可检验、可复现实验的。
- **与我方盲登记的同构**【判断】：仓库 `BLIND_REGISTRY.md`（已核实存在）用**哈希冻结 + 版本留痕**担保"预言先于结果"——其信任不依赖对我方诚信的假设，而依赖哈希函数的单向性这一公开可验性质。QKD 的密钥安全不依赖对 Eve 算力的假设，而依赖量子力学的公开可验定律。**两者都是"把信任从人格/算力假设迁移到可公开审计的数学-物理结构"**：信息论安全 = 可证伪性框架内的真安全，这是治理哲学的同一主题在不同领域的发作。
- **残差诚实**【判断】：QKD 的实现层（探测器侧信道、光源不完美）仍需工程治理——"物理定律担保"的是协议层，设备层回到传统审计；这一分层本身也是治理教训（担保链条的强度 = 最弱一环）。

### 3.3 CNF 轴（★★★★☆）

- **无信号约束 = 因果律的概率投影**【判断 + F0】：Bob 侧的约化密度矩阵不依赖 Alice 的基选择——否则即可超光速通信。形式上：对 Alice 测量选择 x、结果 a，∑_a p(a|x) ρ_B^{a|x} = ρ_B 与 x 无关。这是因果序在操作概率层的显式约束，CNF 框架可直接收纳为"因果完备性条件"。
- **Bell/CHSH 与因果结构**【F0】：Bell 定理给出"因果 + 定域 ⟹ CHSH ≤ 2"的可证伪界，量子到 2√2，PR box（Popescu–Rohrlich 1994【F0】）到 4 而无信号仍成立——**无信号 ⊋ 量子**的夹缝说明因果律不是量子关联的全部解释，这是量子因果结构研究的出发点。
- **无时序因果**【待核】：Oreshkov–Costa–Brukner 的过程矩阵框架（传 *Nat. Commun.* 3, 1092, 2012）把因果序本身变成可对象化研究的自由度——与 CNF 的"因果网络即对象"立场同构，值得单独立项。
- **量子网络即因果网络**【判断】：纠缠交换与量子中继把"谁在谁的因果过去"变成可设计的网络拓扑；ACM 原文的"量子互联网"展望【实录·已核】正是 CNF 意义上的大规模因果结构工程。

### 3.4 层化轴（★★★☆☆）

- **量子协议栈的层化**【判断】：
  - L0 物理层：光子/离子的量子态制备与测量；
  - L1 链路层：BB84/E91 建立逐跳密钥（信任在此注入）；
  - L2 网络层：纠缠交换、量子中继、蒸馏（把链路黏成网络）；
  - L3 应用层：QKD 网络、量子互联网、分布式量子计算。
- 特征【判断】：每一层的安全/质量担保都向下一层追溯（应用安全 ← 链路 QBER ← 物理层设备参数），与 §3.2 的"担保链条最弱环"教训互补；但层间接口目前是工程协议而非理论定理，故评级止于 ★★★。

### 3.5 谱轴（★★★☆☆）

- **密度算子的谱 = 一切标量信息**【F0 + 判断】：von Neumann 熵只依赖 ρ 的特征值；纠缠熵、蒸馏的 hashing 界、量子纠错码的 Knill–Laflamme 条件全部落在谱上。
- **蒸馏的谱解读**【推导】：BXOR 递归把 Werner 态的谱（一个最大特征值 + 三个简并小特征值）逐轮压缩向 delta 谱——纠缠蒸馏就是**概率单纯形上的谱纯化流**，与第 07 篇 ee 放大流（ẋ = αx(1−x²)，推向单纯形顶点）在数学上同族【判断：两篇的包圆在谱轴深处握手】。
- 评价【判断】：谱轴在此有真实但间接的内容——谱是工具不是主题；给 ★★★。

### 3.6 核心升华：信息概念的三次革命【判断】

- **第一次（Shannon 1948/1949）**：信息 = 抽象的比特计数，与载体无关；
- **第二次（BB84 1984 起）**：信息 = 物理量——载体不可删去，物理定律直接成为信息处理能力的边界与担保（不可克隆、Holevo 界、纠缠单配性）；
- **第三次（进行中，我们的位置）**：信息 = 几何——熵、容量、估计精度统一为流形上的度量与联络（38 号文方向）。
- 图灵奖追认第二次革命之时，恰是第三次革命需要 infrastructure 之日【判断】。ACM 主席"他们改变了我们对信息本身的理解"【实录·已核】可作第二次革命的官方印章。

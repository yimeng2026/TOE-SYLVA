## 二、机制解剖：从藻类视蛋白到神经开关

### 2.1 光敏蛋白机制：一个发色团撬动一个通道

Channelrhodopsin 属于微生物型视蛋白（type I rhodopsin）：七次跨膜（7TM）骨架 + 共价结合的**全反式视黄醛**（all-trans retinal）发色团【F1】。光循环的教学级链条【F2，教科书口径】：

```
470 nm 蓝光光子被视黄醛吸收
  → 全反式 → 13-顺式异构化（飞秒-皮秒级，光化学核心步骤）
  → 7TM 骨架构象变化（光循环中间态，毫秒级演化）
  → 跨膜孔道开放：阳离子内流（ChR2 对 H⁺、Na⁺、K⁺、Ca²⁺ 通透）
  → 神经元膜去极化 → 达到阈值即触发动作电位
  → 视黄醛热回复异构化，通道关闭（ChR2 关断时间常数约 10–20 ms 量级）
```

两个决定工程命运的分子事实【F1/J】：

1. **单组分性**：感光元件与离子通道是同一个蛋白。无需外源酶、无需第二信使级联——转入一个基因即获完整光控功能。这是 2003–2005 年工程转移得以成立的分子基础；
2. **辅因子现成**：视黄醛在哺乳动物组织中天然存在（维生素 A 代谢物），无需外加——这是 in vivo 可行的前提。
3. ChR1 与 ChR2 的功能分工史：ChR1 主要是质子通道（电流小、去极化能力弱），ChR2 是广义阳离子通道（钠内流主导，去极化强）——2005 年奠基论文选 ChR2 正是这个原因【F1/J】。

### 2.2 从微生物视蛋白到哺乳动物神经开关：工程转移清单

2005 年奠基之后，工程化沿四条线展开【F1/J】：

1. **表达与运输**：哺乳动物密码子优化、内质网输出信号与膜运输标签的融合（ChR2 早期在哺乳动物细胞膜表达弱、聚集，是第一批改进对象）；
2. **动力学突变体谱系**：H134R（增大光电流）、ChETA 系（超快开关，支持高频刺激）、Chronos/Chrimson 系（快慢通道与红移通道）——按"时间精度 × 光敏感性 × 光谱"三轴的工程空间展开【F2，领域共识口径】；
3. **靶向与递送**：细胞类型特异性启动子（如 CaMKIIα、Thy1）、Cre-lox 重组酶系统、AAV 病毒载体——把"哪类细胞对光敏感"交给遗传学决定；
4. **传光**：植入式光纤（2007 年 in vivo）、后来的 µLED 与无线器件——把"何时何处给光"交给工程学决定。

### 2.3 光遗传学的实验范式：因果干预三件套

光遗传学之所以是范式革命而非技术改良，在于它同时满足三个此前不可兼得的性质【F1/J】：

| 性质 | 内容 | 此前手段的短板 |
|---|---|---|
| **细胞类型特异性** | 遗传学靶向决定"谁"响应光 | 电刺激无细胞类型分辨；药理无空间精度 |
| **毫秒时间精度** | 光脉冲宽度/时序决定"何时"放电，精度达单动作电位级 | 药理慢（分钟-小时）；电刺激时序可控但对象混杂 |
| **双向开关** | ChR2 类激活 + NpHR/Arch 类抑制，同一制备内可做增益与失能 | 损毁/抑制只有单向 |

由此形成的标准实验设计逻辑【J】：

- **充分性检验**：激活 X 类细胞 → 行为 Y 出现（gain-of-function）；
- **必要性检验**：抑制 X 类细胞 → 行为 Y 消失（loss-of-function）；
- **时序因果判定**：ms 级时序控制可区分"X 驱动 Y"与"X 仅是 Y 的相关物"；
- **对照组体系**：仅光照无 opsin（光热/光毒性对照）、仅 opsin 无光照（泄漏电流对照）、yoked 非配对刺激（时序特异性对照）。

读出端的配合：光电极（optrode）同步电生理、钙成像、行为学量化——干预与观测在同一实验中闭环【F2】。

### 3.1 CNF 因果网络轴【强】：因果推断的实验化

这是本奖对我方框架**命中最深**的一轴。诺贝尔委员会自己的表述——"超越相关性观察，直接检验特定细胞与回路的作用"（§1.1）【F1】——就是因果推断语言。逐条展开【J】：

1. **do-算子的物理实现**。Pearl 因果理论区分观察分布 P(Y|X) 与干预分布 P(Y|do(X))：前者混杂着所有指向 X 的因果路径（backdoor），后者将 X 从其自然原因中"剪断"并强制赋值。光遗传学在字面上执行了 do(X)：光照这一外生变量接管了 X 类细胞的放电（X 的取值不再由其上游突触输入决定，而由实验者的光脉冲决定），同时保持回路其余部分原样运行。**电生理记录是 P(Y|X) 的采样器，光遗传刺激是 P(Y|do(X)) 的采样器**【J】。

2. **混杂控制的实验对应**。do-演算要求关闭 backdoor；光遗传学的对照体系（§2.3）正是实验版的 backdoor 关闭：随机化光照时序消除"光照 ↔ 行为阶段"的时序混杂，yoked 对照隔离"放电本身"与"放电时序"，仅光照对照隔离热/毒性混杂【J】。

3. **因果方向的时序裁决**。ms 级时间精度使干预-读出时序远快于回路传播时延，因果方向（X→Y 而非 Y→X）可由时序与双向干预（充分性+必要性）联合锁定——这对应 CNF 中"因果边 = 有向 + 可干预检验"的定义要求【J】。

4. **网络语义**。神经回路天然是图：节点 = 细胞/细胞类，边 = 突触连接。光遗传学把"边是否承载因果效应"从解剖学推断（连接组）提升为实验判定（受控激活上游节点、测量下游响应）——这正是我方 CNF"因果网络须经干预检验方可称因果边"立场在神经科学中的已实现版本【J】。

5. **诚实的局限**【J】：(a) 光控诱发的放电模式与生理放电模式之间存在保真度争议（超强、超同步的刺激可能诱出非生理响应）——do-操作的"赋值方式"本身影响结论外推；(b) 单节点 do-操作在强循环回路中的可识别性问题（recurrent feedback 使干预效应沿环路回流）未被范式本身解决；(c) 从细胞类型级干预到突触级干预的分辨率鸿沟仍在。这三条不构成否定，恰是 §5 开放问题的来源。

### 3.2 层化结构轴【强-中】：分子→行为的全层穿透

光遗传学的因果链横跨五个层级【J】：

```
分子层：视黄醛异构化（ps–ms）
  → 通道层：孔道开放与离子流（ms）
    → 细胞层：膜电位与动作电位（ms–s）
      → 回路层：群体同步与信息路由（ms–分钟）
        → 行为层：恐惧、奖赏、运动、决策（秒–分钟）
```

与我方 CNF 层化结构（`framework/09_neutrino_inflation.md` 的能量尺度分层）的同构点【J】：**同一干预手段（光）贯穿全部层级**，而每层有独立的读出（光电流/膜电位/群体场电位/行为指标）——层间因果映射因此可以被**逐层测量、逐层验证**，而非整体黑箱。Deisseroth 本人将光遗传学用于精神医学（抑郁、焦虑、社会行为的回路基础）正是"行为层的因果结论须回落到回路层机制"的跨层研究纲领【F2/J】。评强-中而非强：层间映射在复杂行为端仍是统计性而非确定性的。

### 3.3 信息几何轴【中】：神经流形上的受控探针

2026 年 ICTP Dirac 奖章得主 Haim Sompolinsky（与 Derrida、Dhar、Mézard 同获，2026-08-08 公布）的近期工作方向包括"神经表征几何与深度网络中物体流形的容量"（ICTP 引文口径）【F1】。其与我方信息几何轴及本奖的三角接口【J】：

1. 神经群体活动的状态空间常被低维流形组织（表征几何）；光遗传学提供了**沿流形 vs 离流形扰动**的实验手段——干预方向与流形几何的夹角决定行为后果，这是流形功能意义的因果检验【J/C】；
2. 我方信息几何系列（Fisher-Rao 度量、统计流形）与表征几何存在概念接口：群体响应分布族上的 Fisher 度量可刻画"可分辨性几何"，光遗传扰动则提供流形坐标的实验标定【J】；
3. 纪律提示：本接口立项前须通过 `AGENTS.md` 三.1 禁 vacuous 审查——模块强化 19 号曾以 `True` 占位顶替 Cramér–Rao 不等式，教训在先（`framework/EXTERNAL_LESSONS.md` §三 T-待1）【仓库事实】。

评中：接口真实存在，但需我方先清偿自身信息几何模块的证明债务。

### 3.4 形式化治理轴【中】：可重复性规范

光遗传学的治理形态是**方法规范型**而非 IceCube 式**大科学盲登记型**【J】：

- 对照体系的标准化（§2.3 四类对照）是领域准入门槛【F2/J】；
- 光照发热 artifact 的定量控制是已知陷阱：脑组织温升本身即可改变神经活动，规范要求报告光强-温升曲线并设仅光照对照（Owen, Liu & Kreitzer, Nature Neuroscience 2019 一类方法学文献）【待核】；
- 动物实验报告标准（ARRIVE 类）、病毒载体滴度与表达验证的 QA 流程【F2】；
- 临床转化（视网膜视觉恢复试验）带来的新治理维度：人体干预的伦理审查与终点指标预登记【F1/J】。

评中：规范成熟且与我方治理关切同向，但缺乏"冻结-登记-判死"级别的形式化承诺机制——恰是我方可输出的互补面（§4.3）【J】。

### 3.5 谱方法轴【弱-中】

节律干预（以特定频率光刺激驱动伽马等振荡，检验振荡的因果作用——Cardin 等 2009 年以小清蛋白中间神经元光驱动确立伽马振荡因果性的实验范式）与 LFP/连接谱分析存在接口【待核/J】。但谱方法非本奖成果核心，评弱-中。

### 4.1 CNF × 光遗传学对照文档【优先级 P0】

## 二、统一轴名约定（v1.1，2026-10-07）

本系列 §3"CNF 包圆分析（五轴评级）"统一使用以下**标准五轴名**：

| 标准轴名 | 内容范围 |
|---|---|
| **CNF 因果网络** | 约束网络、因果结构、干预与反事实 |
| **层化结构** | 尺度分层、粗粒化、跨层映射与涌现（含粗粒化流/RG 等动力学内容） |
| **谱方法** | 频谱、关联谱、谱序列、解耦/限制等频率空间方法 |
| **信息几何** | Fisher 度量、指数族、参数流形与表征流形几何 |
| **形式化治理** | 知识治理、形式化（Lean）、公理化制度、盲登记与裁决纪律 |

**约定条款**：

1. 评级表表头与小节标题一律使用标准轴名；评级针对"该成果与 TOE-SYLVA 本体的接口密度"（★1–★5），非对成果本身重要性的评价。
2. 某轴无命中时如实登记"无独立命中行"，不强行凑轴。
3. 变体/临时标签（如 05/06 篇 v1.0 的"几何轴""动力轴"）经内容判定后：同义缩写直接更名；不构成标准轴命中的保留为内容注记标签，并在该篇 §3.0 表后附"轴名映射说明"给出归属判定。

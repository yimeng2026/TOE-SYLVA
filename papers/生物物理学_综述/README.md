## 主题简介

生物物理学在分子尺度上用物理定律理解生命过程。本综述从 TOE-SYLVA 框架出发，系统覆盖六大经典主题：**蛋白质能量景观与折叠**（Levinthal 佯谬 → 漏斗能量景观模型）、**Hodgkin-Huxley 神经元动力学**（离子通道的全或无定律）、**DNA 弹性力学**（蠕虫链模型 WLC）、**Turing 形态发生**（反应扩散方程的模式形成）、**FRET 单分子能量转移**（荧光共振能量转移的 1/R⁶ 定律）、以及 **Helfrich 膜曲率弹性理论**。

核心视角：将生物大分子的构象动力学诠释为**因果网络上的构象空间采样**——蛋白质折叠的能量漏斗对应于信息自由能最小化的梯度流，Turing 斑图的形成对应于因果网络上的信息对称破缺，而 FRET 效率的 1/R⁶ 定律对应于纠缠熵在纳米尺度上的距离衰减。

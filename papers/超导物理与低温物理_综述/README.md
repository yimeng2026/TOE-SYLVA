## 目录主题简介

**超导物理**是凝聚态物理学中最引人入胜的领域之一，自 1911 年 Kamerlingh Onnes 发现汞在 4.2 K 以下电阻突降为零以来，超导现象始终驱动着理论与实验的前沿突破。超导的核心物理——零电阻与完全抗磁性（Meissner 效应）——由 1957 年 Bardeen-Cooper-Schrieffer（BCS）理论给出：声子介导的电子-电子吸引使费米面附近的电子配对形成 Cooper 对，凝聚为宏观量子相干态。BCS 理论预言的能隙方程 $ \Delta(T=0) = 1.76\, k_B T_c$、同位素效应、Andreev 反射等构成了传统超导的标准图像。

然而，**高温超导**（如 1986 年发现的铜氧化物超导体，$T_c$ 可达 160 K）和**非常规超导**（如铁基超导、重费米子超导、镍基超导、拓扑超导）突破了 BCS 框架，其配对机制仍属未解之谜——普遍认为是反铁磁自旋涨落而非声子作为"配对胶水"。**低温物理**为超导研究提供了不可或缺的实验环境：液氦温区（$<4.2$ K）、稀释制冷机（$<10^{-3}$ K）以及核绝热去磁等技术使对量子多体基态的精确探测成为可能。
